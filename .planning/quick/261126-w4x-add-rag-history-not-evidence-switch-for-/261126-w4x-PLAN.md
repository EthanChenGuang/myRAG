# Quick task 261126-w4x: RAG_HISTORY_NOT_EVIDENCE

Goal: with `RAG_HISTORY_NOT_EVIDENCE=true`, knowledge-base turns get one fixed, domain-neutral system-prompt instruction saying earlier assistant messages are not a source of facts. Default `false` reproduces today's messages byte for byte.

## Task 1: helper and route wiring
- files: src/lib/chat/history-not-evidence.ts, src/app/api/chat/route.ts, src/app/api/embed/chat/route.ts
- action: `appendHistoryNotEvidence(prompt, enabled)` appends the instruction once. Chat route: applied on the knowledge-base prompt branch (not bypass, not small talk) and to the Claude Citations system text. Embed route: applied on its knowledge-base branch. `/api/internal/voice-chat` only persists messages (no prompt assembly), so it is untouched.
- verify: tests/chat-history-not-evidence.test.ts

## Task 2: config sync
- files: src/lib/env.ts, scripts/init-env.js, scripts/config-server.js (3 templates), scripts/config-ui/index.html, scripts/rag/env-manifest.json, config/rag/settings-classification.json (query side), eval/config/rag-eval-env.json (regenerated)
- verify: node scripts/check-config.mjs; node scripts/ci/check-settings-classification.mjs; tests/eval-env-pin.test.ts

## Out of scope
- Capping prior assistant turns: not trivial (history feeds persistence, tool parts and the query layer); skipped.
