## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator CLI and admin routes to service-role SQL | a pointer flip changes v2 retrieval for every tenant of a doc type |
| Recorded decision to the activation gate | the evidence file comes from the sweep tool via an operator |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-59 | Elevation of privilege | anon or authenticated calling create, activate or rollback | high | mitigate | EXECUTE revoked from PUBLIC, anon, authenticated; granted to service_role; SET ROLE tests in both modes |
| T-04-60 | Tampering | activating a profile without passing evidence, or with evidence from an older build | high | mitigate | gates no_evidence, eval_failed and stale_evidence bound to the latest completed build run; decision validated by the generated schema before recording |
| T-04-61 | Denial of service | partial or concurrent pointer flips | medium | mitigate | one transaction with row locks; partial unique index on the active doc type; rollback always available to legacy |
| T-04-62 | Information disclosure | activation exposing another tenant's children | critical | mitigate | the flip changes only the pointer; hybrid_search_chunks keeps the tenant_key predicate; two-tenant check after activation |
