## Deviations from Plan
1. **Query vector file name**: `vectors/query-vectors.<tenant>.<profile>.f32` (per tenant) instead of `query-vectors.<profile>.f32`, because `VectorFileHeader` has one `tenant_key` and mining is per tenant. Tenant keys appear in file names with `:` replaced by `_` (the bundle file pattern has no colon). 06.1-11's `vectors_io` should read these names.
2. **Kept-query row type**: the plan did not pin it; rows are `FinetunePair` (see key decisions). 06.1-07/08 should write that shape into `queries.kept.jsonl` and `queries.test.kept.jsonl`.
3. **Fake provider instead of fake HTTP endpoint** for embed-queries: the test stubs the Voyage provider through `setEmbeddingProvidersForTests` (the `embedding-cli.test.mts` pattern), so the whole production query path (`embedQueriesForEvalProfile` → profile embedder → dims/model assertions) runs against it. The model-mismatch case exercises the existing `EmbeddingProfileMismatchError` path.
4. **Extra files**: `scripts/tests/check-rag-boundary.node-test.mjs` (the boundary RED test, as the plan's behaviour asks) and the 0410 lockdown entry.
5. Migration number 0653 was free; used as planned.
