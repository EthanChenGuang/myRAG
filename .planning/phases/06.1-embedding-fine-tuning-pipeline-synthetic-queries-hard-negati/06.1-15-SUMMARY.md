# Phase 6.1 Plan 15: rag:embedding ft-* operator commands Summary

- `cli.ts`: ten new command shapes in `ParsedEmbeddingArgs`, `isFinetuneCommand`, usage lines, and `runFinetuneCommand`. Existing commands behave as before (embedding-cli and embedding-binding-cli tests unchanged and green). `set-status` still never sets active; `activate`/`rollback` untouched.

## Deviations from Plan
1. **`--scope` flag on grant** (not in the plan's shape): needed to choose private vs deployment consent (D-27); default private.
2. **Switch injection through `main(..., deps)`**: `env` is a process snapshot, so tests pass `finetuneEnabled` and `runCommand`; production defaults read `env.RAG_FINETUNE` and spawn the command.
3. **Revoke prints `ft-release-rollback` too** when the tainted slot is the active profile's rollback target, since clear refuses `rollback_target` otherwise.
4. **No purge hook / store inventory entry**: this plan adds no store.
