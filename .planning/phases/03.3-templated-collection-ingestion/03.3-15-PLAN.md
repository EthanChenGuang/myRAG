## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin input (template text) to stored headers and, later, to embedding and lexical text | Tenant-supplied text with placeholders |
| One tenant's template and headers to another tenant | Headers carry attribute values |
| Browser clients to the route, the functions and the chunk metadata key | Admin session; service-role functions; a guarded column |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.3-1501 | Information disclosure | template or stored header read across tenants | critical | mitigate | Tenant assertion and predicate in every function; both batched-read modes tested with a foreign id; tenant-keyed cache with a two-key test; two-organization route tests |
| T-03.3-1502 | Elevation of privilege | non-admin or anon reaching the writer | high | mitigate | `checkAdminOrOrgAdmin` first; `p_actor` checked in SQL; REVOKE and GRANT; 404 while off |
| T-03.3-1503 | Tampering | template as an injection carrier | medium | mitigate | 200-character template, validated placeholders, 500-character rendered header, values whitespace-collapsed by the renderer; the header is stored apart from chunk content (plan 03.3-17 proves the text sent to the model is unchanged) |
| T-03.3-1504 | Tampering | forged chunk stamp through the metadata key | medium | mitigate | The stamp trigger fires before the update guard `rag_guard_phase33_columns` of migration 1001, which refuses the change for non-service roles; tested |
| T-03.3-1505 | Denial of service | re-rendering a large tenant inside a request | medium | mitigate | Keyset pages, a time budget with `more`, id caps on the batched read, equal values not rewritten |
| T-03.3-1506 | Information disclosure | template, header or value in logs and error bodies | medium | mitigate | Counts, version and code words only; marker-value and placeholder-secret tests |
| T-03.3-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
