## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Tenant files and live data to the repository | Tenant content, patterns, values and keys must never be committed |
| Live project to client roles | New schema on the real database |
| Live measurements to shipped thresholds | Unmeasured thresholds could remove real content |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.3-2601 | Information disclosure | tenant text, values, patterns or keys committed | high | mitigate | Files kept outside the repository; keys from the shell environment; numbers-only reports; privacy check against a terms file outside the repository before commit |
| T-03.3-2602 | Elevation of privilege | new functions or tables reachable by clients on the real project | high | mitigate | Anon and authenticated calls on every function and table, recorded with status codes |
| T-03.3-2603 | Tampering | cleaning thresholds removing real content | medium | mitigate | Residue measured with false-removal counts before trust; not_trusted keeps rules-only cleaning for the import and hands the numbers to a follow-up |
| T-03.3-2604 | Denial of service | trigger cost or id-list size slowing bulk writes or searches | medium | mitigate | A2 and A3 measured against pre-stated limits; fallbacks named in hand-offs |
| T-03.3-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
