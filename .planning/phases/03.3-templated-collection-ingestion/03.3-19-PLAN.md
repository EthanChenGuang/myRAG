## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Query text and explicit filter to the set of searched documents | Caller input narrows, or tries to widen, what retrieval reads |
| One tenant's attribute values to another tenant's request, and to traces, logs and cache keys | The lexicon and the resolved ids are tenant data; values must not leave the tenant through diagnostics |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.3-1901 | Information disclosure | another tenant's values or documents reached through resolution | critical | mitigate | Scope only from the request; resolver and cache keyed by `scopeKey`; two-tenant end-to-end test in both modes |
| T-03.3-1902 | Elevation of privilege | an explicit filter widened by fallback, by an unknown key or by a resolver failure | high | mitigate | The fallback drops automatic ids only; an unknown key matches nothing; a failure with an explicit filter fails the request; tested |
| T-03.3-1903 | Information disclosure | values or query text in stage detail, counts, trace, logs or the hash | medium | mitigate | Counts, flags and fixed codes; a digest in the hash; planted-value assertions and the hot-path log test |
