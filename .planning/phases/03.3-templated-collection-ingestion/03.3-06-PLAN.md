Both read `rules.hits[line.trim()]` and nothing else to decide what a heading is.
    - Allowed headings only: a document with three hit lines gives three sections whose `section_path` holds the canonical names of the hits, nested by level as `splitSections` nests Markdown headings (a hit of level L closes every open level at or below L). A Markdown heading line that is not a hit stays in the body of the current section unchanged; a hit line may be a plain line or a Markdown heading line, the key is its trimmed text either way.
    - Lines inside a fenced block and table rows are never headings, even when their trimmed text is a hit key. Text before the first hit is one section with an empty path.
    - Variants: with a restart-flagged hit occurring twice, the first occurrence starts variant 1 and the second variant 2; each occurrence resets the heading stack; every section from the first occurrence on has the variant label as the first path element, and every chunk of it has `metadata.variant_index` (1-based integer) and `metadata.variant_label`. Text before the first occurrence has neither. With the restart heading occurring once or never, no path gets a variant element and no chunk gets the two keys.
    - Variant label: the trimmed text of the occurrence line without Markdown heading marks, cut to 80 characters; when two variants of one document would get the same label, every label of the document gets a space and its index appended. Deterministic for equal input.
    - Table-of-contents runs (`skip_toc` true, `toc_min_run` K, default 3): K or more consecutive hit lines with only blank lines between them open no section and add no text, except the last line of the run, which opens its section; hits inside a skipped run do not count as restart occurrences. A run of fewer than K lines is kept; a run in which every line is deeper than the line before it is kept (a heading chain); with `skip_toc` false nothing is skipped.
    - Packing: each section goes through `chunkTableSection` with its path, so a section over the token budget splits into several chunks with the same path, a table inside a section is cut by whole rows with its header, and packer warnings are returned. Every chunk has `page_start` and `page_end` null.
    - Rule data with an empty `hits` map (or absent): the whole document is one section with an empty path and the result carries the warning `rule_sections_without_rules`.
    - The header-carry transform of `carryTableHeaders` applied before the chunker gives the same sections and paths as without it (hits are keyed by text, not by line index).
    - Pure: equal input gives deeply equal output; the input rules object is not mutated; the module has no regular-expression constructor call and no import from `src/lib/rag/patterns` or `src/lib/rag/identifiers`.
  </behavior>
