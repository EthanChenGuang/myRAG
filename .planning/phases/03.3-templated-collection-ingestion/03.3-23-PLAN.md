Make the fixture database reflect each Phase 3.3 switch that a run config turns on, then run every `tpl-*` configuration in both fixture modes and record the results.
Purpose: TPL-09 and the eval side of TPL-01, -02, -05, -06 and -07 (D-36). The gates of plan 03.3-22 measure the features only if the fixture tenant holds what a deployment would hold. Plan 03.3-25 runs the official comparison.
