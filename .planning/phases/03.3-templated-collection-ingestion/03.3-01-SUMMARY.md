# Phase 3.3 Plan 01: Contracts Summary

## Performance

- Ten new top-level models are exported with default and full samples. `npm run gen:schemas` leaves no diff.

## Contract reference (for plans 03.3-02 to 03.3-22)

Import from `rag_sidecar.contracts.templated` (also re-exported from `rag_sidecar.contracts`). The Zod names are `<Model>Schema` in `src/lib/rag-eval/contracts.generated.ts`.

Constants: `MAX_SECTION_RULE_SETS=10`, `MAX_BOILERPLATE_RULES=40`, `MAX_HEADING_PATTERNS=60`, `MAX_ATTRIBUTE_DEFINITIONS=30`, `MAX_ATTRIBUTE_VALUE_LENGTH=200`, `MAX_ATTRIBUTE_LIST_VALUES=50`, `MAX_HEADER_TEMPLATE_LENGTH=200`, `ATTRIBUTE_KEY_PATTERN=^[a-z][a-z0-9_]{0,39}$`, `SECTION_HITS_MAX=5000`, `SECTION_HIT_LINE_MAX_LENGTH=1000`.

| Model / type | Fields and limits |
| --- | --- |
| `HeadingPattern` | `pattern` 1..200, `flags` `u`\|`iu` (default `u`), `name` 1..80, `level` 1..6, `required` false, `restart` false; back-reference rejected |
| `SectionRuleSet` (validation) | `name` 1..80; `doc_type` (DocType) and `source` optional, omitted when unset; `enabled` true; `headings` 1..60 with unique `pattern`; `require_increasing_numbers` false; `skip_toc` true; `toc_min_run` 2..20 (default 3) |
| `SectionHeadingHit` | `name` 1..80, `level` 1..6, `restart` false |
| `ResolvedSectionRules` | `rule_set_id` (lower-case UUID), `version` >= 1, `skip_toc` true, `toc_min_run` 2..20 (default 3), `hits`: map of trimmed line text (1..1000 chars) to `SectionHeadingHit`, at most 5000 entries |
| `BoilerplateRule` (validation) | `name` 1..80, `kind` `line`\|`fragment`, optional binding `doc_type`/`source`, `enabled` true. `line`: `pattern` 1..200 and `flags` required, no back-reference, fragment numbers refused. `fragment`: `max_length` 1..200 and `min_page_share` (0, 1] required, pattern and flags refused |
| `BoilerplateRulesConfig` (validation, numbers only) | `schema_version` 1, `rules_version` >= 1, `page_share` (0,1], `edge_lines` >= 1, `max_line_tokens` >= 1, `min_pages` >= 1, `fragment_max_length` >= 1, `fragment_page_share` (0,1], `review_share` (0,1]; strict ints and floats, no extra keys |
| `BoilerplateReport` (serialization) | `cleaner_version` >= 1, `rules_version` >= 1, `lines_removed` >= 0, `tokens_removed` >= 0, `share` [0,1] |
| `AttributeDefinition` (validation) | `key` (pattern above), `type` `text`\|`text_list`\|`code`, `filterable`/`in_header`/`in_identifier_index`/`soft` default false; `in_identifier_index` only with `code` |
| `AttributeSchema` (validation) | `definitions` 0..30, unique keys |
| `AttributeValue` / `AttributeValues` | a strict string of 1..200 characters, or a list of 1..50 unique such strings; the map holds at most 30 keys; numbers, booleans and nested objects are rejected |
| `AttributeFilter` | map of 1..30 keys to lists of 1..50 unique values of 1..200 characters |
| `AttributeImportRow` (validation) | `source_key` 1..1024, `source` optional, `attributes` (`AttributeValues`) |
| `AttributeHeaderTemplate` (validation) | `template` 1..200, `version` >= 1 |
| `AttributeFilterConfig` (validation, numbers only) | `schema_version` 1, `rules_version` >= 1, `soft_weight` (0,1], `id_cap` >= 1 |
| `TenantRulesFile` (validation) | `schema_version` 1, `section_rule_sets` 0..10, `boilerplate_rules` 0..40, names unique within each list |

Extended models (all new fields optional and omitted while unset):
- `ingest.ChunkerKind` adds `rule_sections`. `ChunkerSettings.section_rules: ResolvedSectionRules`.
- `ingest_settings.IngestFingerprintParts.chunk_prep: ChunkPrepPart`, which holds `boilerplate` (`ChunkPrepBoilerplatePart`: `mode` `detect`\|`rules`\|`both`, `cleaner_version`, `rules_version`, `rule_fingerprint` 64 hex characters) and/or `section_rules` (`ChunkPrepSectionRulesPart`: `rule_set_id`, `version`). Ints are strict, and at least one sub-part is required. `FingerprintSwitches` and `FingerprintPartName` are unchanged.
- `languages.LanguageRegistry.quantity: QuantityNotation`: `unit_symbols` 1..200 unique, each 1..8 characters with no whitespace and no digit; `decimal_separators` and `grouping_separators` each 1..4 unique single non-digit characters. One character may appear in both lists.
- `parse_eval.BackfillManifestEntry.attributes: AttributeValues`.
- `retrieval.RetrievalFilters.attributes: AttributeFilter`.
- `golden.Category` adds `templated_collection`.
- `eval_run.TraceAttributeFilter`: `mode` `hard`\|`soft`, `explicit` bool, `matched_attributes` >= 0, `resolved_documents` >= 0, `applied`, `fallback`, `too_broad` bool. It holds no key or value text. `RagTrace.attribute_filter` uses it, and `TraceKeptChunk.variant_index` is >= 0.
- `report.SliceMetrics`: `boilerplate_token_share`, `named_document_recall`, `wrong_document_at_1`, `variant_accuracy`, `quantity_match_rate`, `attribute_filter_fallback_rate` (MetricValue). `report.ItemResult`: `named_document_hit`, `wrong_document_at_1`, `variant_correct`, `quantity_matched`, `attribute_filter_fallback` (bool).

Sample variants added: `<Model>:full` for each of the ten new models, plus `RagTrace:phase33`, `EvalReport:phase33`, `GoldenItem:templated_collection`, `LanguageRegistry:quantity`, `IngestFingerprintParts:chunk_prep`, `RetrievalFilters:attributes` and `BackfillManifestEntry:attributes`.

## Deviations from Plan
- **Golden "answerable or not".** The existing rule allows only `no_answer` and `small_talk` to be unanswerable, so `templated_collection` is answerable-only. Relaxing that rule would change the shared rule for every category. The test asserts this behaviour.
- **`BoilerplateRulesConfig.min_pages`.** One extra numbers-only field, the minimum page count for `detect`. Without it, a one-page document would make every edge line repeat on 100% of pages.
- **No type fallout.** `tsc` was clean without touching any exhaustive map, and the `run_config_hash` normaliser needed no change: the smoke runs show zero paired differences.
