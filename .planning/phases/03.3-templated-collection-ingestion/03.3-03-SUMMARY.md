# Phase 3.3 Plan 03: Schema 1001 Summary

Migration `1001_phase33_schema.sql` creates the five Phase 3.3 tenant tables and five nullable document/chunk columns, reachable only by `service_role`, tenant-bound by the shared 0853 guard, limited by CHECK constraints, idempotent, and defining no function.

## Schema reference (for plans 07, 08, 10, 11, 15, 18, 24)

Every table: `ENABLE ROW LEVEL SECURITY`, no policy, `REVOKE ALL ... FROM PUBLIC, anon, authenticated`, `GRANT SELECT, INSERT, UPDATE, DELETE ... TO service_role`, trigger `<table>_tenant_key_guard` `BEFORE INSERT OR UPDATE OF tenant_key` executing `public.rag_row_tenant_key_guard()` (raises 22023 for a malformed key or a key of the other deployment mode). Audit columns `created_by` / `updated_by` are `uuid REFERENCES auth.users (id) ON DELETE SET NULL`, nullable; `created_at` / `updated_at` are `timestamptz NOT NULL DEFAULT now()`.

### public.rag_section_rule_sets
| Column | Type | Null / default |
|---|---|---|
| id | uuid PK | `gen_random_uuid()` |
| tenant_key | text | NOT NULL |
| name | text | NOT NULL |
| doc_type | text | null |
| source | text | null |
| enabled | boolean | NOT NULL DEFAULT true |
| rules | jsonb | NOT NULL |
| version | integer | NOT NULL DEFAULT 1 |
| created_by, created_at, updated_by, updated_at | | audit |

Constraints: `rag_section_rule_sets_name_check` (btrim length >= 1, length <= 80); `rag_section_rule_sets_doc_type_check` and `rag_section_rule_sets_source_check` (null or `^[a-z][a-z0-9_-]{0,63}$`); `rag_section_rule_sets_rules_check` (rules is an object whose `headings` is an array of 1..60 entries); `rag_section_rule_sets_version_check` (>= 1); `rag_section_rule_sets_tenant_name_ux` UNIQUE (tenant_key, name). Index `rag_section_rule_sets_enabled_binding_ux`: UNIQUE (tenant_key, COALESCE(doc_type,''), COALESCE(source,'')) WHERE enabled.

### public.rag_boilerplate_rules
Columns: id uuid PK, tenant_key text NOT NULL, name text NOT NULL, kind text NOT NULL, pattern text null, flags text null (no default), max_length integer null, min_page_share double precision null, doc_type text null, source text null, enabled boolean NOT NULL DEFAULT true, version integer NOT NULL DEFAULT 1, audit columns.
Constraints: `rag_boilerplate_rules_name_check` (1..80, not blank); `rag_boilerplate_rules_kind_check` (`line`, `fragment`); `rag_boilerplate_rules_shape_check` (line: pattern 1..200, flags `u`|`iu`, both numbers null; fragment: pattern and flags null, max_length 1..200, 0 < min_page_share <= 1); `rag_boilerplate_rules_doc_type_check`, `rag_boilerplate_rules_source_check` (as above); `rag_boilerplate_rules_version_check`; `rag_boilerplate_rules_tenant_name_ux` UNIQUE (tenant_key, name).

### public.rag_attribute_definitions
Columns: id uuid PK, tenant_key text NOT NULL, key text NOT NULL, type text NOT NULL, filterable / in_header / in_identifier_index / soft boolean NOT NULL DEFAULT false, audit columns.
Constraints: `rag_attribute_definitions_key_check` (`^[a-z][a-z0-9_]{0,39}$`); `rag_attribute_definitions_type_check` (`text`, `text_list`, `code`); `rag_attribute_definitions_identifier_index_check` (in_identifier_index only on `code`); `rag_attribute_definitions_tenant_key_ux` UNIQUE (tenant_key, key).

### public.rag_attribute_header_templates
Columns: tenant_key text PK, template text NOT NULL, version integer NOT NULL DEFAULT 1, updated_by uuid null, updated_at timestamptz NOT NULL DEFAULT now().
Constraints: `rag_attribute_header_templates_template_check` (length 1..200); `rag_attribute_header_templates_version_check` (>= 1).

### public.rag_staged_attributes
Columns: tenant_key text, source text, source_key text, attributes jsonb (all NOT NULL), staged_at timestamptz NOT NULL DEFAULT now().
Constraints: `rag_staged_attributes_pkey` PRIMARY KEY (tenant_key, source, source_key); `rag_staged_attributes_source_check` (`^[a-z][a-z0-9_-]{0,63}$`); `rag_staged_attributes_source_key_check` (length 1..1024); `rag_staged_attributes_attributes_check` (object and `octet_length(attributes::text) <= 2000000`).

### Document and chunk columns
| Table | Column | Type | Check |
|---|---|---|---|
| documents | attributes | jsonb | `documents_attributes_object_check`: null or object |
| documents | attribute_header | text | none (bounded by the 200-character template and writer value limits, plan 03.3-15) |
| documents | attribute_header_stamp | text | `documents_attribute_header_stamp_check`: null or <= 64 |
| document_chunks | attributes | jsonb | `document_chunks_attributes_object_check`: null or object |
| document_chunks | attribute_header_stamp | text | `document_chunks_attribute_header_stamp_check`: null or <= 64 |

All nullable, no default. Index `document_chunks_attributes_gin` = `USING gin (attributes)` (default jsonb_ops: containment and key existence). No index on `documents.attributes` (plan 03.3-18 may add one in 1008).

### Triggers
- Five `<table>_tenant_key_guard` (above).
- `rag_guard_phase33_columns` BEFORE UPDATE on `documents` → `rag_guard_ingest_state('attributes', 'attribute_header', 'attribute_header_stamp')`; on `document_chunks` → `rag_guard_ingest_state('attributes', 'attribute_header_stamp')`. Roles other than service_role/postgres/supabase_admin get 42501 when they change these columns. Phase 3 `rag_guard_ingest_state` triggers untouched.

### Left to the writer functions
- Count limits per tenant: 10 rule sets (03.3-07), 40 boilerplate rules (03.3-07), 30 attribute definitions (03.3-08).
- Values inside jsonb: heading pattern length 1..200, flags, canonical names, levels (03.3-07); attribute values 1..200 characters, lists 1..50 unique values, at most 30 keys, unknown keys and types (03.3-08 / 03.3-11).
- Values of doc_type and source bindings (only their shape is checked here).
- Placeholder validation of the header template (03.3-08/15).
- The chunk-attributes copy trigger (1005) and the stamp metadata trigger (1006).

### Purge
No new table has a `document_id`, `chunk_id` or `lineage_id` column or a foreign key to documents, document_chunks or document_parents; the new document/chunk columns go with their rows. No purge hook added here; plan 03.3-24 (or the D-35 hook `rag_purge_hook_doc_attributes`) covers nulling columns and staged rows.
