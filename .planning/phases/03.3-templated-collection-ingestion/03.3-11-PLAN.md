<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Upload form field and manifest file to the pipeline | Untrusted keys and values |
| One tenant's values, staged rows and documents to another tenant | Values are tenant data on a filterable column |
| Browser clients to the tables and functions; values to logs and job snapshots | The new columns sit on tables that owners may update |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
