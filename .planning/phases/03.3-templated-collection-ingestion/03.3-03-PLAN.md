<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PostgREST clients (anon, authenticated) to the five tables | Tenant rule data and staged values are service-role only |
| A signed-in user to the new document and chunk columns | The table update policies decide rows, not columns |
| One tenant's rows to another tenant | Every table is keyed by tenant_key |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.3-09 | Information disclosure | rule sets, definitions, templates or staged values read by anon or authenticated | high | mitigate | RLS on with no policy and all privileges revoked from the three roles; role tests on every table in both modes |
| T-03.3-10 | Tampering | a tenant key of the other deployment mode or a malformed key in a new table | high | mitigate | `rag_row_tenant_key_guard` on insert and on update of tenant_key; tested per mode |
| T-03.3-11 | Tampering | a signed-in user sets attributes or the header stamp on own rows, bypassing schema validation | medium | mitigate | Second BEFORE UPDATE trigger executing the existing column guard with the new column names; 42501 test for `authenticated`, pass test for the service role |
| T-03.3-12 | Denial of service | oversized rule bodies, patterns, templates or staged objects | medium | mitigate | CHECK limits of D-12 on every row; byte bound on staged objects; count limits in the writers of plans 03.3-07, 03.3-08, 03.3-11 |
| T-03.3-13 | Tampering | attributes set on a document row at insert by a signed-in user | low | accept | Attributes narrow retrieval inside the caller's own tenant and grant nothing; the unified pipeline writes rows as service role and plan 03.3-11's insert trigger overwrites the chunk value from the document; listed for the matrix of plan 03.3-24 |
| T-03.3-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
</threat_model>
