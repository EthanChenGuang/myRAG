# Phase 03.3 Plan 21: Quantity tokens end to end Summary

With `RAG_LEXICAL_QUANTITY` on, the one per-tenant lexical options resolver returns the quantity option. Ingestion, relex and the v2 query side all tokenize with it and stamp the effective version, 6 to 9. `rag:relex` moves stored chunks to that version and back, and tells the operator to recalibrate refusal. With the switch off, every row, token list and hash is the same as before this plan.
