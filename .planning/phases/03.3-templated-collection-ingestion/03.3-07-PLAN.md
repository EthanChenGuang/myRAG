<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin input (patterns, names, bindings) to storage and later execution | A stored pattern runs on every document of the binding |
| One tenant's rule data to another tenant | Rules, names and patterns are tenant data |
| PostgREST clients to the new functions | Service-role only; the actor is re-checked in SQL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.3-701 | Denial of service | catastrophic tenant pattern saved for later runs | high | mitigate | Save-time check of plan 03.3-04 (04.2-14 static checks and time-boxed probe, anchoring for headings) before any rpc; SQL and the loader never execute a pattern; caps of 60 patterns, 200 characters, 10 rule sets, 40 rules; run-time execution only in the worker (plans 03.3-10, 03.3-12) |
| T-03.3-702 | Information disclosure | rule data read or changed across tenants | critical | mitigate | Tenant assertion first and the tenant in every predicate; actor checked against `rag_upload_approval_keys`; two-tenant tests in both modes; cache keyed by the tenant key with a two-key test |
| T-03.3-703 | Elevation of privilege | functions callable by anon or a non-admin actor | high | mitigate | Invoker rights, empty search_path, REVOKE and GRANT on exact signatures; `not_admin` for writers and no rows for the lists; fake-edge test and the static scans |
| T-03.3-704 | Tampering | a row written past the service (another service-role caller) holds an unchecked pattern | medium | mitigate | The loader re-checks stored patterns statically and skips failures; execution is worker-only with a deadline |
| T-03.3-705 | Information disclosure | patterns, names or database messages in errors and logs | medium | mitigate | Failures carry code words, indexes and finding codes only; unknown database errors become `unavailable`; marker tests |
| T-03.3-706 | Denial of service | unbounded rule rows per tenant | low | mitigate | Limits under an advisory lock, tested at the 11th and 41st row and with parallel inserts |
| T-03.3-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed |
</threat_model>
