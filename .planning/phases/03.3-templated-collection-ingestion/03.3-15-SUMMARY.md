## Stamp and rendering

- Stamp: `t<template version>.` + first 12 hex characters of `sha256(canonicalJson(row))`, where `row` maps every placeholder name of the
  template to its rendered value (a list joined with the separator) or `null`. Metadata key constant `ATTRIBUTE_HEADER_STAMP_KEY =
  'attribute_header_stamp'`, clearing value `ATTRIBUTE_HEADER_STAMP_NONE = 'none'` (plan 03.3-17 writes these on chunks).
- Separator: `headerListSeparator()` = the primary language pack's `list_separator` (`getLanguageSettings().primary`), else the `en` pack,
  else `', '`.
- Rendering: `renderTemplateHeader` per `|` segment (a segment with a missing value is left out, whitespace collapsed); segments joined with
  ` | `; trailing segments dropped while longer than 500 characters; never throws (any renderer throw gives `''`).

## Route `/api/rag/admin/attribute-header`

`export const runtime = 'nodejs'`; every answer `Cache-Control: no-store`; while `attributeHeaderEnabled()` is false every method answers 404
`{ success: false, error: 'Not found' }` before any session lookup or rpc. Guard: `admit(request)` from `_tenant-data/lib.ts`
(`?organizationId=`, `checkAdminOrOrgAdmin`, admission); the tenant key and actor come only from it. Bodies are `.strict()`.

- GET → 200 `{ success: true, template: string | null, version: number (0 without one), placeholders: string[] (in_header keys, key order), limits: { max_template_length: 200 }, stale: { count, more } }` (stale page of 200).
- PUT `{ template: string (1..200) | null }` → 200 `{ success: true, template, version, rerendered, more }` after `renderPendingHeaders` with
  `RERENDER_BUDGET_MS = 20_000`. 201 characters or extra fields → 400 `Invalid request data`; unknown placeholder → 400
  `{ success: false, error: 'unknown_placeholder', details: [{ path: 'template', message: <name> }] }`.
- POST `{ action: 'render' }` → 200 `{ success: true, rerendered, more }`.
- Other words: `not_admin` 403 `Forbidden`, `invalid_argument` 400 `Invalid request`, anything else 503
  `Tenant rule administration is unavailable` (no database message). Logs: `[RAG Admin]` with version and counts only.

## Deviations

- Plan text says the floor version after a removal comes from "a stamp of that tenant's documents"; it also scans the tenant's chunk stamps
  (stricter: an old chunk stamp can never look current). Documented above.
- `renderPendingHeaders` accepts `null` for its client and then uses the ingest deps' service-role client, so the route imports only from
  `@/lib/rag`, `@/lib/admin-route-auth` (through the shared helper) and `_tenant-data/lib.ts`.
- `rag_attribute_headers` returns `(document_id, chunk_id, header, stamp)` in both modes (chunk mode also gives the document id and stamp).

## Deferred / known limits

- If the header write fails after an import batch already committed its values, rerunning the same file finds the rows unchanged and does
  not re-render; the stamp of those documents keeps the old hash with the current version, so neither the pending nor the stale listing
  names them. Recovery today: change the template (version bump re-renders all). Plan 03.3-23/17 may add a hash check (owner note).
- Rebuild of chunks after a header change is plan 03.3-17/23 (`rechunk` classification, D-27).
