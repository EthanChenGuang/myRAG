<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tenant heading patterns to the ingestion process | JavaScript has no regex timeout; the patterns run on every document of the binding |
| One tenant's rule set to another tenant's documents | Rule sets are loaded per tenant and binding; re-chunk walks several tenants in one run |
| Rule data to stored chunk structure | Hit data decides section paths and variant labels that reach embedding and lexical text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.3-1201 | Denial of service | tenant heading pattern at ingestion | high | mitigate | One wrapper call per document (worker with a deadline, match window, anchored match); a timeout flags the document and the profile's chunker is used; no expression is built in this plan (acceptance gate) |
| T-03.3-1202 | Information disclosure | a rule set applied across tenants | critical | mitigate | Loader keyed by the minted scope's tenant key and the document's binding; re-chunk resolves the scope per document tenant; two-tenant tests in both modes |
| T-03.3-1203 | Tampering | a rule set that fits a document badly drops or mislabels content | high | mitigate | Conformance check before selection; fallback to the profile's chunker with a review flag; sections keep every body line (a heading that is not allowed stays as text); `parse.md` untouched, so re-chunk repairs |
| T-03.3-1204 | Tampering | resumed run cut by edited rules, giving a chunk count mismatch | medium | mitigate | Snapshot of hits, rule set id, version and verdict; resume test with an edit between yield and resume |
| T-03.3-1205 | Information disclosure | heading names or patterns in logs, warnings, review reasons or stage notes | medium | mitigate | Fixed code words and integer counts only; console-spy tests with marker text |
| T-03.3-1206 | Denial of service | hit map too large for the saved state | low | mitigate | Contract caps on the map; over the cap the profile's chunker is used and the document is flagged |
| T-03.3-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed |
</threat_model>
