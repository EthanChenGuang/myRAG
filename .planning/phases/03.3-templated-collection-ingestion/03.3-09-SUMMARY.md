## For plan 03.3-21 (wiring)

- Option shape: `LexicalOptions.quantity?: boolean | { unitAliases?: Readonly<Record<string, string>> } | null`. Pass it only while `V2Config.lexicalQuantity` is on, the same way `dictionary` is passed.
- `unitAliases` maps a tenant word to a symbol of the shipped table (for example `{ "<tenant word>": "g" }`). Keys are folded like the tokenizer (NFKC, lower case, accents removed) and trimmed; an alias whose symbol is not in the table, an alias longer than 64 characters, or an alias that spells a shipped symbol is ignored. The table built for one `unitAliases` object is cached in a `WeakMap` keyed by that object, so build the alias object once per TERM version and reuse it.
- Index order: natural tokens (stems interleaved as before), then dictionary tokens, then quantity tokens, one per occurrence.
- Query order: the leading additive group is dictionary, quantity, stem, deduplicated, at most `MAX_ADDITIVE_QUERY_TOKENS = 16`; then natural tokens up to 64.
- `identifierLexicalLookupForms` never returns a `_q_` token (it keeps only the whole and joined forms).
- Version: the +4 bit of `lexicalVersionFor(dictionary, stemIt, quantity)` from 03.3-02 stamps the switch; `LEXICAL_VERSION` stays 2 and every `pack_version` stays 1.

## Grammar as implemented

- A number is a maximal run of digits and separator characters that starts with a digit, is at most 24 characters long, does not end in a separator and is not directly preceded by a non-Han letter.
- After optional horizontal whitespace (space, tab, U+00A0, U+2009, U+202F), the longest table key at that position is the unit; the next character must not be a non-Han letter (end of text, punctuation, digits and Han characters are boundaries).
- Readings: decimal (last separator in `decimal_separators`, earlier separators one grouping character) and grouped (all separators the same grouping character, first group 1..3 digits not starting with 0, then groups of exactly 3). Both valid only for one separator before exactly three digits; the decimal reading is emitted first.
- Canonical number: grouping removed, decimal point, trailing fraction zeros and a trailing point removed, leading zeros reduced to one digit.

## Registry block (both copies byte-identical)

- `unit_symbols` (74): `m km cm mm dm μm nm`, `g kg mg μg t`, `l ml cl dl hl μl`, `s ms μs ns min h`, `°c °f k`, `ma ka μa v mv kv μv w mw kw gw wh kwh mwh gwh ω kω mω ah mah hz khz mhz ghz f μf nf pf`, `b kb mb gb tb pb kib mib gib tib bit kbit mbit gbit bps kbps mbps gbps`, `%`. Stored in NFKC lower case (`µ` and `Ω` inputs normalise to `μ` and `ω`).
- Dropped as a stop-word collision: `a` (ampere; an English lexical stop word).
- Not shipped: `m²`/`m³` (NFKC turns them into `m2`/`m3`, and the contract refuses digits).
- `decimal_separators`: `.` `,`; `grouping_separators`: `.` `,` `'`.

## Deviations

- **Han boundary.** D-31 says the character after the unit (and before the number) must not be a letter. Han characters are treated as boundaries, because Chinese text has no spaces (`星2.5kg蓝` gives `_q_2.5kg`). Latin letters still block (`5 kgx`, `zento5 kg` give nothing).
- **Apostrophe as a grouping separator** (`1'250 g` gives `_q_1250g`); the contract allows it and the canonical token contains no apostrophe.
- **Duplicate symbol** in a table makes `buildQuantityUnits` throw (naming the index), in addition to the whitespace, quote, backslash and digit rule.
- The 64-character token limit cannot trigger with the shipped limits (prefix 3 + number 24 + symbol 8); the check stays as a guard.
