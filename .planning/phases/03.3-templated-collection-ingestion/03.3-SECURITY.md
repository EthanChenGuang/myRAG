## Hardening notes (threats stay CLOSED)

- F-3 (low): the `rag:rules` export guard compares against `process.cwd()` and doesn't resolve symlinks (`src/lib/rag/ingest/rules/transfer.ts:323-326`, `cli.ts:147`). Fix: compare `realpath(dirname(out))` with the realpath of the repository root.
- F-4 (low): 03.3-25 changes quantity tokens inside lexical versions 6–9 without a version bump. This only matters for a deployment that turned `RAG_LEXICAL_QUANTITY` on before the merge. Such a deployment runs `npm run rag:relex`, then `python -m rag_eval.calibrate refusal`, then `POST /api/rag/admin/semantic-cache`.
- F-5 (info): the Config UI help for `RAG_ATTRIBUTE_FILTER=off` says it "ignores attributes", but the API answers 400. The contract's `source` regex is wider than the SQL binding regex; SQL answers 22023, which surfaces as a 400.
