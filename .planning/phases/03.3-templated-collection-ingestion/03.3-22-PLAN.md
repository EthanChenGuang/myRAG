- The comparison tool compares every run with the committed baseline of its mode. - Plan 03.3-02 says layering the ingestion-side switches into the fixture build is plan 03.3-22; PLAN-INDEX gives harness seeding to 03.3-23 and this plan builds no fixture database, so 03.3-23 does it. No `phase42_gate.py` is on trunk: the tool follows `defaults_gate.py` (PATTERNS item 10).
