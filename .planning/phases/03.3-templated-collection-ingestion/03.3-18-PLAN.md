## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Request body (`retrievalFilters.attributes`) and query text to the resolver | Caller-controlled keys, values and text select documents |
| One tenant's values and ids to another tenant; PostgREST clients to the two new functions | Values, ids and the cached lexicon are tenant data; the functions are service-role only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.3-1801 | Information disclosure | values or ids across tenants, or of superseded and non-ready documents (SQL, lexicon cache) | critical | mitigate | Tenant assertion, tenant predicate and current-and-ready predicate in both functions; cache keyed by `scopeKey`; two-tenant tests in both modes; two-key cache test |
| T-03.3-1802 | Elevation of privilege | functions callable by anon or authenticated | high | mitigate | INVOKER, empty search_path, REVOKE and GRANT; fake-edge test and the static scans |
