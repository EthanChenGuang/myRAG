## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tenant dictionary (unit aliases) to the lexical text and query tokens of that tenant | Admin-authored words become index and query tokens |
| The relex command to stored chunks of every tenant | An operator run rewrites lexical text in bulk |
| A tokenizer change to calibrated refusal thresholds and cached answers | Both are keyed by the tokenizer version |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
