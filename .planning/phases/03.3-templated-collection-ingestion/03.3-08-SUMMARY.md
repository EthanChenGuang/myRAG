## SQL reference (1003)

All `SECURITY INVOKER`, `SET search_path = ''`, `PERFORM public.rag_assert_tenant_key(p_tenant_key)` first, tenant in every predicate, `REVOKE ALL … FROM PUBLIC, anon, authenticated`, `GRANT EXECUTE … TO service_role`. Admin = `p_tenant_key = ANY (public.rag_upload_approval_keys(p_actor))`.

| Function | Returns | Notes |
|---|---|---|
| `rag_attribute_definitions_list(p_actor uuid, p_tenant_key text)` | `TABLE(key, type, filterable, in_header, in_identifier_index, soft, updated_at timestamptz)` | key order (`COLLATE "C"`); no rows for a non-admin or NULL actor |
| `rag_attribute_definitions_for(p_tenant_key text)` | `TABLE(key, type, filterable, in_header, in_identifier_index, soft)` | the pipeline's read; no actor |
| `rag_attribute_definition_upsert(p_actor uuid, p_tenant_key text, p_key text, p_type text, p_filterable boolean, p_in_header boolean, p_in_identifier_index boolean, p_soft boolean)` | same row shape as list | new key: count < 30 under `pg_advisory_xact_lock(hashtextextended('rag_attribute_definitions|' || tenant, 0))`; existing key: flags only, type immutable |
| `rag_attribute_definition_delete(p_actor uuid, p_tenant_key text, p_key text)` | `text` (the deleted key) | |

Refusal words (first in the message): `invalid_argument` (22023: key outside `^[a-z][a-z0-9_]{0,39}$`, type outside text/text_list/code, NULL flag), `not_admin` (42501), `invalid_attribute_type` (22023: type change, or `in_identifier_index` on a non-code type), `unknown_placeholder` (2BP01), `limit_reached` (54000), `not_found` (P0002: unknown key or another tenant's key). Values of a deleted key stay on documents; later readers use only keys of the loaded schema. No purge hook: tenant settings, no document reference.

## TypeScript reference

`src/lib/rag/ingest/attributes/validate.ts` (pure; no db, clock or log):
- `ATTRIBUTE_LIMITS = { maxDefinitions: 30, maxValueLength: 200, maxListValues: 50 }`, `ATTRIBUTE_KEY_PATTERN = /^[a-z][a-z0-9_]{0,39}$/`
- `type AttributeErrorCode = 'unknown_attribute' | 'invalid_attribute_type' | 'too_many_values' | 'value_too_long'`
- `interface AttributeError { key: string; code: AttributeErrorCode; index?: number }`
- `validateAttributes(definitions: readonly AttributeDefinition[], raw: unknown): { ok: true; values: IngestAttributeValues } | { ok: false; errors: AttributeError[] }`
  - text/code: string, trimmed, 1..200 code points; text_list: array of 1..50 distinct trimmed strings, order kept.
  - Non-plain-object input → `[{ key: '', code: 'invalid_attribute_type' }]`. Errors in input key order, then index. Accepted keys sorted (code-unit order). Empty object valid.

`src/lib/rag/ingest/attributes/schema.ts`:
- `docAttributesEnabled(config = currentIngestConfig()): boolean` → `config.docAttributes`.
- `AttributeAdminInput { actorUserId; tenantKey; signal }`; `AttributeDefinitionInput { key; type; filterable?; in_header?; in_identifier_index?; soft? }` (flags default false).
- `listAttributeDefinitions(input)` → `{ ok: true; items: AttributeDefinitionEntry[] } | AttributeAdminError`
- `upsertAttributeDefinition(input, definition)` → `{ ok: true; item: AttributeDefinitionEntry } | AttributeAdminError`
- `deleteAttributeDefinition(input, key)` → `{ ok: true; key } | AttributeAdminError`
- `AttributeDefinitionEntry = AttributeDefinition & { updatedAt: string /* ISO */ }`
- `AttributeAdminFailure = 'not_admin' | 'not_found' | 'limit_reached' | 'invalid_attribute_type' | 'unknown_placeholder' | 'invalid_argument' | 'unavailable'`. Pre-checks (actor UUID, tenant key shape, key pattern, type, boolean flags, code-only identifier flag) run before any db call. Unknown database errors → `unavailable`; logs carry rpc name and code only.
- `loadAttributeSchema(scope: TenantScope, { signal, fresh? })` → `{ ok: true; definitions: readonly AttributeDefinition[] } | { ok: false; reason: 'unavailable' }` (frozen). Cache keyed by `scopeKey(scope).toLowerCase()` only: LRU 256 tenants, 60 s TTL, 5 s after a failure, `fresh: true` bypasses, successful upsert/delete invalidates only that tenant (generation counter). Malformed rows → `unavailable`.
- `resetAttributeSchemaCacheForTests()`.
- Not yet exported from `@/lib/rag`: plan 03.3-14 owns the barrel.
