## Exported signatures (for plan 03.3-10)

`src/lib/rag/ingest/prepare/boilerplate-config.ts`
- `boilerplateConfig(): BoilerplateRulesConfig`: parsed once, and the same object on later calls.
- `setBoilerplateConfigForTests(raw: unknown | null): void`: validates and installs an override; `null` removes it.

`src/lib/rag/ingest/prepare/page-lines.ts`
- `lineKey(text: string): string`: applies NFKC, collapses whitespace runs to one space, trims, then replaces each `\p{Nd}+` run with `0`.
- `interface PageLines { pageCount: number; pages: Array<{ page: number; keys: string[] }> }`
- `readPageLines(raw: unknown): PageLines | null`. For docling (`texts[]`), it reads items whose `content_layer` is absent or `body`, takes the page from `prov[0].page_no`, splits text at line breaks and keeps non-empty keys in `texts` order. `pageCount` is `max(pages entries, pages with keys)`, or the highest page seen when there is no `pages`. For per-page text (`pages: [{ page, text }]`), a page with empty text stays with no keys. Caps: `PAGE_LINES_MAX_PAGES` 10000 and `PAGE_LINES_MAX_KEYS_PER_PAGE` 5000.

`src/lib/rag/ingest/prepare/boilerplate.ts`
- `CLEANER_VERSION = 1`, `BOILERPLATE_PAGES_UNAVAILABLE = 'boilerplate_pages_unavailable'`
- `type BoilerplateMode = 'detect' | 'rules' | 'both'`
- `interface BoilerplateFragmentRule { max_length: number; min_page_share: number }`: the fields of a `BoilerplateRule` of kind `fragment`.
- `cleanBoilerplate({ markdown, pageLines, mode, config?, lineHits?, fragmentRules?, protectedLines? }): { markdown, removal, report, aboveReviewShare, warnings }`. `config` defaults to `boilerplateConfig()`. `lineHits` and `protectedLines` take a `Set<string>` or a `string[]` of line texts, compared trimmed.
- `replayRemoval(markdown, removal, protectedLines = [], config = boilerplateConfig()): { markdown, report, aboveReviewShare }`
- `removalTextMap(removal, protectedLines = []): (text: string) => string`
- `lineDigest(text: string): string`: the first 16 hex characters of the SHA-256 of `text.trim()`.

**Removal record:** `interface BoilerplateRemoval { keys: string[]; lineDigests: string[] }`. Both lists are sorted and hold only entries that removed at least one line. `keys` are `lineKey` values removed by detect or the fragment rule. `lineDigests` are `lineDigest` values of the line hits, so the record holds no tenant-matched text.

**Behaviour notes:**
- Protection beats every rule: fence lines and lines inside a fence (tracked the same way as `splitSections`), table rows (`trim().startsWith('|')`), headings with a non-empty title, and the protected set.
- When fewer than `min_pages` pages exist, detect and the fragment rule do nothing.
- The warning `boilerplate_pages_unavailable` is emitted once when `pageLines` is null and detect or a fragment rule would have run. Line hits still apply.
- With nothing removed, the cleaner returns the input string itself.
- `share` is removed tokens divided by input tokens, rounded to four decimals.
- `aboveReviewShare` is `share > review_share` and is not part of the report.

## Deviations

- **Docling page count:** it is `max(pages entries, pages with keys)`, not the bare entry count. This keeps a share from going above 1 when a `pages` map is incomplete. On the recorded fixture the result is the same.
- **Document edges:** they count as blank for the blank-line repair. A removed last line also drops the line break that comes before it. Without this, cleaned output would start or end with stray blank lines.

## Observations for the coordinator
