<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to the feedback route | vote, reasons, comment and chatId are user input |
| Admin tooling to the review route | flagged records leave the database for reviewers |
| App to Langfuse | masked copies and scores leave the deployment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-64 | Tampering | feedback on another user's answer | high | mitigate | record lookup by id and session user; identical 404; tested |
| T-05-65 | Spoofing | injecting query or answer text into the review queue | medium | mitigate | the schema has no query or answer field; review text is read from the caller's own chat row (D-19) |
| T-05-66 | Information disclosure | PII in comments, review copies and admin items | high | mitigate | maskPII on comments, review content and admin items; log lines carry codes and counts only |
| T-05-67 | Tampering | CSRF on the feedback POST | medium | mitigate | JSON content type required; SameSite session cookies; no CORS headers added |
| T-05-68 | Denial of service | feedback flood | low | accept | one changeable vote per answer (an update, not new rows); session required; 500-character comment cap |
| T-05-69 | Elevation of privilege | review route without admin | high | mitigate | S7 guard first; forged cookie, literal bearer and non-admin cases tested |
| T-05-SC | Tampering | npm/pip/cargo installs | high | accept | this plan installs no package |
</threat_model>
