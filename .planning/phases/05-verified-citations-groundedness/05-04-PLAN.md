<objective>
Expose the final context blocks as structured data and add an optional labeler hook to the legacy and v2 renderers, so citation aliases are assigned after the last context step in render order without changing the context when citations are off.

Purpose: D-02 makes the citable unit the final context block and requires aliases after rerank, ordering, merge, compression and budget, with no reordering afterwards. Research Pattern 1: build blocks as data before any string, then derive the labelled context, the AliasMap and the Claude file parts from the same list. GEN-07: without a labeler nothing changes.
Output: additive types, blocks from both renderers and the refs path, the labeler hook, tests.

Runs after Phase 4 and Phase 3.1 are complete. Relies on: plans 04-01 (types.ts additions), 04-12 (assemble.ts helpers), 04-19 and 04-27 (v2 context stage group with parent expansion), 03-20 (refs resolver). Rollout position: D-26 step 2. Execution note: this plan runs PGlite-backed differential tests; do not run it at the same time as plan 05-06 in one working tree (`workflow.use_worktrees` is false).

Commit rule for every task: plain `git commit`; the message ends with the attribution lines the executor's own session supplies; never copy them from a plan.
</objective>
