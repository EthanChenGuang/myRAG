<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to chat/media/LiveKit routes | Body organizationId is untrusted |
| Third-party page to embed route | Body is untrusted; only server config names the tenant |
| Voice agent to internal routes | Agent forwards a token it cannot forge |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-21 | Elevation of privilege | forged organizationId | critical | mitigate | organization_members check for the session user; 403 for non-members and malformed ids; 503 on query error (fail closed) |
| T-02-22 | Spoofing | embed workspace override | high | mitigate | scope only from RAG_EMBED_TENANT; raw-body workspace keys that differ get 403; unconfigured multi-tenant fails closed |
| T-02-23 | Spoofing | forged or replayed voice token | critical | mitigate | HMAC-SHA256 with >= 32-char secret, constant-time digest compare, aud/v/exp/iat checks, membership re-check at use |
| T-02-24 | Information disclosure | timing attack on token signature | medium | mitigate | timingSafeEqual over fixed-length SHA-256 digests |
| T-02-25 | Information disclosure | logs | medium | mitigate | `[RAG Tenant]` logs carry booleans and reasons only; no tokens, secrets or other tenants' ids |
| T-02-SC | Tampering | packages | low | accept | node:crypto only, no package changes |
</threat_model>
