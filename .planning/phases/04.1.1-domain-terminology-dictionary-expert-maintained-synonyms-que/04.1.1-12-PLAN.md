<objective>
Turn missed queries into a review list: a miner that proposes candidate terms per tenant and admin routes to accept (through the normal create path) or dismiss them.

Purpose: the review half of TERM-09 (D-26, PO-7). Coordination (CONTEXT D-25a, FBK-07 amendment): `rag_term_misses` is the interim miner source because this phase ships first. Phase 5.1.1 never writes `rag_term_*` tables: its expert-labelled pairs arrive as `DictionaryCandidate` JSONL through the plan-11 import (dry run, then apply). The reserved `source` values `feedback`/`langfuse` stay unused unless 5.1.1 chooses to feed this log instead.

Execution note: builds PGlite databases; do not run alongside another fixture-database plan in the same tree.
