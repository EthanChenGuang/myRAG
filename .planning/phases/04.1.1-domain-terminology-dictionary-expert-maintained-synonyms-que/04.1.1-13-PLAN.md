<objective>
Give domain experts a Config UI panel for the dictionary: browse, edit (translation pairs included), import and export, preview and review mined candidates.

Purpose: TERM-11, and the Config UI side of TERM-12 (XLG-05 asks for a glossary edited by admins in the Config UI, and it is this dictionary; D-39). This is the phase's only new UI surface and follows the frontend design pipeline (`.claude/gsd-core/references/frontend-design-pipeline.md`): `/gsd-ui-phase 04.1.1` must produce `04.1.1-UI-SPEC.md` first (Task 1 is the gate), then implementation, Impeccable critique, web-design-guidelines on every touched file, `/gsd-ui-review`, and the verifier's `node scripts/ci/check-frontend-design-summary.mjs`.

UI surfaces for the UI-SPEC: (1) Terminology section in RAG Administration (layer switch, workspace picker); (2) entry list with search and pagination; (3) entry create and edit dialog with validation issues, including the translation-pair fields (kind translation: source and target language from the enabled languages, mode fixed to one_way); (4) delete and suppress confirmations; (5) versions and audit strip; (6) CSV import flow (pick, dry-run report table, apply) and export button, with the nine CSV columns explained; (7) query preview box (matches, expansion tokens, overrides, version); (8) candidate review list (support, examples, df, accept and dismiss); (9) the three switch checkboxes added by plan 02 in the v2 retrieval card (already placed, reviewed for consistency only).

Note for `/gsd-ui-review` and the UI-SPEC: plan 02 edits `scripts/config-ui/index.html` (three checkboxes next to `RAG_LEXICAL_TRANSLATION`) before the UI-SPEC exists, following the existing control pattern; the review must cover those lines as surface 9 and any fix lands in this plan.

Content rules: UI copy and examples contain no domain content (D-37); placeholder text in fields uses neutral wording or the D-37 placeholders. No language code is written into the panel (D-35); `scripts/ci/check-language-literals.mjs` covers `scripts/` once Phase 3.2 adds it.
