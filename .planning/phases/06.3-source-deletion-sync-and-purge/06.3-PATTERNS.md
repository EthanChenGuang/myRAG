### `supabase/migrations/0723_purge_lineage.sql` (migration, transactional delete)

**Analog:** function `rag_delete_quarantined(uuid, uuid)`, **newest body** in `supabase/migrations/0425_search_path_empty.sql` (approx. lines 1100–1141). The original is in `0316_quarantine_admin.sql` (approx. line 217); do not copy that one, its search path is not empty. Re-read the newest body on trunk at execution (D-01).

**Core pattern** — tenant limited by the actor's keys, row lock, explicit chunk delete, audit insert in the same transaction, storage keys returned to the app:
```sql
CREATE OR REPLACE FUNCTION public.rag_delete_quarantined(p_document_id uuid, p_actor uuid)
 RETURNS TABLE(document_id uuid, lineage_id uuid, tenant_key text, version integer, rule_ids text[], artifact_keys text[])
 LANGUAGE plpgsql
 SECURITY DEFINER
 SET search_path TO ''
AS $function$
#variable_conflict use_column
DECLARE
  keys text[];
  doc public.documents%ROWTYPE;
  ids text[];
  stored text[];
BEGIN
  keys := public.rag_admin_tenant_keys(p_actor);
  SELECT * INTO doc FROM public.documents d WHERE d.id = p_document_id AND d.tenant_key = ANY (keys) FOR UPDATE;
  IF NOT FOUND THEN
    RAISE EXCEPTION 'not_found';
  END IF;
  ...
  stored := ARRAY(
    SELECT DISTINCT s.key FROM (
      SELECT e.value AS key
      FROM jsonb_each_text(CASE WHEN jsonb_typeof(doc.processing_state -> 'artifacts') = 'object' THEN doc.processing_state -> 'artifacts' ELSE '{}'::jsonb END) AS e
      UNION ALL
      SELECT doc.original_path
    ) AS s
    WHERE s.key IS NOT NULL AND s.key <> ''
  );

  UPDATE public.documents d SET superseded_by = NULL WHERE d.superseded_by = doc.id;
  -- The single-tenant schema has no cascade from documents to document_chunks; chunk_embeddings and gaps cascade from the chunks.
  DELETE FROM public.document_chunks c WHERE c.document_id = doc.id;
  DELETE FROM public.documents d WHERE d.id = doc.id;

  INSERT INTO public.rag_admin_audit (action, document_id, lineage_id, tenant_key, version, actor, rule_ids)
  VALUES ('delete_quarantined', doc.id, doc.lineage_id, doc.tenant_key, doc.version, p_actor, ids);

  RETURN QUERY SELECT doc.id, doc.lineage_id, doc.tenant_key, doc.version, ids, stored;
END
$function$;
```
What to copy: `#variable_conflict use_column`; every identifier schema-qualified because the search path is empty; the same word `not_found` for an unknown id and another tenant's id; `superseded_by` cleared before the delete; explicit `document_chunks` delete in both modes (D-37, C-6); the `stored` key collection (extend it to all versions of the lineage); audit insert before `RETURN`.

**Lineage-level variant and reason words** — `rag_soft_delete_document` in `supabase/migrations/0357_soft_delete.sql` (lines 6–92) is the lineage-keyed model: `(p_tenant_key, p_lineage_id, …)`, count check, `RAISE EXCEPTION 'tenant_mismatch' USING ERRCODE = '22023'`, `RETURNS TABLE (outcome text, lineage_id uuid, job_id uuid)`, idempotent `already_deleted` outcome:
```sql
  PERFORM public.rag_ingest_assert_tenant_key(p_tenant_key);

  IF p_lineage_id IS NULL THEN
    RAISE EXCEPTION 'invalid_argument' USING ERRCODE = '22023';
  END IF;
  ...
  SELECT count(*) INTO v_count
    FROM public.documents d
   WHERE d.lineage_id = p_lineage_id
     AND d.tenant_key = p_tenant_key
     AND d.source = p_source;
  IF v_count = 0 THEN
    RAISE EXCEPTION 'tenant_mismatch' USING ERRCODE = '22023';
  END IF;
```
Note for the planner: 0357 asserts with `rag_ingest_assert_tenant_key`, 0603 with `rag_assert_tenant_key` (0403, mode-specific files). D-11 says "the existing tenant-key guard"; RESEARCH Pattern 3 names `rag_assert_tenant_key`. Pick one and say which in the plan.

### `src/lib/rag/ingest/purge.ts` (service, CRUD) — the only caller of the purge RPCs

**Analog:** `src/lib/rag/ingest/quarantine-admin.ts` (`call`, `failureOf`, `deleteQuarantined`) and `src/lib/rag/ingest/soft-delete.ts` (`softDeleteLineage`).

**Imports** (`quarantine-admin.ts` lines 1–3):

**RPC call + fixed reason words** (`quarantine-admin.ts`, functions `failureOf` and `call`, lines 53–78):
```ts
const SQL_REASONS = new Set<QuarantineFailure>(['not_found', 'not_quarantined', 'not_admin']);

function failureOf(message: string | undefined): QuarantineFailure {
  const word = /^[a-z_]+/.exec(message ?? '')?.[0] as QuarantineFailure | undefined;
  return word !== undefined && SQL_REASONS.has(word) ? word : 'unavailable';
}

/** One RPC on the admin client. Only the fixed reason words of the SQL functions leave this module, never a database message. */
async function call(rpc: string, args: Record<string, unknown>, signal: AbortSignal): Promise<Call> {
  const db: RpcClient | null = getIngestDeps().db();
  if (!db) return { ok: false, reason: 'unavailable' };
  try {
    signal.throwIfAborted();
    const response = await db.rpc(rpc, args).abortSignal(signal);
    signal.throwIfAborted();
    if (response.error) {
      const reason = failureOf(response.error.message);
      if (reason === 'unavailable') console.error('[RAG Admin] quarantine call failed', { rpc, code: response.error.code ?? null });
      return { ok: false, reason };
    }
    return { ok: true, rows: (response.data ?? []) as Row[] };
  } catch (error) {
    console.error('[RAG Admin] quarantine call failed', { rpc, error: error instanceof Error ? error.name : 'unknown' });
    return { ok: false, reason: 'unavailable' };
  }
```
