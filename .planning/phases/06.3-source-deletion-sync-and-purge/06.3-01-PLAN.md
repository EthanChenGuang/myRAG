<objective>
Change the two shared contracts this phase needs before any code or SQL depends on them: the citation record can carry a withdrawn marker, and the retrieval trace can carry the stale-index drop count.

Purpose: `CitationRecord` is strict and `quote` has a minimum length of 1. Without this change the first purge that scrubs a citation makes `validCitations` drop it, and nothing shows the marker (RESEARCH C-4). D-36 requires this plan to land in an earlier wave than any code or SQL that writes the flag (06.3-10 writes it in wave 3).
Output: the two Pydantic changes, regenerated JSON Schema and Zod, samples, and the `validCitations` rule.
