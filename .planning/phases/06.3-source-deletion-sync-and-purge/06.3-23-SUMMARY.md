## Deviations

1. **One fixture database for the file, not one per case.** The fake edge and the `@/lib/supabase` singleton bind to one URL per process, so a second database would need a second process. Every case uses its own connection, provider, files, run marker and cache key, so no case sees another's rows.
2. **Generic in-sync path driven through `removeOrphans(connection, listing, 'sync', { complete })`.** `syncDocumentsForConnection` needs a live Nango client (proxy calls), which node:test cannot mock without the experimental module-mock flag. `removeOrphans` calls the same `deleteOrphanedDocuments(…, listingComplete)` that every generic caller calls; the per-caller wiring (Dropbox single and multi folder, records fallback) stays covered by 06.3-28's orphan-removal matrix.
3. **The cap is set on both `process.env` and the loaded `env` object.** `src/lib/env.ts` snapshots `process.env` at import, so setting `process.env` alone inside the case had no effect (first run: 2 purged). Both are restored in `t.after`.
4. **`confirmReconcileRun` call.** It takes no admin injection and the fake edge serves no nango table reads (`FAKE_EDGE_UNSUPPORTED`). For that one call the service client's `from` and `rpc` are routed to the PGlite admin with `mock.method`, restored right after. The function itself (decide in SQL, connection read, batch removal, finish) runs unchanged.
5. **Soft change feed.** The fake connector's feed page is read and its deleted ids go to `applySourceDeletions(…, 'change_feed')`, as the plan's key link names; `handleSyncWebhook` is not driven (it is covered by 06.3-09 and 06.3-28).
6. **External points are seeded straight into the fake vector store** for the purged version ids, so the purge drain has points to delete; the document-row drain is not exercised here (Phase 7's own tests cover it).
7. **An extra seventh case** for the tombstone note of 06.3-21/06.3-28 (orchestrator brief).
8. **One commit for all three tasks**: they are cases of one new test file, and the file is the test (no RED/GREEN split is possible for a test-only plan). RED evidence is the two guard mutations above.
