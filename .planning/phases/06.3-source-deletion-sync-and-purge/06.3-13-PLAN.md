## Trust Boundaries

|----------|-------------|
| browser to /api/nango/sharepoint/* | signed-in user; connection resolved from the session |
| browser-supplied cursor to Graph | a cursor must not steer requests to another host or path family |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.3-32 | Elevation of privilege | listing another user's connection | high | mitigate | connection looked up by session user, provider and status; never from the query; tests |
| T-06.3-33 | Spoofing / SSRF | opaque cursor | medium | mitigate | cursor re-validated with `pathAndQueryOf` (graph.microsoft.com only) and a fixed path prefix per route |
| T-06.3-34 | Tampering | oversized or malformed selection | low | mitigate | strict zod schema with caps; provider check; 400 on violation |
| T-06.3-SC | Tampering | npm/pip/cargo installs | high | accept | no package is installed by this plan |
</threat_model>
