<objective>
Show a withdrawn source to readers: the server's answer record decides, the sources panel keeps an empty dashed frame where the quote was, and the chip turns neutral (D-13, D-36, UI-SPEC 6.9).

Purpose: D-36 requires the app code that reads the withdrawn flag to ship in an earlier wave than any SQL that writes it (plan 06.3-10, wave 3). Without this plan a scrubbed citation would show an empty quote box with no explanation.
Output: the display rule, the panel and chip forms, four strings in three languages, and tests.

Standing rules: (1) trunk moves (D-01): Phase 5 also edits these components; locate `citationDisplayEntries`, `citationSourcesFor`, `CitationSourceEntry`, `CitationChip`, `documentStatuses`, `toAnswerRecord`, `answerQualityStrings` by name and re-read them at HEAD; `chat-message.tsx` is very large, change only the `CitationChip` call site; (2) `[HEAD=…]` values were measured at 4b4a488: re-measure each count gate before editing and stop if one already passes; (3) React Compiler is on: no manual memoization; text is always a React text child, never `dangerouslySetInnerHTML`; `cn()` for classes; tests use neutral names such as `file-a.pdf`; (4) plain `git commit` with the attribution lines of the executor's own session.
</objective>
