| Boundary | Description |
|----------|-------------|
| source sync to purge | an irreversible removal driven by a provider's deletion signal |
| source listing to ingest | a file that an admin withdrew must not return |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.3-54 | Tampering | irreversible purge from a mistaken or compromised source | high | mitigate | purge mode is opt-in per connection with a confirmation dialog; full-listing diffs pass the D-09 guard; change-feed batches are bounded and recorded |
| T-06.3-55 | Information disclosure | admin-purged content re-ingested from the source | high | mitigate | tombstone check before every connector ingest; fail closed on lookup errors; tests per provider |
