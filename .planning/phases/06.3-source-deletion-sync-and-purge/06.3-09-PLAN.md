## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet to /api/nango/webhook | unauthenticated callers; only the HMAC proves Nango sent the body |
| webhook body to deletion | the body names a connection and model only; file ids come from the Nango API, owner from the connection row |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06.3-21 | Spoofing | forged webhook triggering deletions | high | mitigate | HMAC-SHA256 of the raw body, constant-time compare, legacy header refused; file ids re-read from Nango; owner from the connection row |
| T-06.3-22 | Spoofing / Denial of service | replayed webhook | medium | mitigate | idempotent deletion; data re-read from Nango; bounded batch and deadline |
| T-06.3-23 | Information disclosure | connection existence oracle | low | mitigate | same 200 body for unknown and known connections; test |
| T-06.3-24 | Tampering | full-sync deletion diff from an incomplete Nango dataset | high | mitigate | `fullListing` page sets go through the D-09 guard (D-33); cursor not advanced on a pause |
| T-06.3-SC | Tampering | npm/pip/cargo installs | high | accept | no package is installed by this plan |
