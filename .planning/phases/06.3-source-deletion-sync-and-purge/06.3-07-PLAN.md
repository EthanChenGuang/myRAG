<objective>
Recheck retrieval candidates against Supabase after search and fusion and before rerank on the v2 path (RET-14, D-19, D-38), behind `RAG_SOURCE_RECHECK`, off by default, with the drop count on the trace; deliver the SQL function, the shared helper, the switch, the trace mapping and the boundary rule that every path uses.

Purpose: an index row that missed a delete, an undrained outbox or an in-flight purge must never reach the context. On pgvector the search RPCs already filter currency; the recheck closes the window and the exact-id leg. On Weaviate and Qdrant the recheck is Phase 7's single `rag_validate_chunks` call, which sets the same `sourceRecheck` marker; plan 06.3-14 makes this stage skip such candidate sets (D-46, D-47).
Output: migration 0723, the recheck helper, the switch and stage name, the conditional stage on the v2 path, the trace field and the boundary rule. The legacy chat, legacy voice, media and overview insertion points and the report-only latency budget line are plan 06.3-27 (split at plan-check iteration 2 to keep each plan within the 10-file budget).

Choices recorded here: stage failure policy `'skip'` (Open Question 7); stage timeouts 1000 ms in the standard tables and 300 ms in the voice table (RESEARCH A7, measured at live verification); the function is `SECURITY DEFINER` per D-02 (its analog `rag_cache_invalidate` is `INVOKER`) and uses the search-side guard `rag_assert_tenant_key` per D-43; if Phase 7's `rag_servable_chunks` view is on trunk at execution, read it but do not re-implement chunking-profile servability (a variant or legacy-fallback chunk stays a valid candidate).

Standing rules: (1) trunk moves (D-01): Phases 5, 6 and 7 edit `v2/stages/search.ts`, `config.ts` and the run route; locate `runSearchStages`, `OPTIONAL_STAGES`, `RagConfig`, `parseExactIdSwitch`, `ragEnv`, `stageCountsOf` and the `if (config.exactIdLookup)` block by name; (2) `[HEAD=…]` values were measured at 4b4a488: re-measure each count gate before editing and stop if one already passes; (3) style (D-44): 2 spaces and bracketed `console.*` in `src/lib/rag/**`; (4) plain `git commit` with the attribution lines of the executor's own session.
</objective>
