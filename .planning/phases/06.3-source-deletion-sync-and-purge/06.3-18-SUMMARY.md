# Phase 6.3 Plan 18: Source sync panel and connector card warning Summary

**Admins get a Source sync panel in RAG administration. It lists every connection with server-named reconcile badges, sets each connection's deletion mode (Purge only after a dialog) and confirms or dismisses a paused mass removal. Members see a read-only amber pill and note on a connector card that is paused or overdue. Nothing in the browser can start a reconcile.**

## What was built

- **`rag-panels/source-sync.js`** (classic script, prefixed names, 2-space indent, DOM built only with `createElement` and `textContent`; `innerHTML` count 0):
  - Labels `SOURCE_SYNC_LABELS` in en, zh and it, copied verbatim from UI-SPEC 12.2. Shared `error.signIn`, `error.network`, `error.unavailable` and `error.generic` come from `window.ingestLabel`.
  - Pure builders:
    - `buildSourceSyncRowView`: badges from the server `states` with Paused first, reason lines, mode help line, relative and absolute times.
    - `buildPausedRunView`: `paused.body`, `paused.bodyAll` or `paused.bodyCap`, the found and confirm-until times, at most 20 names, `paused.filesMore`, the expired form, and file ids when no names are sent.
    - `mapSourceSyncError`: the mapping of 8.2.
    - `sourceSyncSortRows`: paused, then overdue, then failed or incomplete, then the rest; within a group by provider, then owner. This orders the rows across loaded pages; the browser never computes a state.
  - `SourceSyncPanel`:
    - Connections and Settings sub-tabs with `role="tablist"`; Left and Right arrows move between them.
    - Toolbar with the Updated time and Refresh connections.
    - Overdue summary alert naming `npm run rag:source-reconcile` in `code`, with no live role.
    - The table in a focusable region with a caption. The Documents column hides below 768px and the count joins the Connection cell.
    - Per row: the deletion-mode select and its help line, and the paused-run block with Show files, Remove documents… and Dismiss run.
    - Load more connections fetches 50 per page.
    - The static `rag-source-sync-settings` block moves into the Settings sub-tab, and its "Open RAG Modes" button is wired to the RAG Modes tab.
  - Every call goes through `ragFetch`, wrapped so a thrown fetch is handled. Nothing polls and nothing is stored.
  - Dialogs are native `dialog`s that open with `showModal()`, with focus on the safe button:
    - **Use Purge mode** saves only on confirm. Keep, Escape or the backdrop restore the previous value and focus the select.
    - **Remove documents** shows the count and the sentence for the connection's mode. While its request runs it stays open: both buttons are disabled, the confirm button shows "Removing…", `cancel` is prevented and the backdrop button is disabled.
  - States: first load, refresh (60% opacity with `aria-busy`), empty with Open Connectors, 401/403 sign-in alert replacing the data view (Settings stays usable), 503/5xx/network alert with Reload panel (content stays, dimmed), mode saving and refused, expired run (by `expires_at` or 409 `confirmation_expired`), run handled elsewhere (`error.runGone` and reload), partial removal alert, and unknown state or code shown in monospace.
  - Focus: after an action it moves to the connection's mode select; after a failure it stays on the button that was used.
  - `initSourceSyncPanel` is idempotent and bound to every `[data-tab="rag-administration"]` link and to `DOMContentLoaded`.
- **`index.html`**: one `<script src="rag-panels/source-sync.js">`, placed directly after `rag-panels/ingestion.js`.
- **`ConnectorGrid`**:
  - `ConnectorReconcilePill` (amber `h-5` pill with `PauseCircle` or `AlertTriangle`, `aria-hidden`) sits after the Connected pill.
  - `ConnectorReconcileNote` (`text-xs text-amber-700 dark:text-amber-300 mb-4`) sits under the last-synced line.
  - Both are driven by `connection.reconcile_state`. `ok`, a missing field or any other value renders nothing, and no button, link or count is added. The card border and background are unchanged.
- **Translations**: four keys in `en.ts` and `zh.ts` next to `connectorStatusConnected`, with the 12.7 copy. Other locales fall back to en.

## Wire names used (from 06.3-16)

| Call | Used for |
|------|----------|
| `GET admin/source-sync/connections?limit=50&offset=N` | `items[]` (`id`, `provider_name`, `owner.label`, `workspace_key`, `document_count`, `connected_at`, `last_full_reconcile_at`, `states`, `days_without_reconcile`, `deletion_mode`, `paused_run{id, found_at, expires_at, candidate_count, total_count, file_names, names_not_sent}`), `total`, `limits{max_age_days, max_delete_share}` |
| `PUT admin/source-sync/connections/{id}/deletion-mode` `{ mode: null \| 'soft' \| 'purge' }` | mode select |
| `POST admin/source-sync/runs/{id}/confirm` (`{}`) | Remove documents (`removed`, `failed`) |
| `POST admin/source-sync/runs/{id}/dismiss` (`{}`) | Dismiss run |
| `GET /api/nango/connections` → `reconcile_state` | app card |

The panel reads the optional fields `paused_run.file_ids`, `paused_run.pause_reason === 'purge_daily_cap'` and `paused_run.daily_cap` / `limits.purge_daily_cap` when they are present. 06.3-16 does not send them yet (see Deferred).
