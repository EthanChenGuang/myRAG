## Switch audit: `readRagEnvInput` (`src/lib/rag/deps.ts:95-178`)

## Integration (cross-phase)

- **Parity-off holds.**
  - Each effective switch is `raw && RAG_QUERY_LAYER`, and routing is forced to `off` while the layer is off.
  - The `scope_gate` stage is disabled unless effective, and always for voice (`config.ts:1442,1513`).
  - The new trace fields (`speculative`, `out_of_scope`, `query_plan.completeness`) appear only when produced.
  - Smoke tiers and `parity-off.test.ts` pass.
- **True defaults change behaviour with the layer on.** Completeness and history-fallback default to true, so with `RAG_QUERY_LAYER=true` they change retrieval against the Phase 6 layer-on baseline. CONTEXT D-04, D-23 and D-28 accept this, but the layer-on baseline must be re-recorded (06.2-22 says "re-baseline pending").
- **Config hash and cache key.**
  - With switches off, the Phase 6 hash is unchanged: the subq-filter prompt and glossary block enter only while effective (`query/hash-part.ts:48-59`, `v2/config-hash.ts:386,394`).
  - **Missing from the hash:** completeness, historyFallback, langidSidecar and scopeGate. Flipping completeness or historyFallback with the layer on changes retrieval without changing the hash, so the semantic cache keeps serving answers from before the flip (G5).
  - The cache key (`cache/keys.ts:6-15`) holds `generatorModel`. 35 must write the routed model there, and the decomposed-answer block must enter `systemPromptHash` once it is wired.
  - An `out_of_scope` turn is never stored (`cache/bypass.ts:30,155`).
- **Voice.**

  - Translate runs only when listed in `RAG_QUERY_VOICE_TRANSFORMS`, with a 250 ms timeout.
  - History is at most 6 turns, bound to the scope token (`api/internal/voice-rag/route.ts:41-68`).
  - The 06.2-27 eval voice entry is in place.
- **Multi-tenant isolation.**
  - The q62 PGlite suites cover subq filters (narrow only; another tenant's doc type is dropped), tenant doc types, glossary, centroids, separation, WhatsApp eval and fixture isolation; all pass.
  - The baseline `v2-two-tenant-matrix` has **no 6.2 rows**. exec/06.2-36 adds four: subq filters, glossary, scope gate centroids and examples, WhatsApp history.
  - No new path takes a tenant input other than `scopeKey`.
- **Migrations and grants.**
  - 0980: SECURITY DEFINER, `search_path=''`.
  - 0981: INVOKER.
  - 0982: RLS on, no policy, `REVOKE` from PUBLIC/anon/authenticated, service_role only.
