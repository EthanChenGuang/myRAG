## Deviations from Plan
1. **No private helper fallback**: rag-ui.js is on trunk and loaded first, so the panel depends on it (see decisions) instead of duplicating its builder, dialog and request helpers.
2. **Two extra label keys** (`delete.running`, `panel.workspaceDefault`) in en, zh and it.
3. **Chunks and Updated per kind** come from workspace totals where the route has no per-kind value (see decisions; 06.2-38 deferred item).
4. **Thresholds command** is the route's `uv run --directory eval …` form, not the bare `python -m rag_eval.calibrate scope` of UI-SPEC 12.3.
5. **TDD order**: tests and code in one commit; mutation evidence above.

## Deferred
- Per-kind chunks included and update time need a `rag_scope_status` change (06.2-18 SQL, already listed by 06.2-38).
- Added-by display names: rows carry user ids only; the panel shows the id in `font-mono` and will show `createdByName` once the route sends it.
- "Not in use" examples never appear until the service lists examples of other profiles (06.2-38 deferred item); the rendering is in place and tested.
- Low: with a fixture calibration every threshold row carries the "Fixture, eval only" badge (the contract asks for it per row); a single block-level note would read quieter. Left as specified.
- Human check from the plan (zh/en/it at 360/768/1024, focus after a removal) is for /gsd-ui-review; the Playwright runs above cover the overflow part.
