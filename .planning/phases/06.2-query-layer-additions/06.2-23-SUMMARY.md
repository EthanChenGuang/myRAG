## Behaviour changes

- With `RAG_PIPELINE=v2`, `RAG_QUERY_LAYER=true` and `RAG_DECOMPOSED_ANSWER` on (default true under the layer), a turn whose plan has two or more sub-questions gets the localized block after the context (and after the answer-language line), with each part's block aliases when citations label the blocks, `“<labels.not_covered>”` for a part without a block and the comparison order on R3. Embed (no citations) gets the block without aliases.
- Claude Citations path (chat and eval): the same block in the direct call's system text, naming documents by order.
- After the answer, chat and embed record an `answer_structure` stage; the eval trace carries `answer_structure`.
- Out-of-scope in balanced, flexible and embed: the answer starts with the notice, the prompt says not to repeat it, the finish metadata has `rag.scopeGate` (label only; scores stay on the server trace, T-06.2-66).
- Off: switch off, layer off, legacy pipeline, fewer than two sub-questions, or no knowledge context: prompts and streams are byte-identical (tested: same system prompt for no sub-questions, one sub-question, switch off and layer off; characterization tests unchanged). Strict "information not available", webSearch with Exa, `source_images`, `{{context}}`, voice and embed are unchanged with the switches off; out_of_scope cannot occur while `RAG_SCOPE_GATE` is off.
