## Behaviour changes

- The chat model selector shows an "Auto" row second in the OpenRouter list. The default model is unchanged. Until 06.2-29 and 06.2-35 resolve `auto` on the server, selecting Auto sends the id `auto` to the provider, which fails. Merge those plans before releasing to users, or remove the row under AI Models.
- check-config now fails when `RAG_ROUTING_FAST_MODEL` or `RAG_ROUTING_QUALITY_MODEL` is empty (tracked locations), `auto`, or not in an OpenRouter model list. This includes `.env.local`, and its `NEXT_PUBLIC_OPENROUTER_MODELS` if set: a local `.env.local` with an older model list lacking the Claude 5.5 entries now fails.
- No runtime behaviour otherwise: nothing reads the twelve switches yet.
