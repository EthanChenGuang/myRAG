## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (`tests/**/*.test.ts`); `node --import tsx --test` (`.test.mts`, PGlite suites in `tests/rag-db/`, e2e in `tests/rag-e2e/`); `node --test` (`scripts/tests/*.node-test.mjs`); pytest in `eval/` and `rag-sidecar/` |
| **Config file** | `vitest.config.ts`, `eval/pyproject.toml`, `rag-sidecar/pyproject.toml` |
| **Quick run command** | `npx vitest run tests/rag/query tests/rag/scope tests/rag/lang` (+ the task's own PGlite file via `node --import tsx --test tests/rag-db/<file>.test.mts`) |
| **Full suite command** | `npx vitest run && node --import tsx --test tests/*.test.mts && node --import tsx --test tests/rag-db/*.test.mts && uv run --directory rag-sidecar --extra chunking pytest -q && uv run --directory eval pytest -q && node scripts/check-config.mjs && node scripts/ci/check-rag-boundary.mjs && npm run typecheck:new && npx next typegen && npx tsc --noEmit -p tsconfig.json` |
| **Schema parity** | `npm run gen:schemas && git diff --exit-code -- rag-sidecar/schemas src/lib/rag-eval/contracts.generated.ts tests/fixtures/contracts/samples.json` |
| **Smoke tier** | `npm run test-rag -- --out eval/out/<name>` then `jq -e '.passed == true and .paired.all_zero == true' eval/out/<name>/gate.json` (also `--fixture-mode ingest`) |
| **Estimated runtime** | quick ~30 s; full ~10–15 min |

---

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command plus `npm run typecheck:new` for TypeScript changes.
- **After every plan wave:** full suite, schema parity, smoke tier in both fixture modes with the paired-zero check (until the golden-addition plans; afterwards the gate against the re-recorded baseline).
- **Before `/gsd-verify-work`:** full suite green, decision record written by the tool, boundary and config checks green, `node scripts/ci/check-frontend-design-summary.mjs` green.
- **Max feedback latency:** 60 seconds per task command.
