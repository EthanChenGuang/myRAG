## Deviations

- Output paths: the plan named `eval/reports/q62-scope-separation-real/report.json`. The orchestrator assigned one subdirectory per profile, so the route A report is `.../openai-3-small-1536/report.json`. 06.2-26 should read its precondition from that path.
- Runner: the live runs used a scratchpad wrapper around `runScopeSeparationCli` that added the call cap, the 1.5 s pause and the stop on 402/429. The wrapper also loaded `openai/shims/web`, because the `openai` SDK's bundled node-fetch skips the session proxy (that is the bge-m3 401). Proxied sessions also need `NODE_USE_ENV_PROXY=1`. The harness code is unchanged.
- `src/lib/env.ts` validation needs `OPENAI_API_KEY` and `SUPABASE_SERVICE_ROLE_KEY` to be non-empty when it loads. Both were set to placeholders that never reached any host; with `RAG_OPENAI_EMBEDDINGS_VIA=openrouter` the embedding request uses `OPENROUTER_API_KEY`.
