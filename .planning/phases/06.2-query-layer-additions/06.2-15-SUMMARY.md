## Behaviour

- `rag_scope_centroids_rebuild(tenant, profile)` replaces the tenant's rows for that profile in one INSERT … SELECT: `public.avg(halfvec)` per `<doc_type>/<language>`, `<dimension>:<value>/<language>` and `tenant/<language>` (D-34, P-03). Membership follows the 0856 chunking-profile rule (active chunking profile, else legacy; legacy fallback while the document has no chunk in the active profile). The legacy profile (`storage = 'legacy_column'`) reads `document_chunks.embedding::halfvec`; others read `chunk_embeddings` with matching dims. Language: chunk language, else document language, else `und`. Returns groups and chunks per kind.
- Examples: at most 500 characters (`example_too_long`, 22001), not empty (22023), duplicates by case- and whitespace-folded text refused (`example_duplicate`, 23505), at most 100 per tenant and profile (`example_limit`, 54000), embedding dims must match the profile (22023). Delete only within the tenant. A per-tenant transaction advisory lock makes the limit check race-free.
- Invalidation (P-27): statement triggers on `documents` (insert, delete, update of is_current, status, version, tenant_key, doc_type, language, scopes, provisional, superseded_by), `document_chunks` (insert, delete, update of is_current, status, tenant_key, doc_type, language, scopes, provisional, chunking_profile_id, embedding) and `chunk_embeddings` (any write, that profile only) delete the tenant's centroid rows in the same transaction. Triggers take the tenant's shared advisory lock; rebuild takes the exclusive one, so an overlapping rebuild either sees the change or is cleared after it.
- Every function asserts the tenant key first, is SECURITY INVOKER (trigger functions and the invalidate helper are SECURITY DEFINER, service_role only), `SET search_path = ''`, revoked from PUBLIC, anon, authenticated, granted to service_role. Nothing is folded into the setup files; no product code calls the functions yet (06.2-18 onward). Switch-off behaviour of the app is unchanged.
- No example text, centroid or vector is logged anywhere.
