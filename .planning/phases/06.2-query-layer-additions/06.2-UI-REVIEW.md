## Top 3 Priority Fixes

1. **Load 404 shows `error.changed`** — an admin on a deployment without the route (or with the gate route switched off) is told someone else changed an item, which is false and gives no next step — map a 404 on the initial `GET` to a dedicated "not available on this deployment" alert, keeping `error.changed` for actions only (spec 7.1 restricts it to actions).
2. **Error rendered twice** — the 500/404/401 sentence appears in the alert and again in `[data-scope-gate-status]` (`role=status`), so it is seen and announced twice — keep the alert, set the status region to a neutral "Status not loaded." or leave it empty on load failures.
3. **Thresholds table clips at 1024 without affordance** — the Recorded column is cut to "Nov 20, 20" inside the scroll region; users do not know to scroll — let the profile column wrap at token boundaries (or drop `whitespace-nowrap` on dates) so the table fits at 1024, and add an edge fade/shadow when the region overflows.

## Detailed Findings

### Pillar 1: Copywriting (3/4)

- **MED — load 404 copy is wrong.** `scripts/config-ui/rag-panels/scope-gate.js:688` returns `error.changed` for any 404; `rag-ui.js:26` text "This item was changed by someone else. The list has been reloaded." Seen at `en-1024-off404.png`, `it-1024-off404.png`. Spec 7.1/8 define 404 only for actions; the load case is a spec gap the implementation filled with a misleading sentence. Fix: add `error.notAvailable` (en/zh/it) for 404 on `status`, e.g. "The scope gate is not available on this deployment. Update the app, then reload."
- **LOW — "None" for a missing threshold** (`scope-gate.js:1276`, `cell.none`) reads as a value; the neighbouring Margin cell uses an em dash for the same absence. Fix: use the em dash with an `sr-only` "No threshold" for consistency.
- Pass: headline, explanation, reasons, `examples.help`, delete dialog ("Keep example" / "Delete example"), pointer text and "Open scope gate" match the contract; zh and it renders contain no leftover English beyond env names, ids and commands.

### Pillar 2: Visuals (3/4)

- **MED — duplicated error.** `en-1024-error500.png`, `it-1024-error500.png`: the alert and the status line under it carry the same sentence. Fix as in priority 2.
- **MED — Recorded column clipped at 1024** (`en-1024-populated.png`, threshold table built at `scope-gate.js:1265-1300`, region at 1082). Fix as in priority 3.
- **LOW — "Refresh status" row floats alone** with ~40px empty space above and below (`en-1024-populated.png`), visually detached from both the switch and "In effect now". Spec puts the alert host and Updated/Refresh on one row; with no alert, collapse the row's top margin.
- Pass: the 16/600 headline is the clear focal point; readiness badges carry icon plus word; icon buttons all have text.

### Pillar 3: Color (4/4)

- Badges: On/Ready `badge-success badge-outline`, Missing `badge-warning badge-outline`, Not calibrated `badge-ghost`, Not in use warning outline — all as 6.3.2/6.3.5. `checkbox-primary` and `btn-primary` "Add example" are the only accent uses in the panel. Rates and thresholds are uncoloured (F-19). Errors use `alert-error`.
- **LOW — alert-error contrast**: dark text on the saturated red alert (`it-1024-error500.png`) is readable; the bolder "Reload panel" button is fine. No action needed beyond monitoring theme changes.

### Pillar 4: Typography (3/4)

- **LOW — mono ids break mid-token**: `profile-beta-1` / `024`, `profile-alpha-` / `1536` at 1024 and 360 (`break-all` per spec). Spec mandates `break-all`, but at 1024 there is room; consider `break-words` plus `overflow-wrap:anywhere` only below `md`.
- **LOW — zh command wraps inside the token** (`zh-1024-needscal.png`: "uv ru / n --directory"). Same cause; acceptable per spec but harms copy-paste reading.
- Pass: 18/600 title, 16/600 block headings and headline, 14px body, 12px help lines; `tabular-nums` on numbers.

### Pillar 5: Spacing (3/4)

- **LOW — 360 tables scroll horizontally with no hint**: Scope data table and thresholds table exceed the 295px card (TABLE right edge 333px en, 342px it) inside the focusable `overflow-x-auto` region; the page itself does not overflow. Thresholds at 360 show only Profile, Mode and a cut Status edge (`en-360-populated.png`). Fix: hide Chunks included below `sm`, and add an overflow shadow.
- **LOW — examples table at 360** wraps example text to one word per line (`en-360-populated.png`) because the Delete button column takes ~45%. Fix: at `<md` render Delete below the text (`flex-col`) or as `btn-xs`.
- Pass: five blocks separated by `mt-6`; form `p-4` on `bg-base-100`; `gap-x-6` readiness grid.

### Pillar 6: Experience Design (3/4)

- **MED — load 404 treated as a concurrent edit** (see Pillar 1); the "Reload panel" action can never succeed.
- **LOW — "What happens to an out-of-scope question" summary is 20px tall** (touch target under 24px at all widths). Add `py-1`.
- **LOW — pointer button `btn-xs px-0`** (`index.html:6936`) is ~24px tall; acceptable as a link but small on touch.
- Pass (observed): pointer selects the tab, scrolls and focuses `#rag-scope-gate-title`; switch stays usable in 401/404/500 states; `reason.switch.pending` shows when page and running values differ; empty submit and 409 set `aria-invalid="true"` with the right message; Ctrl+Enter submits; add announces "Example added."; delete opens a modal with "Keep example" focused; rebuild issues one request and announces "Scope data rebuilt."; CLI-only rebuild shows command + Copy, no dead button; empty states for scope data, examples and thresholds render centred with next steps.
