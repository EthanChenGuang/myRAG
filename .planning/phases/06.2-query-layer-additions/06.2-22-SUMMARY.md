## Task 2: items, scripts and re-baseline

### Items (described by structure)

- **scoped_compound (15):** two sub-questions each, about the two scope-tagged documents of one language: recalibration interval, recalibration duration, spare stock and reorder threshold. Each sub-question's gold span is in exactly one scoped document. Its decompose script names that document's region and department scopes as the sub-question filter.
- **glossary (9):** each question uses the invented source-language term. The gold span is in the glossary document of the glossary row's target language and contains the required translation. The translate script for that target is a generic translation that does not contain the required term. In each language, one of the three scripts keeps the source term.
- **off-domain no_answer (12):** questions about a field topic that no fixture document covers. They are asked next to the adjacent probe/battery passages. Tags: `off_domain`, `phase62`, `q62_adjacent:q62-adjacent.<lang>.md`.
- All items are `synthetic_fixture` / `approved`. The zh and it items also carry `native_review: {origin: llm_drafted, status: pending}`. Split = hash rule.

### Re-baseline

- Old baselines were copied to `eval/baselines/history/*.pre-06.2-22.json`.
- Prechunked: `RAG_PIPELINE=legacy npm run eval:baseline`. Ingest: `RAG_PIPELINE=legacy uv run --directory eval python -m rag_eval.baseline record --runs 3 --fixture-mode ingest --out eval/baselines/fixture-ingest-baseline.json`.
- Prechunked went from 413 to 446 items and ingest from 561 to 594. No old item moved in either.
- `category:scoped_compound` now records `all_evidence_recall_at_5/10` and `subq_coverage_at_5/10` (n=2 items / 4 sub-questions in the gate population). Only approved English dev items gate; drafted zh/it items are report-only (P-11).
