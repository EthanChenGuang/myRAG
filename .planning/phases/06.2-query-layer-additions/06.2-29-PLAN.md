<objective>
Build the rule router for Auto turns and the citation-session hook it needs, and make the routing measurable on fixtures through the eval route; the chat and embed wiring follows in 06.2-35.

Purpose: D-19 (Auto entry semantics, explicit choice never replaced, routing off resolves to quality), D-20 (pure rule router after retrieval, inputs, trace, Citations path, eligibility measurement) and D-35 (the two routing IDs are written defaults, so the router and the delay table read real IDs). Split from the chat and embed wiring (06.2-35) so each executor holds either the generation modules and the eval harness or the two large route files, not both.

<assumption_delta_decision>
Primary noun: the requested model selection (an explicit model id or auto). Decision: promote — each route resolves the selection once at its top into a concrete model id, and every helper below reads only the resolved id; the raw request value is demoted to an input of resolveRequestedModel. Rationale: Auto turns a chosen model into a derived one; letting helpers read the raw value is how auto leaks to a provider. Invariant test: no code path after resolution sees the string auto (here for the router and the eval route; for chat and embed in 06.2-35).
</assumption_delta_decision>

Output: the router, a citation-session change, the eval-route support, a mock-generator delay table and the router test.
