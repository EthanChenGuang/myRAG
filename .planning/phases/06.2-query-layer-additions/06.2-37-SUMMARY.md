# Phase 6.2 Plan 37: Query layer card script Summary

The Query layer card now has its own script, `query-additions.js`. It fills the fast and quality routing selects from the page's OpenRouter list, computes the routing warnings, dims nested switches when their parent is off, and wires the "Open glossary" pointer. Everything comes from page state: no request, no config write.

## Task 1: precondition (D-01)

Passed. The 06-40 SUMMARY exists, and every plan in depends_on, including transitive ones, has a SUMMARY on this branch.
- Card id: `query-layer-card`
- Routing selects: `RAG_ROUTING_FAST_MODEL`, `RAG_ROUTING_QUALITY_MODEL` (plus `RAG_MODEL_ROUTING`)
- Glossary entry point: `window.initGlossaryView` (glossary.js), called by terminology.js. Its tab button is `#rag-terminology-tab-glossary`, selected through `window.terminologyPanel.tabs.select('glossary')`
