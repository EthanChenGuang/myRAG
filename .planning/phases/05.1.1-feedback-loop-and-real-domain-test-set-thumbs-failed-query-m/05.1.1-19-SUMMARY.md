# Phase 5.1.1 Plan 19: Domain test set promotion with the document-group split, and the hand-off files

**Expert-approved golden candidates now become permanent items of a per-tenant private domain set. Items that share a document always share a split, frozen splits never move, deletions are caught by the scorer, and the dictionary and training hand-off files are validated and checked for test-split leaks before they are written.**

## Accomplishments
- `rag_eval.split`: the `docgroup-sha256-first8hex-mod100-lt70-dev` rule beside the item-id rule. Groups are built by union-find over shared gold document ids (`GoldSpan.document_id`, D-21/D-29; name-keyed when a span has none) and confirmed near-duplicate tags. A new group is assigned from `sha256(min document key)`; `group_assignments` is recorded; a manifest never switches rule.
- `rag_eval.near_dup`: character 3-gram Jaccard on `normalize_text(question)`, threshold 0.85; works for zh (punctuation-only and end-of-sentence measure-word changes pair; a measure-word change in a short question does not, 0.6).
- `review_queue promote-db`: reads `kind=golden` from the export route with the Bearer token from `--token-env`, re-checks every quote against the exported chunk text, re-runs `mask_text`, requires `confirm_near_duplicate_of` for a near-duplicate, builds approved `GoldenItem`s (provenance `production`, or `human` with `paraphrased_question`), appends to `eval/golden/private/domain/<tenant_hash>/golden.jsonl` through `assert_private_path`, freezes splits in that set's own `split-manifest.json`, then posts `{id, split, split_group}` to the mark route in batches of 500.
- `rag_eval.feedback_exports`: writes `eval/golden/private/exports/<tenant_hash>/<kind>-<date>.jsonl`, every line validated by `DictionaryCandidate` or `TrainingPair`, with the second leakage check against the domain set.
- `runner score`: refuses a golden file missing an id of its split manifest (`--split-manifest`, or a docgroup manifest next to the file), so a deleted item is caught. There is no delete command.
- Output never prints a token, question, answer or chunk text; refusals name review-item hashes, golden ids and reason codes. Existing exit codes are reused (0, 2, 4, 6).
