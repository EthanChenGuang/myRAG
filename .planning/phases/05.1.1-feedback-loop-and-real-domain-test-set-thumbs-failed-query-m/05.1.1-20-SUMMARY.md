# Phase 05.1.1 Plan 20: Stats route, failure report and weekly report Summary

**Aggregate feedback-loop stats per tenant hash behind the admin guard, plus private failure and weekly reports that carry only ids, counts, hashes and codes.**

## Accomplishments

- `GET /api/rag/admin/feedback-loop/stats` returns `FeedbackLoopStats` for each tenant hash: retrievals by channel, outcome counts, refusal, zero-result and low-score rates, votes by kind, thumbs-down rate, refusal disputes, source-open rate, items mined, labelled, skipped and exported, and triage counts. The admin guard runs first, and the window can be at most 92 days.
- `rag_eval.failure_report` reads private runs started on or after `--since`. It gives each failed item a layer, leaves out failures already in the previous report, groups the rest by layer and then category, and writes JSON and Markdown under `eval/golden/private/reports/`.
- `rag_eval.weekly_report` combines the stats route, the trend of the last 8 runs for each domain set and the failure report. Where data exists without private runs it prints a skip notice and exits 0.
