## Deviations from Plan

1. **Re-apply was rolled back, not committed.** Later migrations on eval (0967, the 0410 r13 delta) could be affected by a committed re-run. Rolling back still proves the files run twice without error, and it leaves the shared project unchanged.
2. **RLS was checked through role and claim impersonation in SQL, not with real users through PostgREST and the app.** The session's permission guard refused creating and deleting real auth users on the eval project. The policies, grants and `auth.uid()` that PostgREST relies on are what the check exercises. The app path is still listed under Operator pending.
3. **Expert grants were written directly to the table, not through the Config UI admin card.** No app deployment runs against eval in this session.

**Impact:** the security properties of Task 1 are verified. Only the UI grant path and real-JWT PostgREST reads remain for the operator.
