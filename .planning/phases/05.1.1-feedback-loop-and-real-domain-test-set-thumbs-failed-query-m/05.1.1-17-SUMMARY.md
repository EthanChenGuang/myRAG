# Phase 5.1.1 Plan 17: Expert labelling panel in the Config UI Summary

**Domain experts work the review queue in the Config UI with their own sign-in: they filter and open cases, read the retrieved passages, search their workspace, quote evidence that the panel checks word for word, and save a label that the route accepts; a test-set label needs the personal data check first.**

## Accomplishments
- Queue view (UI-SPEC 6.6.1): status, reason and language filters (query string, "All" omitted), 50-per-page cursor paging with "Load more cases", status badges with icon and word, reasons with "Asked: n", workspace shown only when cases span more than one. 401/403 show the shared sign-in sentence plus the expert line; 404 on the list shows "Expert review is switched off"; 503 and network failures keep earlier content dimmed.
- Case view (6.6.2 to 6.6.4): masked question, meta line, outcome, masked answer or "No answer text is kept", passage blocks ten at a time with section, one score (rerank or similarity, three decimals), used/not used, gone passages with disabled controls; chunk text from `/chunks` set unchanged with `textContent`; review search (`POST …/search {query}`, 500-character limit checked before sending, 503 and empty mapped). A 404 on any case call reloads the queue with `error.gone`.
- Label form (6.6.5, 6.6.6): quote slips from the remembered selection (or empty for keyboard use), checked on every input with the route's normalisation; Save stays enabled and sends nothing while a field is invalid, marks fields, focuses the first and announces `save.blocked` as an alert. Answer, category, language, five uses, term pairs, not-relevant passages (locked on quoted passages), personal data check with rewritten question and near-duplicate id. 400 span errors land on the named quote, 409 reloads the case read-only, a thrown save reloads and says the outcome is unknown, save/skip opens the next case. Discard dialog on leaving with unsaved changes; `beforeunload` guard.
- No delete, export, split or tag control; the panel calls only `/api/rag/review/items*` and sends no tenant.
