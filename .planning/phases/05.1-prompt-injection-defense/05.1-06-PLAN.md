Output: the stage module, the stage registration and DI seam, the legacy main-graph wiring, the renderer switch, and four test files.

Runs after Phase 5 is complete. Relies on: plans 05.1-01 (shared rules), 05.1-02 (wrapper), 05.1-04 (switches and reader), 05-04 (ContextBlock and the labeler hook in buildContext, refs sections), 05-16 (last chat route state; the route is read, not edited), 04-08 (StageEntry rules and counts), 04-02 (stage registry), 03-20 (matcher). Rollout position: D-19 steps 3 (legacy chat part) and 4.

Stage timing decision (A-3, research Pattern 4): the configured injection_check timeout (chat and embed 400 ms, media 400 ms, voice 1000 ms, eval 60000 ms) is the stage budget. Recorded deviation from D-09 ("eval has no timeout"): eval uses the 60000 ms registry maximum as a safety ceiling, the Phase 4 F-16 convention, and no ML deadline applies to eval below it; the stage runs its rules synchronously before the first await, and runStage is given that budget plus a 250 ms guard so the race can never pre-empt a later inner ML deadline (plan 05.1-21 sets the inner deadline to budget minus inner_reserve_ms). If the stage is still recorded skipped through an event-loop stall, the pipeline applies the rules verdict it already holds (fail-safe), records degraded, and never drops the rules result.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Retrieved knowledge-base text to the generator | Uploads, connector pages, scrapes and captions are untrusted and reach the prompt |
| Retrieval result to user-visible lists | Sources panel, source_images and the synthetic tool result must match what the model saw |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.1-16 | Tampering | rules skipped by a stage timeout (fail-open) | high | mitigate | rules run synchronously before any await; runStage budget plus guard; stall fail-safe applies the held rules verdict (Task 3 tests) |
| T-05.1-17 | Denial of service | an empty <documents> block breaking the strict refusal sentinel | high | mitigate | wrap only with at least one block; NO_CONTEXT_TEXT kept; all-dropped gives empty/injection_filtered; chat-strict cases in zh, en and it |
| T-05.1-18 | Information disclosure | chunk or query text in [RAG Security] or trace logs | medium | mitigate | ids, rule ids and counts only; log spy assertions; hot-path-logs suite |
| T-05.1-19 | Tampering | a dropped document still offered to the model or the UI (sources, synthetic query_documents result) | medium | mitigate | FilteredCandidates rebuilt through filterCandidates; references lose text and UsedDocument; tracer second case |
| T-05.1-20 | Elevation of privilege | injected text in a referenced document's filename | medium | mitigate | reference docs rendered with escapeAttr source and escaped body |
| T-05.1-SC | Tampering | npm/pip/cargo installs | high | accept | this plan installs no package |
</threat_model>
