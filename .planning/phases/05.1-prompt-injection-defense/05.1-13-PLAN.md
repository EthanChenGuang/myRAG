| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05.1-39 | Tampering | injected text steering image or video prompt rewriting | medium | mitigate | rules-only drop on the media graph (A-11) |
| T-05.1-40 | Tampering | overview fallback and voice context reaching the model untagged | medium | mitigate | overview blocks wrapped; voice.context wrapped and used by plan 05.1-20 |
