## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App to sidecar classify endpoint | Chunk text batches cross an HTTP boundary |
| Golden files to the CI gate | Fixture contents decide whether the injection gate can pass |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.1-08 | Tampering | golden items that let the injection gate pass vacuously (canary in the expected answer, injected doc equal to the gold doc) | high | mitigate | Pydantic validators in Task 2; plan 05.1-10 adds a minimum item count to the gate |
| T-05.1-09 | Denial of service | oversized classify batches | medium | mitigate | items 1..32, text up to 20,000 characters, ids up to 64 characters, enforced by the request contract |
| T-05.1-10 | Tampering | detector thresholds or languages loosened without notice | medium | mitigate | config is data validated at load, carries a version that enters the trace and the retrieval config hash (plans 05.1-13, 05.1-14) |
| T-05.1-SC | Tampering | npm/pip/cargo installs | high | accept | this plan installs no package |
</threat_model>
