## Deviations from Plan

1. **[Rule 1, convention] Id shape.** The plan wrote `<lang>-injection_evasive-NNN`. The repository's id test requires the category with hyphens, so the ids are `<lang>-injection-evasive-NNN`.
2. **[Rule 3, blocking] The ingest baseline was re-recorded.** The plan said ingest mode is not touched. But `ingestGoldenPaths()` merges `golden.jsonl` with `golden-ingest.jsonl`, so the ingest gate refused on `golden_sha256`. The re-record used the same per-item identity proof as the prechunked one (192 of 192 identical).
3. **[Rule 3, blocking] Count and snapshot pins outside the file list:** `test_fixture_coverage.py`, `test_golden_phase4.py`, `ingest-mode-routing.test.mts`, and the chat, embed, voice and voice-v2 characterization snapshots. The snapshots were re-recorded with `UPDATE_CHARACTERIZATION=1`, following the 05.1-09 and 04-38 precedent. A script checked that every pre-existing entry is identical and keeps its order. Chat gained 36 entries (18 questions × 2 model kinds), and embed, voice and voice-v2 gained 18 each.
4. **Addition:** a `scanText` cross-check in `injection-fixtures-rules.test.ts`. Python has no rules engine, so the Python test pins the class by heading. The TS test proves that each item's category matches what the shipped rules actually do with its injected chunk.
