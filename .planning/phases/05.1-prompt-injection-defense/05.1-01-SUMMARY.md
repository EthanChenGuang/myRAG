## Deviations

- `injectionRulesVersion(filePath?)` takes an optional path, because the loader has no path option. With a path the file is hashed and the result is not memoised. The test uses it on a temporary copy.
- The default file is read from `path.join(process.cwd(), 'config/rag/injection-rules.json')`, a form that Next's output file tracing follows. If the file is missing at runtime, the call throws; no fallback hash is invented. The plan that first calls it at runtime (05.1-12/13) should confirm that the deployed bundle contains the file.
- None of the corpus chunks matched a new rule, so no rule needed narrowing.

## Decisions for STATE

- The rule-set version is `sha256(file bytes)[:12]`. `schema_version` remains the contract version (always 1). The config server and the Python side must hash the same bytes.
- Indirect rules need an AI-type addressee. A plain "assistant"/"assistente"/"助手" counts only in the note-to form (zh: only with an AI prefix). "model" alone is never an anchor, because the corpus uses it for products. The Italian "ai" is never an anchor, because it is a preposition.
