<objective>
Treat webSearch and MCP results as data on their way to a model, suspend YOLO auto-approval on turns with flagged context, and record injectionFlagged for those turns.

Purpose: D-10 (tool results tagged under a separate switch and never dropped; the MCP approval rule stays the human guard, with an invariant test), A-7 (escape only the model's copy through toModelOutput), A-8 (YOLO mode would otherwise bypass that human guard; research F-5), A-14 (record the flag on the stream payload, trace and log, no schema change). AGENTS.md section 14 requires that webSearch and the strict webSearch path behave as today.
Output: the tool-result helpers, chat and approve route changes, three test files.

Runs after Phase 5 is complete. Relies on: plans 05.1-01 (rules for tag_and_flag), 05.1-02 (escapeTags, escapeAttr, TOOL_RESULT_SENTENCE, TOOL_RESULT_NOTICE), 05.1-04 (switch), 05.1-06 (RetrievalResult.injection), 05-16 (last chat route edits, including the Claude path). <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Web search and MCP results to the model | Third-party pages and emails are attacker-writable |
| Model tool calls to MCP execution | An injected instruction can ask for a tool call |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.1-45 | Elevation of privilege | injected tool call auto-approved by YOLO mode | critical | mitigate | one per-turn YOLO value computed after retrieval and read by all three execute wrappers (A-8, W1); approval invariant tests per path with YOLO on and off; source gate that no wrapper reads the pre-retrieval const |
| T-05.1-46 | Tampering | escaping altering what users see or what groundedness checks | medium | mitigate | toModelOutput escapes the model copy only; tests on raw webSearchResults and metadata |
| T-05.1-47 | Tampering | email bodies steering the approve-route summariser | high | mitigate | instructions first, escaped tool_result elements, notice; byte-identical when off |
| T-05.1-48 | Repudiation | no record that a turn's context was flagged | low | mitigate | injectionFlagged on stream metadata, approval payload, trace and [RAG Security] log |
| T-05.1-SC | Tampering | npm/pip/cargo installs | high | accept | this plan installs no package |
</threat_model>
