## Deviations from Plan

1. **Unset rule fields omitted from the dump.** The first write of `monitor-alerts.json` had nine `null` keys per rule. Because the file is hand-edited, unset `MonitorRule` fields are now left out (`exclude_if` plus `omit_none_schema`); Python still accepts an explicit `null`. The generated Zod treats them as optional.
2. **Additions beyond the plan text:** `cluster_ids` on `MonitorAlert` (D-45 names the clusters); extra `config_changes.source` values `embedding_profile`, `chunking_profile`, `retrieval_log` (D-27); `ConfigGateSummary.layers`; `default_release_gate()`; a holistic metric cannot be a `gating` judge cell; the drift and gap rules must equal the drift block. `trace_urls` was left out (see key decisions).
3. **RED failures:** a few RED tests failed with `AttributeError` on the stub (for example `report.gates`) rather than an assertion. None failed on module-not-found.
