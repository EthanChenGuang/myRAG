## Deviations from Plan

1. **[Rule 1 - Bug] Serialization of non-None defaults.** The plan typed `stale_count: int = 0`, `stale_share: float = 0.0` and `rag_mode = "strict"` as plain defaults. Written always, they changed every regenerated report: `eval/tests/test_report_citations.py::test_report_without_citation_data_is_byte_identical_to_before` failed. These keys are now left out of the dump while they hold their default (`omit_default_schema`). Values and types are unchanged, and the generated Zod marks them optional.
2. **Updated test expectations (intended by D-03 / X-1):** `test_gate_population_provenances_are_named_once` now expects `{production, human, historical}`. The real-population note in `test_gate_population.py` now lists `historical` and `paraphrased` as report-only, because the default population is still production and human.
3. **Precondition:** `GatePopulationConfig` was present, so the X-1 edit was made (it widens the `RealProvenance` Literal). Nothing was skipped.
4. **Additions beyond the plan text:** `default_quality_gates()` is the single source of the D-04 values. `manifest_hash()` is public for 05.3-06. Holistic metrics are also rejected in `judge.pass_threshold`.
