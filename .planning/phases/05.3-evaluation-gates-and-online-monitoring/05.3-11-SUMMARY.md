# Phase 5.3 Plan 11: Daily monitor aggregation Summary

## Accomplishments

- `0971_rag_monitor_aggregate.sql`: `rag_monitor_aggregate(p_day date) RETURNS integer` reads the log rows of one UTC day, derives each row's cell key and counters, joins online judge scores and answer records by trace id and tenant, builds the two 22-bin histograms per cell, and upserts `rag_monitor_daily` on its six key columns, returning the number of cells written. Cells without rows for the day are left as they are. `rag_monitor_days_to_aggregate(p_trailing integer DEFAULT 7) RETURNS SETOF date` lists the trailing days plus older days that still have log rows and no cell. Both are `SECURITY INVOKER`, `SET search_path = ''`, schema-qualified, revoked from PUBLIC, anon and authenticated, granted to service_role. Log, answer-record and judge-score references are `to_regclass`-guarded. The function writes counts and histograms only: no text column is read into the output.
- `tests/helpers/retrieval-log-seed.ts`: `seedRetrievalLog` inserts deterministic log rows per cell (tenant, UTC day, language, mode, channel, row count) with exact counts for refused / below-threshold, error / kb-unavailable, degraded, zero-result, votes, groundedness flags and judged traces, a top-score and latency distribution and a config hash; it creates the tenant's user, organization and per-doc-type document as needed and returns every seeded row (kind, vote, score kind and value, latency, document) for assertions. `seedRate(total, rate)` gives the exact count for a rate. Every draw comes from mulberry32 seeded from the spec's string (same generator as the backfill sampler). No natural-language content.

## Deviations

2. The plan's behaviour "one cell per combination" holds per (tenant, language, mode, channel, doc type): rows without a kept candidate form a separate `doc_type = 'unknown'` cell next to the document's cell. The test checks both cells exactly and that their sum equals the seeded counts.
3. `seededRandom` is not exported from `src/lib/rag/ingest/backfill/sample.ts` yet (plan 05.3-31); the helper carries a local mulberry32 with the same seeding, as the plan allows.
