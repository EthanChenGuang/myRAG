<objective>
Enforce the setting check on every writer of `.env.local` and record each RAG-affecting change (D-10, D-15, D-16).

Purpose: `enforce` must not be bypassable from any product surface, and every override is recorded with the config hash and the result (EVAL-23, success criterion 2).
Output: the config-server guard and its use in two routes and two proxies, the app guard and its use in three routes, tests for all five writers.

Orchestrator decision O-4: enforcement covers all five writers; the Config UI dialog (plan 05.3-42) covers the three Config UI paths; the in-app settings page shows the 409 through its existing error path. Planner resolution: in `warn` mode a record failure is logged and the save proceeds (warn never blocks, D-10); in `enforce` mode an override that cannot be recorded is refused (D-16), while a save with a passed check proceeds and logs the failed record.

Depends on 05.3-21 (gate core) and 05.3-22 (runner and check files in `scripts/config-server-rag-gate.js`). Rollout position: D-60 step 5. Trunk is changing under other sessions: re-read each writer before editing; never rely on a line number.
