## Deviations from Plan

1. **[Blocked must-have] The prechunked smoke tier is `report`, not `enforce`.**
   - The plan's stop rule applies: never mark a tier by hand, and never change quality-gates.json.
   - The tier fails only `false_refusal_rate`: overall 0.32, en 0.39, zh 0.33, against the 0.25 ceiling.
   - The cause is retrieval-level refusals, not the fixture composition or the fake generator. Strict empty retrieval under the legacy 0.65 rule on the fixture n-gram embedder refuses 48 of 150 answerable dev items before generation. Retrieval-only runs show the same rate (0.34 at HEAD).
   - `test_absolute_gate_measurement.py` therefore asserts the part the setting check depends on: every false_answer_rate row passed, and each mode is consistent with its measurement. It does not assert `mode == enforce`.
   - What would change it: the owner's H-10 decision, or a retrieval or floor change for the legacy fixture path in a later plan.
2. **[Rule 3] 13 near-miss items instead of 9.** The 9 of the research were recomputed on trunk and were not enough for the ingest-mode share.
3. **[Rule 1] Fake generator change** (05.3-14's deferred item). It answers unlabelled context in answers mode, in three context formats: prechunked `Document: … Content:`, ingest `--- Document: … ---`, and tagged `<doc>`.
4. **[Rule 4] Per-mode refusal cells kept out of `refusal-thresholds.json`**, as described in Key decisions. The `--write-thresholds` CLI path would have written them, so the write ran through the tool's Python entry with `targets_by_mode` unset.
5. **[Rule 3] Pins and tests outside files_modified**, because the corpus, the golden set and the default changed:
   - corpus and file counts in `test_fixture_pii.py`, `test_draft_sources.py`, `tests/eval-corpus.test.ts` and `relex.test.mts` (125 → 149);
   - the corpus hash in `test_corpus.py` and `fixture-phase42-corpus.test.mts`, plus that test's dump digests;
   - the manifest version in `test_golden_set.py`;
   - exclusions in `test_golden_phase4.py`, `test_gate_population.py` and `test_metrics.py` (corpus files);
   - the probe sentence cap in `test_finetune_pipeline.py`;
   - `--no-answers` in `eval-sec-overlay.test.mts` (it tests the retrieval-only stub path);
   - `answers: true` in `tests/rag-e2e/domain-parity-arm.mts`, so it runs like test-rag;
   - historical baseline comparisons in `test_metrics.py` and `ingest-mode-routing.test.mts` now read `history/fixture-ingest-baseline.pre-05.3-15.json`;
   - the refusal-cell rule tests in `test_phase42_gate.py` read the frozen `eval/tests/data/refusal-calibration-result.pre-05.3-15.json`;
