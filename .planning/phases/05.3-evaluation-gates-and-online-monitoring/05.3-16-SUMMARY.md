# Phase 5.3 Plan 16: Absolute gates in every CI tier Summary

**Every gated smoke run now carries the absolute gates of `eval/config/quality-gates.json`. Only `--no-gate` leaves them out. CI runs a tier report-only only where the committed measurement record says so, and the workflow lint enforces that. A new prompt control fails CI with exit 11 when the refusal directive is missing. pr-smoke verifies both golden manifests, and the nightly judge job runs the stale scan and the absolute gate in report mode.**
