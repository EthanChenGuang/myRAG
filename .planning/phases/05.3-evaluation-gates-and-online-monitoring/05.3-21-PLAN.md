## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser and CI to the save decision | a forged or stale `ragGate` body tries to pass enforcement |
| Admin route to the change-record table | records are the audit trail for overrides |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.3-211 | Spoofing | a `check_id` of another settings hash reused to pass enforce | high | mitigate | hash equality required in `decideSave`; fixture case |
| T-05.3-212 | Tampering | a corrupted or hand-written check file accepted | high | mitigate | uuid ids, schema validation, invalid reads as absent (fail closed) |
| T-05.3-213 | Information disclosure | setting values or prompt text in records or responses | high | mitigate | builder keeps names and hashes only; contract has no value field; test |
| T-05.3-214 | Repudiation | an override saved without a record | medium | mitigate | 503 `rag_gate_record_failed` when the insert fails; caller refuses the save (plans 05.3-22, 05.3-23, 05.3-51) |
| T-05.3-215 | Elevation of privilege | a non-admin listing or writing records | medium | mitigate | `checkAdmin` first; route test |
| T-05.3-SC | Tampering | npm/pip/cargo installs | high | accept | no package is installed by this plan |
