## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Monitor job to the operator's webhook URL | outbound request to an address set in the env file |
| Monitor job to Langfuse | scores attached to production traces |
| Admin browser to the run route | starts a full monitor run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.3-281 | Tampering | SSRF through `RAG_MONITOR_WEBHOOK_URL` | high | mitigate | https only, `assertPublicUrl` with DNS check on every delivery, no redirects |
| T-05.3-282 | Spoofing | forged alerts at the receiver, or replay | medium | mitigate | HMAC-SHA256 over timestamp and body with a 32+ character secret; timestamp header |
| T-05.3-283 | Information disclosure | text or the webhook secret in bodies or logs | high | mitigate | contract body without text; logs carry ids and channel status only |
| T-05.3-284 | Denial of service | repeated run requests | low | mitigate | admin guard; 404 when off; idempotent upserts |
| T-05.3-285 | Repudiation | host-side setting changes leaving no trace | medium | mitigate | `record-change`; unrecorded hash changes listed in alerts (plan 05.3-27) |
| T-05.3-SC | Tampering | npm/pip/cargo installs | high | accept | no package is installed by this plan |
</threat_model>
