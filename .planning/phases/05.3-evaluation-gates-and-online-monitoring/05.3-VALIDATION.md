## Sampling Rate

- **After every task commit:** quick command of the touched area, plus `npm run typecheck:new` (TypeScript) or the single pytest file (Python)
- **After every plan wave:** full suite + structural gates + both smoke tiers
- **Before `/gsd-verify-work`:** full suite green; smoke tiers and negative controls exit with the expected codes (70, 2, 12, 11, 10 ordering); defaults-equal check (all six 5.3 switches off ⇒ no rows written, paired retrieval differences exactly zero)
- **Max feedback latency:** 60 seconds per task
