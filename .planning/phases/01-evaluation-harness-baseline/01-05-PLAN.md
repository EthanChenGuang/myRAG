    - /ready is 503 not_ready with the secret unset, 503 with a 31-character secret, 200 ready with a 48-character secret
    - with the secret unset: /v1/info, /v1/unknown, /docs and /openapi.json all return 503 with a SidecarError body even when a header is sent
    - with the secret set: missing header 401, wrong header 401, header differing only in the last character 401, correct header 200 with SidecarInfo
    - /docs and /openapi.json return 401 without a header and 404 with the correct header (docs disabled)

  <action>
Per D-21:
- settings.py: Pydantic model `SidecarSettings` with `secret: SecretStr | None` read from RAG_SIDECAR_SECRET, `min_secret_length = 32`, and `version` from package metadata; `load_settings()` reads os.environ once; `secret_configured` is true only when the secret is at least 32 characters.
- auth.py: pure ASGI middleware `SharedSecretMiddleware(app, settings)`. Paths exactly `/health` and `/ready` pass through. For every other HTTP request: 503 SidecarError `sidecar secret not configured` when not configured; 401 SidecarError `unauthorized` when the `x-sidecar-secret` header is missing or its SHA-256 digest does not match the secret's under `hmac.compare_digest`. It never logs header values or request bodies.
- main.py: `create_app(settings: SidecarSettings | None = None)` builds `FastAPI(docs_url=None, redoc_url=None, openapi_url=None)`, adds the middleware, defines `GET /health` (SidecarHealth) and `GET /ready` (SidecarReady, 503 when not configured), and an `APIRouter(prefix='/v1')` with `GET /v1/info` returning SidecarInfo (service 'rag-sidecar', package version, contracts schema version 1). Module-level `app = create_app()`. No URL fetching, no file paths taken from input, no import of deepeval or ragas.
- Tests build apps with explicit settings via `create_app(SidecarSettings(...))` and use `fastapi.testclient.TestClient` or `httpx.AsyncClient(transport=httpx.ASGITransport(app))`; write them first and see them fail.
  </action>
