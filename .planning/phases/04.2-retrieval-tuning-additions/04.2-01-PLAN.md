<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Request body and eval items to the retrieval filter contract | `versions` is the first filter that widens what is searched |
| Admin input to the identifier pattern contract | Pattern text is attacker-shaped input for the server |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-01 | Tampering | `RetrievalFilters.versions` | medium | mitigate | Closed union (current, all, range) with date validation; `current_only` stays `Literal[True]`; unknown values rejected by `extra="forbid"` |
| T-04.2-02 | Denial of service | `IdentifierPattern` | medium | mitigate | Length and flag bounds in the contract (200 characters, flags u or iu); the regex safety checks themselves are in plan 04.2-14 |
| T-04.2-03 | Tampering | committed config files and hashes | medium | mitigate | Omit-when-unset serializers plus byte-identity and hash tests on the three committed configs |
| T-04.2-04 | Information disclosure | trace identifier block | low | mitigate | Counts, a fallback flag and at most 3 suggestions from the caller's tenant; the eval trace already carries chunk text |
| T-04.2-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
</threat_model>
