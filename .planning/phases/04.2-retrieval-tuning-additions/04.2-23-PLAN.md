<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server answers and admin input to the DOM | Pattern names, patterns, samples and matches are untrusted text |
| Admin pattern to the browser's regex engine | A slow pattern could freeze the tab |
| Config UI page to the app's admin routes | Same-origin requests through the config-server proxy |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-86 | Tampering | stored XSS through names, patterns, samples or matches | high | mitigate | `createElement` and `textContent` only; XSS payload tests; no `innerHTML` (acceptance grep) |
| T-04.2-87 | Denial of service | browser-side catastrophic regex | medium | mitigate | The browser compiles a draft only; matching runs on the server's worker (plan 04.2-14); test asserts no match call with an admin pattern |
| T-04.2-88 | Spoofing | credentials leaking from the page | medium | mitigate | `ragFetch` only, same-origin, no `Authorization` header, nothing in web storage or cookies |
| T-04.2-89 | Information disclosure | tenant key shown in the page | low | mitigate | No tenant key is ever displayed; `<key>` stays a literal in the commands |
| T-04.2-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
</threat_model>
