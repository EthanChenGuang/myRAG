- PGlite plan: never run at the same time as another fixture-database plan in the same tree.
- Commit with plain `git commit`; the message ends with the attribution lines the executor's own session supplies. Hand-off notes go to `.planning/phases/04.2-retrieval-tuning-additions/handoffs/04.2-37-<topic>.md`.
