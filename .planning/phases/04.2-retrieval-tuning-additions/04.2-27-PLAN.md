<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Question text to identifier resolution | User text decides a filter that narrows retrieval |
| One tenant's identifiers to another tenant's suggestions | Suggestions reveal stored identifiers |
| Retrieval result to the strict answer | A wrong identifier must never be answered |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-99 | Information disclosure | suggestions or resolve results from another tenant | critical | mitigate | Tenant only from `scopeKey`; SQL tenant predicate (plan 04.2-14); two-tenant suggestion test in both modes |
| T-04.2-100 | Information disclosure | identifier existence oracle within one tenant | low | accept | A user of the tenant can already retrieve that tenant's documents; nothing crosses tenants |
| T-04.2-101 | Tampering | answer about a look-alike identifier | high | mitigate | Pre-ranking filter, in-memory guard after rerank, strict refusal with suggestions; tests per spelling and distance class |
| T-04.2-102 | Information disclosure | identifiers in logs | medium | mitigate | Counts and a fallback flag only; suggestions only on the eval trace and in the user's own answer |
| T-04.2-103 | Denial of service | many identifiers in one question | low | mitigate | At most 16 resolved; guard is in memory; stage timeouts |
| T-04.2-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
</threat_model>
