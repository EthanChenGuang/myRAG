# Phase 04.2 Plan 17: identifier pattern admin routes Summary

**Admins can now list, create, update, delete and test identifier patterns for their own workspace through five owner-or-admin routes. The tenant always comes from `resolveAdminWorkspaceScope`, and no log line carries a pattern, a sample or a match.**

## Route contract (for 04.2-23)

Every route: `export const runtime = 'nodejs'`, `Cache-Control: no-store` on every answer, `checkAdmin` first, then the request is parsed, then the workspace is resolved, then the service is called. `organizationId` is the only workspace input (query string on GET and DELETE, body otherwise). Every body is `.strict()`, so a body that names `tenantKey`, `tenant_key`, `createdBy` or any other key answers 400.

Error shape: `{ success: false, error, details?: [{ path, message }] }`.

| Call | Request | Success |
| --- | --- | --- |
| `GET /api/rag/admin/identifier-patterns?organizationId=` | — | 200 `{ success: true, items: [{ id, name, pattern, flags, enabled, updated_at }], limits: { max_patterns: 20, max_pattern_length: 200, max_name_length: 80, max_sample_length: 10000 } }`, items in creation order |
| `POST /api/rag/admin/identifier-patterns` | `{ organizationId?, name (trimmed, 1..80), pattern (1..200), flags: 'u' \| 'iu', enabled?: boolean }` | 201 `{ success: true, item }` |
| `PATCH /api/rag/admin/identifier-patterns/{id}` | `{ organizationId?, name?, pattern?, flags?, enabled? }`, at least one of the four fields | 200 `{ success: true, item }` |
| `DELETE /api/rag/admin/identifier-patterns/{id}?organizationId=` | — | 200 `{ success: true, id }` |
| `POST /api/rag/admin/identifier-patterns/test` | `{ organizationId?, sample (0..10000), draft?: { id?: uuid, pattern (1..200), flags: 'u' \| 'iu' } \| null }` | 200 `{ success: true, matches: [{ raw, normalized, source, start, end }], tested: { pattern_ids: string[] }, truncated, total }` |

`item` is `{ id, name, pattern, flags, enabled, updated_at }`. `source` is `built_in`, `draft` or a saved pattern id. `start` and `end` are UTF-16 offsets into the sample as sent. `tested.pattern_ids` lists the enabled saved patterns that ran (a draft with an id removes that id). At most 500 matches are returned; `total` counts all of them.

| Status | `error` | When |
| --- | --- | --- |
| 401 | `Admin authentication required` | no credential (adminDenied) |
| 403 | `Admin access required` | signed in but not in `admin_users` (adminDenied) |
| 503 | `Admin verification is unavailable` | the admin lookup failed (adminDenied) |
| 403 | `Forbidden` | the admin is not a member of the named organization; no RPC is called |
| 503 | `Workspace verification unavailable` | the membership lookup failed |
| 400 | `Invalid request data` | schema failure, `details[].path` = `name`, `pattern`, `flags`, `sample`, `id`, `draft.*` or `''` (unknown key, empty PATCH body); invalid JSON: `details: [{ path: '', message: 'Body is not valid JSON' }]`; service `invalid_argument` uses the service field as path, `sample_too_long` uses `sample` |
| 400 | `invalid_identifier_pattern` | `details: [{ path: 'pattern', message: <finding code> }]`, one entry per finding (`too_long`, `invalid_regex`, `invalid_flags`, `backreference`, `lookbehind`, `nested_unbounded_quantifier`, `matches_empty`, `probe_too_slow`, `no_alphanumeric`); save and test alike |
| 409 | `limit_reached` | the 21st pattern |
| 409 | `name_exists` | duplicate name in the workspace (create or rename) |
| 404 | `pattern_not_found` | PATCH or DELETE of an unknown id or an id of another workspace |
| 503 | `Identifier patterns are unavailable` / `Identifier pattern test is unavailable` | `db_unavailable`, `backend_error`, `test_unavailable` or any other failure; the database message never appears |

Success log lines: `[RAG Admin]` with `{ action: 'create_identifier_pattern' | 'update_identifier_pattern' | 'delete_identifier_pattern', patternId }`, and for the test `{ action: 'test_identifier_patterns', patterns, draft, matches }` (counts and a boolean). Failure lines carry the error name, rpc, code and SQL state only.
