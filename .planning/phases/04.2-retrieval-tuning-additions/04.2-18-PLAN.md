<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Document text (tables, identifiers) to new stored columns and rows | Uploaded content becomes lookup data |
| One tenant's rows and identifiers to another tenant | Tenant data in new storage |
| PostgREST clients to the new functions | Service-role only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-65 | Information disclosure | rows or identifiers written or read across tenants | critical | mitigate | Tenant assertion first, tenant predicate on documents, chunks and rows, document-ownership check on every chunk id; two-tenant tests in both modes |
| T-04.2-66 | Elevation of privilege | new functions callable by anon or authenticated | high | mitigate | INVOKER, empty search_path, REVOKE and GRANT; fake-edge test and the static grants scans |
| T-04.2-67 | Denial of service | very large tables or many identifiers per chunk | medium | mitigate | Caps on rows, cells, cell length and array sizes with ERRCODE 22023; paging in the read function |
| T-04.2-68 | Information disclosure | cell values, headers or identifiers in logs | medium | mitigate | Counts, ids and error class names only |
| T-04.2-69 | Tampering | SQL built from cell or identifier text | high | mitigate | Values only inside one `jsonb` argument read with `jsonb_to_recordset` or `jsonb_array_elements`; no dynamic SQL |
| T-04.2-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
</threat_model>
