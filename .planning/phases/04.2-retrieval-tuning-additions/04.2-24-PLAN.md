<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Question tokens to a SQL lookup | User text becomes lookup values |
| One tenant's table rows to another tenant | Rows are tenant data |
| Model output to the database | No model may write or shape SQL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-90 | Information disclosure | rows of another tenant | critical | mitigate | Tenant assertion and predicate; tenant only from `scopeKey`; two-tenant test in both modes; matrix path in plan 04.2-30 |
| T-04.2-91 | Tampering | SQL built from user or model text | high | mitigate | Token arrays as bound parameters only; static rules `table-lookup-rpc` and `table-lookup-sql` in CI |
| T-04.2-92 | Denial of service | large token arrays or limits | medium | mitigate | Caps of 64 tokens, limit 50, min_cells 1..10 with ERRCODE 22023; GIN pre-filter; stage timeout |
| T-04.2-93 | Information disclosure | cell values or headers in logs or trace | medium | mitigate | Counts only in detail and counts |
| T-04.2-94 | Information disclosure | superseded rows under the default scope | medium | mitigate | Version rule of 0856 reused; scope current test |
| T-04.2-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan |
</threat_model>
