# 04.2-26 SUMMARY: version tag and 'also in' line in the sources panel

The app's sources panel now shows, for a document source or citation, which version the passage came from and which other
documents carry the same passage, exactly as UI-SPEC Addendum A describes. With the fields absent (switches off, sources
saved before this phase, web and tool sources) the markup is byte-for-byte what it was before; three file snapshots taken
before any component edit pin that.

- **Field names read, and where they come from:**

| Field | Listed source card (`Source`) | Citation entry (`SourceCitation`) |
| --- | --- | --- |
| `version` | payload item `version` (`sourceDocumentFields`, chat route: `query_documents` tool output `documents[]`, `metadata.usedDocuments[]`) | `CitationRecord.documentVersion`, copied only when the record also has `isCurrent` |

## Task 2: fields, view functions, components and strings

- `sourceVersionView(source, listHasSuperseded)` reads from `source.citation ?? source`. It returns null for a non-document
  source, a version that is not an integer ≥ 1, or a non-boolean `isCurrent`. It returns the Superseded marker for
  `isCurrent === false`, and the Current marker only when the list holds a superseded entry. Invalid dates (not `YYYY-MM-DD`,
  or not a real day such as `2025-02-30`) are dropped, and the phrase is `versionFromTo`, `versionFrom`, `versionUntil` or
  `versionOnly`.
- `sourceAlsoInView(source)` drops items without a file name, the entry's own document and repeats (first wins), keeps the
  received order, renders 50 names and counts the rest.
- `SourceVersionTag`: the A.3 markup; `{from}` / `{to}` placeholders in the strings become
  `<time dateTime>` elements formatted with `Intl.DateTimeFormat(language, { dateStyle: 'medium', timeZone: 'UTC' })`.
- `SourceAlsoIn`: native `details`/`summary`, the focusable, labelled `ul` region (`max-h-40`), `translate="no"` names, counts
  with `Intl.NumberFormat(language)`.
- Placements: citation entry, tag after the location line and before the quote, also-in last (`mt-2`); a Superseded
  tag suppresses `documentUpdatedOrRemoved`. Listed card, tag under the title block and before "Uploaded:", also-in last in the
  text column (`mt-2`), or for a linked card directly after the `<a>` inside `div[data-source-item]` (`px-5 pt-2`).
- `SourcesSidebar` computes `listHasSupersededEntry(sources)` once and passes it to both entry kinds.
- `chat-message.tsx`: two `...documentSourceFields(doc)` spreads and the import, nothing else (open PR #119 also edits it).
