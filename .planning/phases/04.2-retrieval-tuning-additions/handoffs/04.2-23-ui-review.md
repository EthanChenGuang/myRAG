## Priority fixes

### BLOCKER
None. No defect found that prevents completing add/edit/toggle/delete/test.

### WARNING
1. **Row actions clipped below 768px** (06-narrow-375). `identifier-patterns.js:1228` puts `whitespace-nowrap` on the actions wrapper and the buttons are 48px `btn` with full labels ("Disable pattern"); at 375px the table overflows and Edit/Disable/Delete show as "Ed", "Disa", "Del" until the admin scrolls the table sideways, while the Name column collapses to one word per line. Spec 10 asks for actions that "wrap under each other" inside the row. Fix: drop `whitespace-nowrap` below md (`md:whitespace-nowrap`), give the Actions cell `max-md:w-0`/let the name column keep `min-w-[..]` via a scale width (e.g. `max-md:min-w-32` on the Name `th`), or move the actions under the name on mobile as the pattern line already is.
2. **Info alerts centre their content on narrow screens** (06-narrow-375). DaisyUI 4 `.alert` is `text-align:center; justify-items:center` below `sm`; `items-start` (lines 995, 1003) does not undo that, so the icon floats alone above centred prose. Spec 6.3 wants a left-aligned line with icon. Fix: add `text-left justify-items-start sm:grid-flow-col` / `grid-flow-col` on both notes (and on the alert-host alerts).
3. **Status region visibly repeats the test summary** (01, 02, 06: "Identifiers found: 4. Stored forms: 2." at the panel foot). The region at line 791 is visible text, so every outcome appears twice and the orphan line under the card reads as stray copy. Spec 9.8 requires the announcement, not a second visible copy. Fix: make the status region `sr-only` for announcements that duplicate on-screen text, or keep it visible only for outcomes not shown elsewhere (saved, deleted, errors).
4. **Delete dialog title reads as one run-on phrase** (04: "Delete pattern Two groups of four letters?"). `confirm.delete.title` (lines 145, 283, 423) concatenates the admin's name with no delimiter, so a name starting with a common word becomes ambiguous. Fix: quote it — `Delete pattern “{name}”?`, `删除模式“{name}”？`, `Eliminare il modello «{name}»?` — and the same for the row-action aria labels if they share the shape.
5. **zh description shows a space between the two sentences** (07: "…互相匹配。 对本部署生效。"). Line 894 only omits the space when `this.locale === 'zh'`; the captured zh render still has it, so the locale the description is built with is not the panel locale at that moment (or the description is not re-rendered on language switch). Fix: re-run the description render on locale change and assert it in the zh test.
6. **Info alerts dominate the dark theme** (01-04). Two `alert-info` blocks at full saturation (~#00B5FF) sit above the toolbar and outweigh the h3 and the table, breaking the 60/30/10 split; the rebuild note's `code` chips are dark-on-bright and are the hardest-to-read text in the panel. Tokens are as contracted, so this is a WARNING on visual weight, not a contract breach. Fix: `alert-info` with `bg-info/10 border border-info/40 text-base-content` (icon keeps `text-info`), which also fixes chip contrast.

### NIT
- Pattern code in the list breaks mid-token (`\d` / `{4}` on separate lines, 01) due to `break-all` at a narrow Pattern column; acceptable per contract, but a wider Pattern column (`min-w-40`) would avoid it at 1024px+.
- "Keep pattern" / "Keep editing" render as near-invisible plain `btn` on `modal-box` in dark (04); consider `btn-outline` for a clear affordance (contract allows `btn`).
- Stale line and scope line are stacked with no gap (02: "The patterns or the sample changed…" directly above "Tested with…"); add `mb-1`.
- 768px: Italian toolbar and labels fit (08), no finding.

## Detailed findings

### 1. Copywriting (3/4)
- All keys in sections 12/8.2 are present in three locales; no generic labels (no Submit/OK/Cancel); every button names its object ("Save pattern", "Keep pattern", "Refresh patterns").
- Findings are full sentences with a remedy (02: nested-quantifier finding gives `{1,20}`). Domain-neutral shapes only.
- Deductions: fixes 4 and 5 above.

### 2. Visuals (3/4)
- Reading order and region separation match 6.3 (mt-6 between list, form, test; form/test regions `bg-base-100 rounded-lg p-4`). Marked sample uses weight + underline (not colour alone). Status badges carry icon + word.
- Deductions: fixes 1, 2, 3.

### 3. Color (3/4)
- `btn-primary` only on Save pattern (1441) and Run test (1694); no `myrag-primary`; error colour only on icons/borders (859, 1569, 1881) with base-content sentences; Delete uses `btn-error` outline in rows, solid in dialog.
- Deduction: fix 6.

### 4. Typography (4/4)
- Sizes: text-xs (19), text-sm (19), text-lg heading, text-base only for sub-headings; weights semibold/normal only. Counts `tabular-nums` (1439). Light theme (05) holds hierarchy.

### 5. Spacing (4/4)
- Spacing classes: gap-2 ×17, mb-4 ×7, mt-1 ×8, mt-2 ×5, mt-4 ×3, mt-6 ×2, py-8 ×2, p-4 ×2, p-2, pl-8; `px-1` only on the accepted ledger chips. No arbitrary `[..px]`.

### 6. Experience Design (3/4)
- Present: list loading/refresh dimming, aria-disabled Add at limit, local+server findings with aria-invalid and focus, discard dialog, beforeunload (1383/1386), stale result dimming (02), empty state (07), sign-in/workspace/unavailable alerts, no innerHTML (count 0), no storage/console use for sample.
- Deductions: fixes 1 and 3 (mobile task friction, double announcement text).
