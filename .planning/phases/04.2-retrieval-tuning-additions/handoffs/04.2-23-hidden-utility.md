# Hand-off from 04.2-23: `hidden md:table-cell` never shows in the Config UI

`scripts/config-ui/index.html` defines a page-level rule `.hidden { display: none !important; }` (inside the page's own
`<style>` block). The `!important` beats every Tailwind responsive display utility, so the pattern
`hidden md:table-cell` / `hidden lg:table-cell` used by several RAG administration panels keeps the cell hidden at every
width. Measured with Playwright at 1280px: computed `display: none` on such a `th`.

Panels that use the pattern today (count of occurrences): refusal-calibration.js 9, upload-approvals.js 15,
review-labelling.js 8, versions-dates.js 5, languages.js 4, scope-tags.js 4, chunking-profiles.js 2,
embedding-bindings.js 2, ingest-impact.js 2, quarantine.js 2, review-admin.js 2.

04.2-23 avoided it in `identifier-patterns.js` with `max-md:hidden` / `max-lg:hidden` and a test that forbids
`hidden md:` / `hidden lg:` in that file.

Suggested follow-up (not done here: it changes every sibling panel's layout and needs its own visual check): replace the
`hidden md:table-cell` pairs with `max-md:hidden` in those files, or scope the page rule to the ids that need it
(for example `#save-indicator.hidden`).
