# Hand-off from 04.2-23: RAG proxy path bug fixed (affects every Config UI admin panel)

`scripts/config-server.js` registers `app.all('/api/rag/*path', …)`. Under Express 5 (`express` 5.1.0 in the lockfile)
`req.params.path` is an array of segments, and `buildRagProxyTargetPath` did `String(pathParam)`, which joins with commas.
Every multi-segment proxied path reached the app as `/api/rag/admin,<name>…` and answered 404, so the RAG
administration panels could not load through the Config UI server. The existing proxy tests checked status and headers
only, against a stub that answers 200 for any URL.

Fixed in commit 6c5ab22c (join the array with `/` before the dot-segment checks). The new test in
`tests/ui/config-rag-panels.test.ts` asserts the forwarded URL and method for PATCH and DELETE and failed on the old code.

Operator note: Config UI deployments started before this fix should be restarted after the merge.
