# 04.2-12 hand-off: no-answer identifier_near_miss items and the GoldenItem category rule

For: plan 04.2-37 (golden items) and the owner of `rag-sidecar/src/rag_sidecar/contracts/golden.py`.

D-32 and 04.2-37 call for 2 `identifier_near_miss` items per language whose asked identifier does not exist
(`answerable: false`). `GoldenItem._check_rules` rejects them today: "category no_answer or small_talk if and only if
answerable is false".

The 04.2-12 scorer already handles an unanswerable `identifier_near_miss` item (precise = refused and no near-miss
chunk kept). The unit test builds such an item with `model_copy` to bypass validation.

Before adding the items, 04.2-37 has to choose one of:
1. Admit `identifier_near_miss` with `answerable: false` in the rule (contract change, `npm run gen:schemas`), or
2. Write them as `no_answer` items. The identifier block then does not count them, because it counts the
   `identifier_near_miss` category only, so precision and leakage on the no-answer half would need a scorer change.

Option 1 keeps the gate in 04.2-31 (precision 1.0 and leakage 0.0 on `identifier_near_miss`) covering all 18 items.
