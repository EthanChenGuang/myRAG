# 04.2-02 hand-off: zh and it for the retrieval tuning switch box (for plan 04.2-25)

Date: 2026-11-26. The 3.2 `data-rag-i18n` mechanism is present on this tree (panels apply it per group, e.g.
`IngestImpactPanel.localizeSettings`), so the static English markup of `#rag-tuning-switches` already carries the UI-SPEC 12.2 keys:
`heading`, `intro`, and `<VAR>.label` / `<VAR>.help` for the eight variables.

Nothing applies them yet: no script is added by 04.2-02 (static markup only). Plan 04.2-25's
`rag-panels/retrieval-tuning-switches.js` should hold `RETRIEVAL_TUNING_LABELS { en, zh, it }` from UI-SPEC 12.2 and localize the box.

Two keys hold mixed content and need a placeholder-aware fill, not `textContent`:
- `intro`: four `code[translate=no]` tokens (`--dry-run`, `<key>`, `s:default`, `o:<organization id>`).
- `RAG_RESULT_DIVERSITY.help`: three `code[translate=no]` tokens (`off`, `collapse`, `mmr`).

Every `.label` key sits on an inner span, so a `textContent` fill keeps the `(<span translate="no">RAG_…</span>)` suffix.
