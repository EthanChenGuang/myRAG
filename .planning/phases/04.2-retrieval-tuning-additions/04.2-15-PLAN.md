## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Request body (chat, embed, eval) to the retrieval scope | `versions` is the only filter that widens |
| Anonymous embed visitors to superseded text | Embed requests are unauthenticated |
| Cached answers to later requests | A history answer must not be served to a current-version question |
