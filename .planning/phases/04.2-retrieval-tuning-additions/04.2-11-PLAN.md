## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Voice agent to the app's internal timing route | A network caller writes numbers onto a trace |
| Timing route to Langfuse | Scores are written with the app's credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-36 | Spoofing | voice-timing caller | high | mitigate | Constant-time internal key check plus a valid signed voice scope token, as voice-rag; tested for missing and wrong credentials |
| T-04.2-37 | Tampering | forged or absurd timing values | medium | mitigate | Strict Zod body, 32-hex trace id, integer bounds 0..120000, pre-generation not above TTFT, fixed score names, idempotent score ids |
| T-04.2-38 | Information disclosure | timing log line | low | mitigate | Trace id and two numbers only; no transcript or answer text |
| T-04.2-39 | Denial of service | timing post slowing the voice turn | medium | mitigate | Fire-and-forget with a short timeout and swallowed errors; tested with a failing server |
| T-04.2-SC | Tampering | npm/pip/cargo installs | high | accept | No new package; `npm ci` installs the agent's existing lockfile only |
</threat_model>
