  <behavior>
    - normalizeIdentifier: full-width letters and digits fold to half-width (NFKC), case folds to lower case, whitespace and `-`, `_`, `.`, `/` are removed; two synthetic spellings of one identifier that differ only by separators, case or width normalize to the same string; the empty result is returned as the empty string.
    - damerauLevenshtein: 0 for equal strings; one substitution, insertion, deletion or adjacent transposition is 1; an optional maximum stops early and returns a value above the maximum.
    - isNearMissIdentifier(askedNorm, otherNorm): false when equal; true for distance 1 when the asked length is at most 6; true for distance 1 or 2 when longer; false otherwise.
    - Every case of `tests/fixtures/identifiers/near-miss-vectors.json` (two spellings, the expected normalized forms, the expected distance and the expected near-miss verdict; at least 20 synthetic cases covering width, case, each separator, transposition, both length classes) passes; the eval's Python twin reads the same file in plan 04.2-12.
    - splitAtIdentifiers(text) without extra patterns returns exactly what it returns today (existing cases untouched). With extra patterns, matches of all patterns merge leftmost-longest into one ordered piece list with no overlap.
