## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser (Config UI) to admin routes | Admin session cookie, untrusted body |
| Admin of one organization to another organization's patterns | Workspace isolation |
| Admin sample and pattern text to logs | Samples may contain real identifiers |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-61 | Elevation of privilege | non-admin caller reaching pattern writes | high | mitigate | `checkAdmin` first in every handler; tests for no session and a non-admin user |
| T-04.2-62 | Information disclosure | patterns of another organization | high | mitigate | `resolveAdminWorkspaceScope` answers 403 for non-members; the RPC tenant comes only from the scope; two-organization tests in both modes |
| T-04.2-63 | Denial of service | large sample or catastrophic draft on the test route | medium | mitigate | 10000-character cap in the schema; drafts validated and run only in the worker of plan 04.2-14; match cap with `truncated` |
