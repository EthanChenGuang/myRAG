## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin input (pattern, sample) to the server's regular-expression engine | JavaScript has no regex timeout |
| One tenant's patterns and identifiers to another tenant | Patterns, resolve results and suggestions are tenant data |
| PostgREST clients to the new functions | Service-role only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.2-48 | Denial of service | catastrophic admin pattern | high | mitigate | Static rejection of backreferences, lookbehind and nested quantifiers; probe and test execution only in a worker terminated at a deadline; caps of 20 patterns, 200 characters, 10000 sample characters, 500 matches; tested with a pattern that passes the static checks |
| T-04.2-49 | Information disclosure | patterns, resolve or candidates across tenants | critical | mitigate | Tenant assertion and predicate in every function; two-tenant tests in both modes; tenant-keyed cache with a two-key test |
| T-04.2-50 | Information disclosure | identifier existence oracle through the test operation | medium | mitigate | The test operation reads only the sample and the tenant's patterns; it never queries stored identifiers |
| T-04.2-51 | Information disclosure | pattern or sample text in logs | medium | mitigate | Ids, counts and error names only; hot-path log test |
| T-04.2-52 | Elevation of privilege | functions callable by anon | high | mitigate | INVOKER, empty search_path, REVOKE and GRANT; fake-edge test and static scans |
| T-04.2-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed; `node:worker_threads` is built in |
