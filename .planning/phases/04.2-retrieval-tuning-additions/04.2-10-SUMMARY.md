# Phase 4.2 Plan 10: TTFT on chat, embed and eval, the budgets, and the CI pre-generation gate

**Chat and embed now record the receipt time, the start of generation and the first answer text delta on the retrieval collector, plus the cache state. The same stream wrapper times every answer path: the model answer, the strict refusal, the knowledge-base-unavailable part and a cache hit. The eval route returns the three fields and the effective lexical version. A node:test gate fails CI when the pre-generation p95 of chat, embed or voice-rag goes above its budget, and its meta-tests show the failing direction.**

## Task 1: upstream gate and the cache branch

- The SUMMARYs of 04.2-02 and 04.2-08 exist, and `withFirstTextDelta` and `effectiveLexicalVersion` are exported from `src/lib/rag/index.ts`. No hand-off note was needed.
- **Cache branch: present.** `streamCachedAnswer` (`src/lib/rag/cache/hit-stream.ts`) and the semantic-cache check (`isCacheHitResult` / `result.cacheHit`, `result.cacheTicket`) exist on this branch. The hit path wrote the stored answer as **one** text delta, so Task 3 changed it to stream in chunks (D-27). No `04.2-10-cache-hit-stream.md` was written.

## Chat-route sites wrapped (by symbol)

- `POST`: `const requestReceivedAt = Date.now()` is the first statement. `startRequestTiming`, `markGenerationStart` and `timeFirstText` are small closures next to `finishRagTrace`.
- Both `ragTrace = { collector, result }` sites (query and overview retrieval) call `startRequestTiming(collector, result)`, which runs `markRequestStart(requestReceivedAt)` and `setCacheState(traceCacheState(result))`.
- `await awaitPreGenerationDelay(); markGenerationStart();` runs right before the `citationSession.startClaude` / `startOpenRouterStream()` decision, so it applies to the direct Claude call and to OpenRouter (the first mark wins, so the Claude-to-OpenRouter fallback does not count twice).
- All four `return createUIMessageStreamResponse({ stream })` returns became `{ stream: timeFirstText(stream) }`: the cache hit (`streamCachedAnswer`), the knowledge-base-unavailable error part, the strict refusal `text-delta`, and the main stream (`writer.merge(gate.stream)` / `writer.merge(result.toUIMessageStream(...))`).
- A turn without a collector (no retrieval ran) returns the stream unchanged and records nothing.
- No chunk is added, removed or changed, and no model callback is used. History trimming and prompt assembly were not touched.

Embed: the receipt time comes first and is marked after `pendingTrace = { collector, result }`. The same wrapper covers `knowledgeBaseUnavailableResponse(request, collector)`, the cache-hit stream and the model stream. The model stream used to be `result.toUIMessageStreamResponse(...)`. It is now `createUIMessageStreamResponse({ stream: timeFirstText(result.toUIMessageStream(...)), headers })`, which is the same composition the SDK uses inside `toUIMessageStreamResponse` (checked in `node_modules/ai/dist/index.mjs`).

## Deviations from Plan

1. **Files outside the list:** `src/lib/rag/cache/hit-stream.ts` (D-27 chunking, as the plan allows for a one-block hit), and `src/lib/rag/trace/ttft.ts`, `src/lib/rag/deps.ts` and `src/lib/rag/index.ts` for two shared helpers: `traceCacheState(result)` and `currentLexicalVersion()`. Routes may import only from `@/lib/rag`, and `getRagDeps` is not exported there.
2. **Embed test fakes:** three test files stubbed `toUIMessageStreamResponse` (`embed-cache`, `embed-query-layer`, `embed-stream-token`). They now stub `toUIMessageStream` instead, with the same assertions on the model's answer and the token metadata.
3. **Voice meta-test:** voice-rag makes no generator call, so the delay setter cannot reach it. The voice meta-test applies the same check to measured samples shifted by the budget plus 50 ms. Chat and embed use the setter end to end.
4. **Gate harness:** the gate is a node:test file, so it cannot use module mocks. It serves the fake model by intercepting `fetch` to the OpenRouter completions URL. It also unrefs timers that would otherwise keep the process alive: module-level `setInterval`s created while the route modules load, and timers of 60 s or more armed during the run (the chat route arms a ref'd five-minute MCP cleanup timer in `onFinish` on every turn). No production code was changed for this.
5. **Eval ttft:** the eval answer comes from `generateText`, so `ttft_ms` there is receipt to the complete answer. The eval route makes no stream.
6. **Unsampled log line:** on the cache-hit and refusal paths `finishRagTrace()` runs before the stream is created. Their `[RAG Trace]` line (unsampled path) therefore shows `ttft_ms: null`. The Langfuse export is built after the response and carries it. The main chat and embed paths finish the trace after the stream and log `ttft_ms` (the gate asserts this).

## Decisions for STATE

- The cache state on the trace comes from `traceCacheState`: hit, miss (ticket), otherwise bypass. Voice never gets a ticket, so it reports bypass.
- `pre_generation_ms` is recorded only when a generator is called.
- A cache hit streams in deltas of four words, which concatenate exactly to the stored text.
