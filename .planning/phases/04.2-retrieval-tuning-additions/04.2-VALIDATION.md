# Phase 4.2 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Source: `04.2-RESEARCH.md` § Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest (`tests/**/*.test.ts`); `node:test` via tsx (`tests/*.test.mts`, `tests/rag-db/*.test.mts`, `tests/rag-e2e/*.test.mts`); pytest (`eval/tests`, `rag-sidecar/tests`); `node:test` in `voice-agent/test/` |
| **Config file** | `vitest.config.ts`, `eval/pyproject.toml`, `rag-sidecar/pyproject.toml` |
| **Quick run command** | `npx vitest run <file>` · `node --import tsx --test <file.mts>` · `uv run --directory eval pytest -q tests/<file>.py` |
| **Full suite command** | `scripts/ci/local-pr-smoke.sh` plus `node --import tsx --test tests/rag-db/*.test.mts` and the phase gate tool on both fixture modes |
| **Estimated runtime** | per task file < 30 s; full suite ~15 min |

---

## Sampling Rate

- **After every task commit:** the task's own test file(s)
- **After every plan wave:** `npx vitest run`, `node --import tsx --test tests/rag-db/*.test.mts`, both pytest runs, `node scripts/check-config.mjs`, `npm run gen:schemas && git diff --exit-code`, `npx tsc --noEmit -p tsconfig.json`
- **Before `/gsd-verify-work`:** full suite green, plus `python -m rag_eval.phase42_gate` on both fixture modes
- **Max feedback latency:** 60 seconds per task
