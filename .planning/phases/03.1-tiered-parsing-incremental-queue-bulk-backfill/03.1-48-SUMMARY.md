# Phase 3.1 Plan 48: rag:backfill command Summary

`npm run rag:backfill` inventories a folder, bucket or manifest, runs a seeded stratified dry-run sample, stores and prints a projection report (class shares, pages per tier, L2/L3 pages, premium/L3/embedding cost at sync or batch price, wall time, sample size per class), refuses to run without a fitting `--budget`, then enqueues at priority 10, monitors, prints an end report that keeps dry-run sample jobs out of every ingest count, and resumes a killed batch without reprocessing.
