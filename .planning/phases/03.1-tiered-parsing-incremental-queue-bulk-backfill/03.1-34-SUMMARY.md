# Plan 03.1-34 Summary

**parse-external now serves `native` and `premium` modes with guarded LlamaParse, cache writes, and per-page responses for the worker.**

## Accomplishments

- **Native (`native.ts`):** Dispatches `.md`/`.txt`/`.csv` through `parsePlainText`, images through `captionImage`, returns `failed`/`unsupported_mode` for html/docx; caches under parser `plain_text` / version `native`.
- **Premium (`premium.ts`):** Validates `subpdf_ref` under `{tenant}/_parse-cache/{file_sha256}/`, reads page mapping from `cursor` JSON, runs `reservePremium` once per job attempt (reuses `stage_state.parseExternalPremium`), calls LlamaParse v2, maps sub-pages to originals, settles/releases budget, returns `pending` with HMAC continuation (`premium-continuation.ts`).
- **`parse-external.ts`:** Mode dispatch; premium skips loading the full original via `buildQueuedContext({ withOriginal: false })`.
