<objective>
Write the state-change half of the ledger API and the optional Realtime broadcast (D-01, D-02, D-04, D-05, D-15, D-24, D-29, D-43, D-55, A-1).

Purpose: "one run has exactly one state authority" (D-01). Every stage the worker or the app runs for a queued job is recorded through these functions, each guarded by the lease owner, so a stale worker cannot overwrite the new owner's state. The Realtime channel policy is the only gate between a browser and another tenant's job status (03.1-38 derives the topic on the client), so Task 3 proves its predicate as the authenticated role, not only that it exists.
