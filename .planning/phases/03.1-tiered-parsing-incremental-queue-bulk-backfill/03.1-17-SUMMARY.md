# Phase 03.1 Plan 17: Ingest outbound clients and fakes Summary

**Sidecar worker outbound stack: typed PostgREST ledger client, Storage REST wrapper, rate-limited app callbacks, and faithful in-memory fakes.**

## Performance

- **Duration:** ~25 min

## Accomplishments

- `supabase_headers` supports legacy JWT service keys and `sb_secret_` keys on `apikey` only (F-7).
- `LedgerClient` is the sole Python module calling `/rest/v1/rpc/` for claim, heartbeat, advance, fail, and parse-cache functions; errors map to `LeaseLost`, `Refused`, and `Transient`.
- `StorageClient` downloads originals and uploads cache objects only under SQL-registered prefixes; object names cannot contain `/` or `..`.
- `AppClient` posts internal detect/parse/advance routes with `x-sidecar-secret`, retries transient failures with the same body, and gates throughput with `TokenBucket`.
- `ingest_fakes` provides `FakeLedger`, `FakeStorage`, `FakeApp`, and `FakeClock` plus a global conversion counter for later D-21 tests.
