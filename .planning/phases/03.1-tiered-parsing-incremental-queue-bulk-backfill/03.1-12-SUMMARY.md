# Phase 03.1 Plan 12: Merge, sub-PDF, cache keys Summary

**Pure `rag_sidecar.ingest` helpers make per-page routing safe: invariant-checked Docling merges, pypdfium2 sub-PDF cuts, and canonical cache hashes in one module.**

## Accomplishments

- `merge` validates tiling, expands gapped slices, concatenates in page order, and asserts `merge_invariant` post-conditions.
- `premium_part` turns per-page LlamaParse markdown into Docling items with original provenance pages.
- `slice_pages` delegates to `DoclingDocument.filter`.
- `cut_subpdf` extracts selected pages with a sub-page→source map.
- `options_hash` / `merged_options_hash` hash canonical JSON with an allow-list that rejects chunker keys.
