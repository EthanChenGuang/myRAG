# Phase 3.1 Plan 44: Parser metrics per tier and page-tier accuracy per layer Summary

**Offline routing report for L1, L1+L2 and L1+L2+L3 over every parse fixture, and an eval module that scores each recorded tier (1 - CER, table cell F1, reading order, headings F1, s/page and cost/page with source) and reports page-tier accuracy per layer combination as a ParserEvalReport.**

## Accomplishments

- **Routing report (`rag_sidecar.preflight.report`).** Runs `run_preflight` with the recorded range converter three times per fixture. L1+L2 passes the pages through the L3 hook unchanged; L1+L2+L3 calls `l3_refine` with `RecordedVlmApp`, which answers from `recorded/<sha>/vlm/page-N.json` and leaves unrecorded pages out (no network); L1 replaces whatever L2 concluded with the fixture's own L1 signals. Each page records tier, preset, signals and the layer that decided it, plus doc class and L2/L3 page counts. No timings, so the bytes are stable. `--no-l2` keeps only L1, `--no-l3` drops L1+L2+L3, `--fixture` selects fixtures.
- **Parser eval (`rag_eval.parser_eval`).** A small Docling JSON reader (body order, text and heading labels, `table_cells`) and a premium markdown reader (`#` headings, pipe tables, paragraphs); no docling import in eval. Metrics: text similarity summed per page as 1 - edits/reference chars after NFKC and whitespace normalisation (Levenshtein by banded DP that doubles the band, checked against the full table); cell micro-F1 on (row, col, case-folded text) multisets; share of anchor pairs in order (exact key first, then prefix); headings F1 on (level, text). Seconds and USD per page come from `costs.tier` in the routing data (structured_* use the structured entry), with source and as-of date in the details.
- **Page-tier accuracy.** For each combination in the routing report: pages, tier and preset accuracy, pages above their tier, and the list of pages below it (fixture, page, expected and routed tier and preset, layer). A scored fixture missing from the routing report, or pages that do not match, is an error.
- **Reports on the current fixtures.** All three combinations route all 26 scored pages to their expected tier and preset (0 below). Test-set scores: fast text 0.63 / tables 0.00; structured_full text 0.92 / tables 1.00; structured_ocr tables 1.00; premium text 1.00 on its four fixtures.
