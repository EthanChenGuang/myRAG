# Phase 03.1 Plan 40: Tiered flow in the worker Summary

**Tiered routing now runs end to end: the worker probes a PDF, parses each page range at its own preset with a per-range parse cache, checks and records every attempt, merges the ranges in page order and hands one cached merged entry to advance; the mixed fixture sends only its table and scanned pages to structured parsing.**

## Performance

- **Duration:** about 4 h
- **Completed:** 2026-11-24T23:32Z
- **Tasks:** 3 (plus 9 fix/test pairs found by the end-to-end test)
- **Files modified:** 20

## Accomplishments

- `tiered.run_tiered`: preflight in the priority pool, full `PreflightResult` stored under the cache prefix as `preflight_ref`, advance to parsing with doc_class, page_ranges, tier_page_counts, detect_counts; each range is a cache entry keyed by (job, parser, version, options hash with the page set); L2 fast conversions are reused and cached; backfill ranges go to the pool in slices of at most 24 pages; every range is checked and recorded as an attempt (tier, preset, parser, version, pages, reason, ms, est_cost_usd, check); ranges are merged with the 03.1-12 invariants, chunked once, cached as `merged` (hash over the ordered range entries) and handed to advance. A single range skips `merge()`.
- A reclaimed job resumes from `preflight_ref` and the range entries (converter counter unchanged for finished ranges) and records no attempt twice.
- Dispatch by type: txt/md/csv and images through parse-external native, docx/html as one native range and pptx/xlsx as one structured range converted in the worker, PDFs through the range flow; an unknown type fails `unsupported_type`; an encrypted PDF fails `encrypted_pdf` at once. Fixed routing is untouched.
- Premium ranges: sub-PDF of only the premium pages under the tenant cache prefix, `parse-external` premium with polling, page texts become a Docling part with original page numbers. A range the guard blocks is parsed `structured_full`: budget/page-cap blocks mark its pages and the job `needs_review`; a cloud-policy block ends `ready` with `routing_note`.
- Dry-run jobs stop after checking: attempts, per-page tiers and cached ranges, no merged entry, no advance, no document row; status `ready`.
- Worker loop, `run_once` and `main.py` now give process_job a storage client, the pool and a converter factory (they had none).
- SC1 e2e through both services: ledger shows fast 1-6, structured_full 7-8, structured_ocr 9, fast 10; published pages 1..10 in order; table chunks on pages 7 and 8 start with the header row; headings continue across range boundaries; no LlamaParse request; bench-100 tier counts 97 fast / 3 structured.

## Decisions Made

See key-decisions. The attempt cost key is `est_cost_usd` (the contract field, extra keys are refused when a row is read back); SQL 0353 reads `est_cost`, so per-attempt cost is not accumulated by the function. The worker writes the total as `est_cost_usd` through the advance fields instead.

### Plan differences

- **Four ranges, doc_class:** the plan's e2e expects doc_class `mixed`; D-12 says `mixed` needs scanned and digital pages each above 10%, and the fixture has exactly 10% scanned, so the class is `tables` (asserted). The four ranges of the plan hold only after fix 1.
- **Dry run ends stage `ready`, not `check`:** `rag_ingest_job_status_for_stage` maps `check` to `checking`, so `rag_advance_ingestion_job` refuses stage `check` with status `ready`. The job passes through `check` (timing recorded) then ends `ready`; `stage_state` carries `{"dry_run": true, "ended_at": "check"}`.
- **Test-only changes to existing tests:** `test_tiered_routing_is_not_handled_by_this_job_function_yet` now asserts the new behaviour (`worker_not_configured` without storage).
- **e2e object store:** the test calls `resetObjectStoreForTests()` so the app uses the edge-backed Supabase store the worker writes to over HTTP (the in-memory fake is invisible to the worker).
- **Failed ranges:** a range whose check fails ends `needs_review` with job reason `quality_check_failed` until 03.1-42 adds escalation.

**Total deviations:** 7 auto-fixed (5 bugs, 1 missing critical, 2 blocking groups) plus the plan differences above.
