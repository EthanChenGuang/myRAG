SET search_path = public` function, `VOLATILE`, called via PostgREST `POST /rpc/...` (RESEARCH Pattern 1, lines ~582-640 — copy the `rag_claim_ingestion_jobs` body verbatim: `FOR UPDATE SKIP LOCKED`, `lease_until`, `locked_by`; F-11 lock the batch row first).
- A-6: cache/ledger/budget functions take `p_job_id` and resolve `tenant_key` inside SQL from `ingestion_jobs`; never accept a tenant argument.
- RLS enabled on `ingestion_jobs` with service-role-only policy; direct table writes from TS must fail the 03-04 boundary check.
- Single/multi-tenant variant files follow 03-01's `.single-tenant.sql` / `.multi-tenant.sql` split; then fold into both setup files per 03-47 and extend `tests/rag-db/schema-equality.test.mts`.
- Realtime: `realtime.send` call inside the transition function (RESEARCH "Supabase Realtime broadcast", ~L935) guarded so PGlite (no `realtime` schema) still loads (Pitfall 11).
- Budget month in UTC (Pitfall 6); reservations released on terminal transition (Pitfall 5).

### Env sync (five places + manifest)
