# Phase 03.1 Plan 06: Cross-language harness primitives Summary

**Fake edge now hosts Storage REST with F-7 key rules, plus an ingest callback HTTP shim and a sidecar module launcher for worker end-to-end tests.**

## Performance

- **Duration:** ~45 min

## Accomplishments

- Added `/storage/v1/object/...` and `/storage/v1/object/list/...` handlers on the fake edge with in-memory blobs, call logging, and key validation aligned with `OBJECT_KEY_PATTERN`.
- Auth mirrors hosted Supabase: `apikey` first; JWT-shaped keys may also use `Authorization: Bearer`; `sb_secret_` keys work on `apikey` only; anon is refused on storage.
- `startIngestAppServer` forwards `POST /api/internal/rag/ingest/jobs/:id/:action` to injected Next-style route handlers.
- `spawnSidecarModule` runs `python -m` under the rag-sidecar project, merges only explicit env with `PATH`, `HOME`, and `RAG_SIDECAR_ENV=test`, and kills the process tree on timeout.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Importing object-store pulled app env validation into node:test**

- **Issue:** `import { OBJECT_KEY_PATTERN } from '@/lib/rag/ingest/object-store'` loaded `src/lib/env.ts` and failed without `OPENAI_API_KEY`.
- **Fix:** Duplicated the regex constant in `fake-edge.mts` with a comment pointing at the canonical definition.
- **Files modified:** `eval/harness/fake-edge.mts`

**2. [Rule 2 - Critical] uv not installed in executor VM**
- **Found during:** Task 2
- **Issue:** `uv` was absent from PATH; smoke tests exited 1.
- **Fix:** `resolvePythonLaunch()` uses `uv run --project rag-sidecar` when `uv` exists, else `python3 -m` with `PYTHONPATH=rag-sidecar/src`.
- **Files modified:** `eval/harness/sidecar-worker.mts`

### Minor test adjustment

- Invalid-key case uses a key segment containing `..` as a substring because `fetch` normalizes bare `../` URL path segments before they reach the server.
