# Phase 03.1 Plan 16: L1 pdfplumber preflight Summary

**Gated L1 probe classifies every parse fixture page and keeps bench-100 at ~36ms with pdfplumber on three pages only.**

## Accomplishments

1. **`l1_signals`** walks every page with pypdfium2 (chars, text layer, images, thin paths, multi-column lines, garbled ratio) and opens pdfplumber only on pages with enough thin paths or aligned numeric rows, then runs `find_tables` on those pages only.
2. **`parse/probe.py`** still exposes the same `text_layer_page_share` semantics by delegating to L1 page reads (F-14).
3. **Tests** cover all manifest fixtures, encryption (user password vs owner-only), mixed/cross-boundary cases, a pdfplumber-open spy on digital-text, and a bench guard on `bench-100.pdf`.

## Deviations from Plan

### Auto-fixed Issues

None — plan executed with the deviations below documented as decisions.

### Decisions

1. **uncertain signal** — L2 uses the `uncertain` boolean; ParserExpected lists do not always include the `uncertain` signal (e.g. scanned-only pages), so it is not added to `signals` when that would break fixture parity.
2. **table_continues** — Continuation uses matching first-column text between the last row on page *n* and the first row on page *n+1* plus table-at-bottom-of-content, avoiding false continues between repeated full tables in mixed-routing.
