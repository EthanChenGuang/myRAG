# Phase 03.1 Plan 37: L2 preflight, run_preflight, and /v1/preflight

**Sidecar preflight now runs L2 on uncertain pages, composes `run_preflight` against parse fixtures, and exposes the probe on `POST /v1/preflight` through the priority pool.**

## Accomplishments

- `l2_refine` batches uncertain (non-scanned) pages, runs fast-preset Docling via the range converter, detects tables/structure, records L1/L2 disagreements, and returns reusable fast conversions keyed by page range.
- `run_preflight` wires L1, L2, optional L3 no-op hook, `page_tier`, `build_ranges`, and `classify` into a validating `PreflightResult` with detect counts and timings.
- `POST /v1/preflight` reuses multipart upload limits, requires the sidecar secret, runs work on `PriorityPool`, and returns JSON without page text.

## Deviations

- **Local merge:** Integrated `origin/exec/03.1-27` (PriorityPool + worker main.py lifecycle) before implementation; no conflict with `exec/03.1-55` wake route.
- **Scanned L2:** Uncertain scanned pages skip Docling conversion (recorded fast pages for mixed-routing page 9 break `DoclingDocument.load_from_json` when joined); tier remains `structured_ocr`.
- **Range lift:** Per-page tiers match fixtures; `build_ranges` may merge short neighbors (e.g. page 10 pulled into OCR range) per existing 03.1-15 rules — tests assert per-page presets and main range groups.
