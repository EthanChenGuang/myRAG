## Sampling Rate

- **After every task commit:** the task's `<automated>` command, plus `npm run typecheck:new` for TypeScript changes and `node scripts/ci/check-rag-boundary.mjs` plus `uv run --directory rag-sidecar pytest -q tests/test_ingest_boundary.py` for changes under `src/lib/rag/ingest/` or `rag_sidecar/ingest/`.
- **After every plan wave:** the full suite command, plus the defaults guard: `npm run test-rag -- --out eval/out/p31-wave && jq -e '.passed == true and .paired.all_zero == true' eval/out/p31-wave/gate.json` (from wave 4 on, also `node --import tsx --test tests/rag-e2e/fixed-equals-phase3.test.mts`).
- **Before `/gsd-verify-work`:** plan 03.1-52 Task 3 command chain green (includes `npm run eval:parse-gate` and both smoke-tier modes with all paired differences zero), and `npm run gen:schemas` with a clean diff.
- **Max feedback latency:** 60 seconds for per-task unit commands; e2e, latency, backfill and gate runs are per-plan or per-wave gates.
