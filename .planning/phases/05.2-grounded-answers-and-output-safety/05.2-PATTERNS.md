### `src/lib/rag/generation/answer-config.ts` (config, transform)

**Analog:** `src/lib/rag/security/config.ts` (`readSecurityConfig`). Copy its whole shape: typed modes, warning codes, `parseMode`, a frozen result, `anyNonDefault`.

**Mode parsing with a warning** (symbol `parseMode`):
```typescript
function parseMode<T extends string>(
  raw: string | undefined,
  modes: readonly T[],
  warning: SecurityConfigWarning,
  warnings: SecurityConfigWarning[],
): T {
  const text = raw?.trim() ?? '';
  if (text === '') return modes[0];
  const mode = modes.find((candidate) => candidate === text);
  if (mode) return mode;
  warnings.push(warning);
  return modes[0];
}
```

**Reader shape** (symbol `readSecurityConfig`): takes `source: Record<string, string | undefined> = process.env`, is read at call time, never cached or logged, and returns `Object.freeze({ ..., anyNonDefault, warnings })`. Warning messages name the variable only, never its value.

**Apply:** `RAG_OUTPUT_GUARD` (`off | flag | enforce`), `RAG_UPLOADER_HOLD` (`off | manual | auto`), `RAG_MAX_OUTPUT_TOKENS` (`off | auto | <n>`) use `parseMode`-style parsing. Invalid combinations of D-58 (per-sentence without citations, judge without a model, claim check without groundedness) push one warning each and resolve to off. Number clamps follow `parseTimeout` / `parsePremiseCap` in `src/lib/rag/generation/config.ts`.
