<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output to the user | links and addresses in the answer are untrusted until checked |
| retrieved document text | a link there is never trusted for that reason |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05.2-111 | Tampering | phishing link carried from an injected document into the answer | high | mitigate | allow rules 1 to 4 only; document-only links rejected; enforce replaces (D-37) |
| T-05.2-112 | Spoofing | look-alike host (full-width, mixed script, U+3002, trailing dot, user info) | high | mitigate | NFKC plus IDNA to ASCII, reject changed hosts and user info, cut at CJK punctuation; tests per case |
| T-05.2-113 | Tampering | link split across stream tokens | high | mitigate | bounded hold-back state machine; every-split-point property test |
| T-05.2-114 | Denial of service | backtracking or unbounded buffering on model text | medium | mitigate | linear scan, 2,048 and 300 character bounds, decide at the bound |
| T-05.2-115 | Information disclosure | removed targets logged or stored | medium | mitigate | removed targets stay in memory for attribution only; the summary serializes counts and rule ids |
| T-05.2-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package; the TLD list is a committed data file with its IANA version line (RESEARCH Package Legitimacy Audit) |
</threat_model>
