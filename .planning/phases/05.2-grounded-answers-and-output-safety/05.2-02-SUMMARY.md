# Phase 5.2 Plan 02: Switches, reader and Config UI inputs Summary

**The fourteen Phase 5.2 switches exist in every config location with their off defaults. One call-time reader, `readAnswerConfig()`, resolves invalid values and half-configured combinations to off with a warning code. The Config UI has a static "Answer rules and output safety" card the existing Save All Changes saves.**

## Accomplishments

- `readAnswerConfig(source = process.env)` (`src/lib/rag/generation/answer-config.ts`). It is read at call time and returns a frozen config. It reads RAG_CITATIONS, RAG_CLAUDE_CITATIONS and RAG_GROUNDEDNESS through `readGenerationConfig(source)`, so each variable has one parser. Fall-back rules:
  - `RAG_MAX_OUTPUT_TOKENS`: `off`/empty means off, `auto` means auto, digits ≥ 256 mean fixed. Anything else, including `0`, `-5`, `1.5`, `1e3` and `0x400`, gives off with `max_output_tokens_invalid`. 1 to 255 gives off with `max_output_tokens_below_floor`. The registry-dependent part of the D-31 floor is left to 05.2-10.
  - `RAG_OUTPUT_GUARD` accepts off, flag or enforce, and `RAG_UPLOADER_HOLD` accepts off, manual or auto. Any other value gives off with a warning.
  - Each D-58 combination resolves to off with one code: per-sentence citations without either citation switch, the claim check without groundedness, or the judge without a model.
- `warnAnswerConfigOnce()` logs one `[Answer Rules]` line with `{ codes }` for codes not yet logged in the process. It never logs values.
- The fourteen variables are in the five app locations, the manifest (`managed`, empty `knownGaps`), the eval pin (regenerated with `eval-env.mts --write`; 14 additions, no other drift) and the settings classification. `RAG_OUTPUT_LINK_ALLOWLIST` is untouched, and `WHATSAPP_LINK_PREVIEW_HOSTS` is not added.
- Run configs may set every Phase 5.2 switch. Enumerated values are checked, `RAG_MAX_OUTPUT_TOKENS` must be off, auto or a positive integer, and unknown names are still rejected.
- Config UI card `#rag-answer-rules`, placed after "Prompt-injection defense":
  - Copy, groups and order follow UI-SPEC 6.12 and 12.3.
  - Eight `checkbox-primary` switches, the guard and hold selects (option value is the env value, option text is the human label), two bounded number inputs and the monospace judge-model input with its always-visible egress note.
  - Answer length: a select (Off, Chosen by evaluation, Fixed limit) and a number with `min="256"` write the hidden `#RAG_MAX_OUTPUT_TOKENS` and fire `change` on it, so the page's handler and Save All Changes store it.
  - A number below the floor sets `aria-invalid` and an inline polite error, and leaves the hidden value unchanged. The error text comes from `data-template`, so 05.2-36 can localise it.
  - Every text element carries `data-rag-i18n="<UI-SPEC key>"` for the zh and it pass of 05.2-36.
