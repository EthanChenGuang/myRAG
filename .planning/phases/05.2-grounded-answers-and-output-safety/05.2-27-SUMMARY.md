# Phase 5.2 Plan 27: Eval contracts for answer rules Summary

**The golden, trace, report and latency contracts now describe partial answers, stale versions and off-topic context, the Phase 5.2 trace fields, the seven answer-rule metrics and the report-only answer-check budgets. Generated Zod is in sync, and every existing file still validates unchanged.**

## Accomplishments

- **Golden (D-53):** three new categories. `PartialSpec`, `VersionsSpec` (with `VersionedValue`) and `OffTopicSpec` are each required exactly for their category ("<field> is required exactly for <category> items"). Evidence is always a span quote. `off_topic_context` is unanswerable. The 5.2.1 categories are not added.
- **Trace (D-16, D-18, D-33, D-41, D-42, D-52, D-89):** ten optional `RagTrace` fields that reuse the 05.2-01 models. Sentence indexes and part ids must not repeat.
- **Report (D-21, D-54, D-33):** `EvalReport.answer_rules` has the seven metrics, each overall and per language and category. `StrategySlice.uncited_sentence_rate` adds the per-strategy view. `InjectionReport` keeps its shape.
- **Latency (D-28, D-61):** `LatencyBudgets.answer_checks` holds report-only `claim_check`, `groundedness_judge` and `output_guard` budgets.
- **Samples:** six neutral named variants (document-a.md style, letters, synthetic units). Regenerated with `npm run gen:schemas`, and a second run is drift-free.

## Deviations from Plan

1. **`src/lib/rag/feedback-loop/labels.ts` (outside `files_modified`).** `ExpertLabel` reads the Pydantic `UNANSWERABLE_CATEGORIES`, and its TS twin of the rule listed only `no_answer` and `small_talk`. Without the change, the two sides would accept different labels. A test (`tests/rag/feedback-loop/label-category-rules.test.ts`) failed on the old code and passes now.
2. **The old-report check uses the committed baselines.** The committed fixture report `eval/reports/frameworks-fixture/report.json` is not an `EvalReport`, so the test validates `eval/baselines/fixture{,-domain,-ingest}-baseline.json` instead.
3. **Stricter golden rules than the plan text.** Covered spans must be gold evidence. A versioned value must occur in its quote. Current and stale versions must come from different documents. These checks guard against T-05.2-271, and fixture authors in 05.2-28 and 05.2-29 must follow them.
