# Phase 05.2 Plan 22: Version conflicts Summary

With `RAG_VERSION_LABELS` on, the server finds version conflicts among the context blocks by rules before generation, labels the older block for the model, records the conflict on the result, the trace and `checks`, hands it to the Phase 3.2 supersession candidates and the review queue after the response, and checks the answer for mixed versions.
