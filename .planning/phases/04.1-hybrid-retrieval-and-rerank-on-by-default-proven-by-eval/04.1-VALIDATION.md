## Test Infrastructure

| Property | Value |
|----------|-------|

| **Config file** | `vitest.config.ts`, `eval/pyproject.toml` |
| **Quick run command** | the plan's own `<automated>` line (one or two test files) |
| **Full suite command** | the CI-equivalent list in plan 04.1-12 Task 2 (run once at phase close; the machine is shared) |

---

## Sampling Rate

- **After every task commit:** the task's `<automated>` command.
- **After every plan:** the plan's `<verification>` list plus `node scripts/ci/check-rag-boundary.mjs`.
- **Before the flip (04.1-09):** the defaults gate (04.1-07) must report `status: flip`, the decision must be current (`python -m rag_eval.defaults_decision check-current`), Phase 3.2 must be complete on trunk and plan 04.1-13 done; 04.1-09 Task 1 checks all of this before any edit.
- **Numbers:** no command in this map compares against a literal baseline value; bounds and item counts are read from the files in force (revised 2026-11-25, CONTEXT D-12 amended).
- **Before phase verification:** plan 04.1-12 Task 2 green.
- **Max feedback latency:** 120 s for unit feedback; eval runs are batched in 04.1-07, 04.1-08, 04.1-10, 04.1-12.
