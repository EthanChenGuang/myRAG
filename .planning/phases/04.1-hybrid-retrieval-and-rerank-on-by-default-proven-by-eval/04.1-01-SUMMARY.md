# Phase 4.1 Plan 01: Legacy-rule refusal floor Summary

**v2 can now refuse with legacy semantics (`RAG_REFUSAL_FLOOR=legacy_rule`) through one predicate shared with legacy assembly; the default `similarity` leaves v2 unchanged.**

## Floor before

Measured before any source edit with `eval/config/runs/v2-all-off.json` (`RAG_PIPELINE=v2`, every sub-switch off), `--no-gate`, on trunk 49e9ccc4. Reports under `eval/out/p41-floor-before-*` (not committed).

| Fixture mode | False-refusal rate | n (answerable) | Refused answerable | Correct-refusal rate | n (no-answer) | Fixture-fitted floor applied |
|---|---|---|---|---|---|---|
| prechunked | 0.0313 | 96 | 3 | 0.2857 | 21 | yes (context_threshold 0.1159 from eval/config/fixture-score-calibration.json, which names `prechunked`) |
| ingest | 0.8661 | 127 | 110 | 1.0000 | 26 | no (legacy 0.65 floor) |

Floor thresholds were confirmed from the traces: every prechunked refusal record has threshold 0.11586; every ingest floor record has 0.65 (26 answered, 172 refused, 12 `no_candidates`). The ingest row is the production-like case: without a fitted floor v2 refuses 110 of 127 answerable items.

## Accomplishments

- `legacyKeepReason(candidate, terms, floors)` returns `similarity` (similarity above the text floor), else `name` (a legacy term in the lower-cased filename or text), else `image` (image above the image floor), else `null`; floors default to 0.65 / 0.25. `legacyQueryTerms` keeps the empty-term quirk for long non-Latin words.
- `filterCandidates` calls the predicate; legacy output is unchanged (oracle, assemble, assemble-switch, legacy-post-filter, chat characterization and the assemble differential suite green).
- `RAG_REFUSAL_FLOOR`: `similarity` (empty or default), `legacy_rule` (any case, trimmed); unknown values give `similarity` and one `[RAG Config]` warning. In the memo key. `readRagEnvInput` reads `process.env.RAG_REFUSAL_FLOOR` only, because `src/lib/env.ts` gains the field in plan 04.1-02.
- `legacyRuleFloor`: `not_applied/no_candidates` on an empty pool; answer if any candidate passes; otherwise refuse with `below_similarity_floor`, basis `similarity_floor`, threshold = text floor, topScore = best dense similarity (null when none). Lexical-only candidates can pass on the term rule.
- `applyRefusal` takes the request query from `runRankStages`; under `legacy_rule` the floor reads every pool hit with filename = `document.filename`, text = chunk content + `document.contentPreview`, terms = `legacyQueryTerms(input.query)`, and the floors applyRefusal already resolves (eval fixture floor, then profile, then LEGACY_PROFILE). The threshold gate still wins when applied.
- Untouched (D-26): `decideRefusal`, `cellKey`, `ThresholdCell`, `loadThresholds`, `eval/config/refusal-thresholds.json`; neither floor takes a RAG-mode argument. `RAG_PIPELINE=legacy` never reaches applyRefusal.
