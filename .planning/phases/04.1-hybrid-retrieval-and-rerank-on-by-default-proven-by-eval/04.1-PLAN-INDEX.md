# Phase 4.1 Plan Index

17 plans in 10 waves (revised 2026-11-25; see "Revision 2026-11-25" and "Gap closure 2026-11-25" below). Plans in the same wave share no file in `files_modified`; every file touched by two plans is ordered by a `depends_on` path (checked with `gsd-tools phase-plan-index 04.1`). The phase starts after Phase 4's automated close (04-42, executed on trunk). Only plan 04.1-08 makes live vendor calls (capped at 600 requests, placeholder key `proxy-injected`). Defaults change only in 04.1-09, and only if the gate records `status: flip` (since gap closure: the re-run in 04.1-17), the decision is still current, and Phase 3.2 is complete on trunk.

Three rules hold in every plan (CONTEXT D-12 amended, D-26, D-27):

- No plan quotes a baseline value or an item count. They are read from the files in force at execution time.
- No plan adds a RAG-mode key or writes `eval/config/refusal-thresholds.json`.
- Code and SQL are named by symbol and re-read at execution time, never by line number.
