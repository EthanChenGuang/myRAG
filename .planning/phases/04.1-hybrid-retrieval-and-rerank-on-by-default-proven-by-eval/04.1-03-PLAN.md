<objective>
Add `RAG_RERANKER=auto` so that rerank can be on by default on a fresh install without any key and without marking requests degraded.

Purpose: CONTEXT D-05 and research F-3. With `cohere` as a default and no key, every request is `skipped`/`missing_key` and degraded. `auto` uses Cohere when the operator configured its key and a local fallback otherwise. The fallback and the hosted profile set are code constants that plan 04.1-07's decision record may change (D-06, D-09) without a new variable.
Output: `auto` parse, resolution, stage detail and hash behaviour, with tests.

Depends on 04.1-01 (both edit config.ts and rank.ts). The default stays `none` until plan 04.1-09.

Commit rule for every task: plain `git commit`; the message ends with the attribution lines (Co-Authored-By and the session link) that the executor's own session supplies; never copy them from a plan. No model identifiers in code comments or commit messages; no secrets.
</objective>
