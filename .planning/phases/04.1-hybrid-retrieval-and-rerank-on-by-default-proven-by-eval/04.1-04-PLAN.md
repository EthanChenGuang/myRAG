<objective>
Make an implicit v2 default safe for deployments whose database does not yet have the Phase 4 RPC.

Purpose: CONTEXT D-07, research F-5 and F-6. After the flip, hosted deployments that never set `RAG_PIPELINE` run v2; without migration 0407 every request would end in `backend_error`, which strict mode reports as "knowledge base temporarily unavailable". A default should degrade to today's behaviour, not to an outage; an explicit choice keeps failing loudly.
Output: readiness module, `DEFAULT_PIPELINE` and `pipelineSource`, dispatch fallback, tests.

Depends on 04.1-03 (config.ts order). Before the flip `DEFAULT_PIPELINE` is `legacy`, so nothing changes on trunk; tests use the setter.
