# Phase 4.1 Plan 05: Pinned legacy characterization and the defaults characterization Summary

**The legacy characterization no longer depends on the shipped defaults, and the D-01 defaults have their own reviewed snapshots plus eight named behaviour-to-preserve cases that pass today.**

## Accomplishments

- `RouteFixtureOptions.env?: Record<string, string | undefined>`; `undefined` removes a variable for the fixture's life; without the option nothing changes. Under `RAG_RERANKER=auto` with no `COHERE_API_KEY` setting the fixture clears the fake edge's placeholder key (same rule as `eval/harness/process-env.mts` from 04.1-06).
- chat, chat-overview, embed and voice characterization pass `env: { RAG_PIPELINE: 'legacy' }`; `git diff` on the existing snapshot files is empty.
- `characterize-defaults.test.ts` runs chat (every golden question, two model kinds), embed and voice (golden plus intent queries) with D01_ENV: the five D-01 values, every other Phase 4 switch at its off value, both rerank tiers, `RAG_SUPPORTED_LANGUAGES=zh,en,it`, `RAG_PRIMARY_LANGUAGE=en` and `COHERE_API_KEY=''`. Nothing is read from the pin, so the snapshots hold before and after 04.1-09 and before and after Phase 3.2.
- Named cases, all passing under the D-01 set (none marked `it.fails`):
  - `defaults run is served by v2`: chat, embed and voice each call `hybrid_search_chunks`; no legacy match RPC; the chat trace has a rerank stage.
  - `strict empty answers information not available`: every `no_answer` item whose trace status is `empty` answers "Information Not Available", never the unavailable message, never reaches the model; at least one such item exists.
  - `backend failure is not reported as information not available`: trace status `error`, body has "The knowledge base is temporarily unavailable", no refusal text, no model call.
  - `web search stays available when strict retrieval is empty`: strict, web search on, empty retrieval reaches the model with the `webSearch` tool and no refusal.
  - `source_images reach chat embed and voice`: chat stream `source_images` part, embed retrieval result and voice `source_images` all carry the floor-plan image URL.
  - `context placeholder substituted`: a synthetic `RAG_SYSTEM_PROMPT` with `{{context}}` yields a system prompt with the prompt text, the gold evidence quote and no placeholder.
  - `general overview stays legacy`: equals `chat-overview.json` exactly, no `hybrid_search_chunks` call.
  - `no key means no degraded status`: 12 answerable chat requests, none degraded, rerank detail `auto:local_bm25`, no rerank call reached the edge.
- `defaults suite under the pin` compares the same three snapshots with no env once the pin's `RAG_PIPELINE` is not `legacy`. Checked once by temporarily writing the D-01 values into `eval/config/rag-eval-env.json`: 3 of 3 pass; pin restored (no diff).
