<objective>
Measure the real hosted rerankers once, cheaply, on the fixture corpus: quality against the local options and p95 latency for 75 candidates.

Purpose: CONTEXT D-09, D-12 G7, D-22 and Q-1, Q-4. `auto` sends chat to Cohere whenever a key is configured, and voice to Cohere's fast tier; before that becomes a default we want real evidence that the hosted rerank is not worse than the local paths on our fixture and that its latency fits the budgets. Real keys are available through the network proxy; code sees only the placeholder.
Output: four live run configs, a capped latency probe with tests, and a committed report.

Depends on 04.1-03 (`auto`, model names) and 04.1-06 (run-config allowlist with placeholder keys and vendor base URLs). Cost: at most 600 requests (about 4 x 80 dev-split queries plus 4 x 30 probe calls).

Commit rule for every task: plain `git commit`; the message ends with the attribution lines (Co-Authored-By and the session link) that the executor's own session supplies; never copy them from a plan. No model identifiers in code comments or commit messages; no secrets.
</objective>
