## Top 3 Priority Fixes

1. **Narrow Profile/Status columns on desktop** (WARNING): `scoped-c-1024` breaks as "scoped-c- / 1024", UUIDs break across 3-4 lines, and the stale hint in the Status cell takes about 13 lines while the Actions column has blank space (`populated-desktop.png`, `switch-off-desktop.png`). Fix: give the Profile cell `whitespace-nowrap` for the profile id (or `md:min-w-40`, as on Scope), and move long row hints (stale, needs-evidence) into a full-width row under the binding, or give Status a `md:min-w-56`.
2. **Evidence column wraps a three-word label** (WARNING): "Baseline / not / recorded" and "global- / a-1536" (`populated-desktop.png`). Fix: `md:min-w-32` on the Evidence cell, or `whitespace-nowrap` on the baseline label.
3. **Badge stack reads as three loose pills** (INFO): Active/Stale/Incomplete stack vertically on desktop because the Status cell is narrow. This goes away with fix 1; otherwise use `flex flex-wrap gap-1`.

## Detailed Findings

### Pillar 1: Copywriting (4/4)
- PASS: "Close form" replaces "Cancel" (`:103`); the gsd-ui-checker BLOCK on L288/L432 no longer applies to the code.
- PASS: The stale hint without a baseline reads "Its evidence has no recorded baseline; the global active profile is now global-a-1536…" (`populated-desktop.png`), and Evidence shows "Baseline not recorded".
- PASS: The proxy error is shown verbatim and paired with "Try again"; the 503 copy states what failed and what to do.
- INFO: Single-verb row labels are disambiguated by `aria.action`; English only (I-2).

### Pillar 2: Visuals (3/4)
- PASS: Mobile stacks each binding as Scope / Profile / Status / Complete / Evidence / actions with labels; nothing is clipped (`populated-mobile.png`, `form-open-mobile.png`).
- PASS: Gated Activate and Retire are outlined and do not wrap; the CLI hint is a left-aligned block under the actions.
- WARNING W-1/W-2: The desktop table splits its width badly. The Actions column takes about 30% of the width and is mostly empty, while Profile and Status wrap hard. The stale row is about 3x as tall as it needs to be.

### Pillar 3: Color (4/4)
- PASS: `btn-primary` only on Create binding, dialog confirm and empty-state New binding; row actions are outlined.
- PASS: The switch-off note is an outlined info alert, so the Status badges are again the strongest color on the panel.
- PASS: Error alerts (`real-unmocked`, `registry-503`) use the error token with a contrasting Try again button; no hex colors.

### Pillar 4: Typography (4/4)
- PASS: `text-xs/sm/base/lg`, weights 400/600; mono sizes are explicit (`:278`, `:282`, `:571`, `:620`, `:636`).

### Pillar 5: Spacing (3/4)
- PASS: Gaps on the 4px grid; warning icons are top-aligned with the count line; the hint block sits `mt` under the actions without crowding them.
- WARNING W-3: The Evidence cell is too narrow, so its label wraps over three lines; the vertical rhythm of the rows is set by wrapping, not by content.

### Pillar 6: Experience Design (4/4)
- PASS: loading, refresh with `aria-busy`, 401/403 sign-in, 503 and proxy/network alerts with Try again, empty, no scoped profile (submit disabled), switch off, confirm dialog, one mutation at a time, 401 clears `formOpen`, a single alert after an unconfirmed mutation followed by a failed reload. Covered by `tests/ui/config-embedding-bindings-panel.test.ts`.
- INFO: Esc closes the form only while focus is inside it; acceptable.
