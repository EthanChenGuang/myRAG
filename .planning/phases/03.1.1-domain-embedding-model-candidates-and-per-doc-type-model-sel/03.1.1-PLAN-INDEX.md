# Phase 3.1.1 Plan Index

16 plans in 8 waves (03.1.1-16 was split out of 03.1.1-01 after plan check; numbers are not wave order). Plans in the same wave share no file in `files_modified`, every later editor of a file transitively depends on the earlier one, every in-phase dependency is in an earlier wave, and each wave number is the minimum its dependencies allow (checked by script on 2026-11-24). Every plan runs after Phase 3 is complete; `depends_on` also names the Phase 3, 3.1 and 4 plans whose outputs it extends (03-xx, 03.1-xx, 04-29); those cross-phase ids do not affect wave numbers.

Migrations: 0440 scope, bindings table, seeds and indexes (plan 04); 0441 binding gate (05); 0442 scoped re-embed (06); folded into both setup files by plan 14. Re-check the numbers against sibling phases planned in the same run before plan 04 executes (D-28).

UI: plan 13 Task 2 (Config UI "Embedding bindings" panel) needs `/gsd-ui-phase 03.1.1` first; plan 03 adds three env fields to the existing form only. Because the phase will have a UI-SPEC, `scripts/ci/check-frontend-design-summary.mjs` treats every SUMMARY of this phase as a UI summary: **every SUMMARY must include a "## Design skills" table** (rows frontend-design, Impeccable, web-design-guidelines; `n/a` with outcome `none` for non-UI plans). Before the UI-SPEC exists the gate already matches plans 03, 10, 12 and 13 (their text names `scripts/config-ui/` or `src/app/`); those four plans carry the table in must_haves and check their own SUMMARY with a local grep. Because plan 13 creates the UI-SPEC, the gate then checks every SUMMARY, so every other plan's `<output>` also requires the table (frontend-design `n/a`, Impeccable `n/a`, web-design-guidelines `none`). The phase-wide gate runs only in plan 14 Task 3 and in `/gsd-verify-work` (plan-check pass 2). web-design-guidelines runs on `scripts/config-ui/index.html` in plans 03 and 13.

Human checkpoints: plan 15 (live model facts, live migrations and index builds, real-data comparison and activation decision). Everything else is automated.
