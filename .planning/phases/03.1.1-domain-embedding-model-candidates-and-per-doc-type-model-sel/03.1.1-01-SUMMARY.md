# Phase 3.1.1 Plan 01: Embedding model catalog and model-aware Voyage provider

**One frozen catalog of vendor model facts; the Voyage provider serves voyage-4-large, voyage-law-2 and voyage-finance-2; the registry resolves by (provider, model) while every Phase 3 lookup keeps the default model.**

## Accomplishments
- `catalog.ts` with five entries (text-embedding-3-small, voyage-4-large, voyage-law-2, voyage-finance-2, Qwen/Qwen3-Embedding-8B): native and supported dims, `sendsOutputDimension`, max input tokens, tokens per request, input types, USD/1M, estimate flag, free-token note, `supportedLanguages`, `languagesNote`, `servingModes` (`['hosted']` everywhere), `hostedEndpoint` (env variable names only), `sidecarPath` (null), `vendorDomainNote` (read by no code), `readOn`.

- `getEmbeddingProviderFor(provider, model)`; `getEmbeddingProvider(id)` unchanged; `KNOWN_DIMS`/`KNOWN_LIMITS` replaced by the catalog default entries (same values).
- Per-model prices; the two-argument `estimateCostUsd(provider, tokens)` and `priceFor(provider)` still work.
