## Rules that apply to every plan

- **Decisions by reference.** `03.2.1-CONTEXT.md` lists the Phase 3.2 decisions this phase carries (D-07 in part, D-25, D-26, D-27, D-48, D-50, D-52, D-54 in part); the binding text is in `03.2-CONTEXT.md`. Research, patterns and the UI contract are Phase 3.2's and are cited by full path in `read_first`.
- **Illustrations are not product content** (owner rule of 2026-11-25): fixture texts are synthetic, neutral and varied in subject; nothing built here contains subject-specific words or values from the planning documents' examples.
- **Nothing is activated.** The profile is seeded `available`; activation stays with the operator through `npm run rag:embedding` and the EMB-05 gate. No plan activates it, on fixtures or live.
- **No fallback to the vendor.** In sidecar mode the provider fails with a typed error; it never calls the hosted API (prohibition in `03.2.1-02`).
- **Tracer first.** Each plan leads with one `type="tracer"` task. **Verification commands** are followed by `<fails_when>`; count gates carry a baseline measured at `4b37ea5b`.
- **Design summary.** Every SUMMARY carries the `## Design skills` table; `03.2.1-04` is the one UI plan and records real outcomes. This directory has no UI-SPEC: the contract is `03.2-UI-SPEC.md` sections 6.3 (group `bge`), 6.10, 8.1, 12.7 and 12.9.
