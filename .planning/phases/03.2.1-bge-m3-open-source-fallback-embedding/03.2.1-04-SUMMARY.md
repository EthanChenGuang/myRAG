# 03.2.1-04 SUMMARY: declared languages and BGE-M3 serving in the Embedding profiles panel

## What changed

- **Route** (`GET /api/rag/admin/embedding-profiles`): each profile now carries `supportedLanguages`, and BGE-M3 profiles also carry `servingMode` (`hosted` | `sidecar`). The guard, the existing fields, the order of the existing fields, the completeness option and the error answers are unchanged.
- **Panel** (`scripts/config-ui/rag-panels/embedding-profiles.js`): each card has one extra 12px line, "Languages: 中文 (zh), English (en), Italiano (it)". A profile that does not declare a chosen language gets one warning line per such language. The BGE-M3 card also gets "Served by: …". Under the list sit an h4 "BGE-M3 serving" and the `bge` settings group, moved from the hidden `#rag-phase032-settings` block. Its select keeps id `RAG_BGE_M3_SERVING`, so "Save All Changes" and check-config still find it, and it stays usable when the list answers 401. The cards, the summary line, Activate and Rollback are unchanged. The BGE-M3 card has only the existing Activate button.

web-design-guidelines findings (all resolved):
- `embedding-profiles.js` warning line: the meaning was carried by colour in low-contrast yellow. Resolved: there is now an icon (aria-hidden) plus the word "Warning:", and the text is in body colour.
- `embedding-profiles.js` language codes: they were translatable identifiers. Resolved: `translate="no"`.
- `embedding-profiles.js` card title: long content had no wrap. Resolved: `break-words`. New lines also use `break-words` and `min-w-0`.
- Language names: each gets a `lang` attribute, so screen readers pronounce them correctly.
- Server strings (profile ids, language codes): built with `textContent` only. No `innerHTML` is written, which the tests assert with `innerHtmlWrites === 0` and a hostile id.
- The select has a visible `<label for>`, `autocomplete="off"` and `aria-describedby` to the help text (static markup from 03.2-03).

3. Bug fix outside the plan text: idempotent `initEmbeddingProfilesPanel` (duplicate listeners on re-click). It has a test that fails on the old code.
