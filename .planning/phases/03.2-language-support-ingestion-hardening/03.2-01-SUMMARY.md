## Deviations from Plan

1. **[Rule 3 - Blocking] Config lookup moved to a base module.** `contracts/languages.py` needs `resolve_config_file`; importing `rag_sidecar.preflight.config` from inside the `contracts` package would import `contracts.ingest`/`routing` while `contracts/__init__` is still loading. The helpers now live in `rag_sidecar/config_files.py` and `preflight.config` re-exports them (all existing importers unchanged). The plan allowed this move.
2. **Task 1 was committed as one tracer commit (tests with implementation).** A RED commit would have failed on module-not-found, which the brief forbids. Task 2 has a real RED commit (assertion failures: copy missing). Task 3 pins current values, so its tests pass on first run by design; the meta-tests prove they fail on drift.
3. **Extra checks beyond the plan:** rewrite-gate lexicon key presence per pack, citation and knowledge-base-unavailable notices, groundedness tooltips.
