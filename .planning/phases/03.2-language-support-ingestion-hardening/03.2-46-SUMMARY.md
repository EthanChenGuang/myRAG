# Phase 3.2 Plan 46: Effective dates (store, apply rule, admin routes) Summary

**Documents and their chunks carry an effective window that an admin can set, confirm or dismiss over HTTP; an extracted date is applied on its own only when it keeps the document usable today with confidence of at least 0.8, and an admin's date always wins.**

## Accomplishments
- 0807: one setter with an admin path and a pipeline path, a proposal store, dismiss and list; dates copied to chunks and the semantic cache invalidated in the same transaction (F-12); no re-embed, fingerprint untouched.
- `versions/effective-dates.ts`: the D-43 decision function (pure, injected `today`), admin service calls with workspace pre-check, and `recordExtractedEffectiveDates` for the extractor (plan 47) that either applies through the pipeline path or stores the proposal.
- Three route files with `checkAdminOrOrgAdmin`, `.strict()` Zod bodies from `zod/v3`, `Cache-Control: no-store`, `[RAG Admin]` logs with ids and counts only.
