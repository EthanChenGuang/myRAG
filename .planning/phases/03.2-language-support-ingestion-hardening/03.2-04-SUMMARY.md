# Phase 3.2 Plan 04: schema seam (migration 0801) Summary

**One additive, idempotent migration adds the `pending_review` hold state, the `translate` ledger kind and every Phase 3.2 document and chunk column. It also updates the field setter, the chunk writers and ten ledger functions to match.**

## Accomplishments
- `pending_review` on `documents` and `document_chunks` (chunk list keeps `variant`), on `ingestion_jobs.status`; `translate` on `ingestion_jobs.kind`.
- A `pending_review` document and its chunks are returned by none of `hybrid_search_chunks` (dense and lexical legs), `match_chunks_by_profile`, `match_document_chunks`, `match_documents` (single-tenant), `match_documents_by_workspace`, `match_document_chunks_by_org` (multi-tenant); `rag_publish_document_version` makes them visible again. No retrieval function was changed.
- New columns, checks and the two indexes; `rag_set_document_fields` accepts `languages`, `ingest_fingerprint`, `hidden_text_check` and status `pending_review`, still refuses `ready` and fields outside its list (tags, dates, approval columns included).
- `rag_write_chunks` / `rag_write_profile_chunks` store `language_confidence` (null without the key) and copy `scopes`, `effective_from`, `effective_to` from the document row. Every other column is written as before.

## Replaced functions (all keep signature, SECURITY mode, `SET search_path = ''`, service_role-only execute)
- `rag_set_document_fields` (from 0425), `rag_write_chunks`, `rag_write_profile_chunks` (from 0424)
- Ledger, with `pending_review` added to the status list: `rag_advance_ingestion_job` (0426), `rag_claim_ingestion_job`, `rag_claim_ingestion_jobs`, `rag_enqueue_ingestion_job`, `rag_enqueue_backfill_jobs`, `rag_list_batch_jobs`, `rag_ingest_job_status_for_stage`, `rag_ingest_mirror_processing_status` (0425), `rag_purge_stale_ingestion_jobs` (0420), `rag_publish_deferred_ingestion_job` (0359)
