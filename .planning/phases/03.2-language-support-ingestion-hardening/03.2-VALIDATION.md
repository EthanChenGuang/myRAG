## Test Infrastructure

| Property | Value |
|----------|-------|

| **Quick run command** | `npx vitest run tests/<file>.test.ts` · `node --import tsx --test tests/rag-db/<file>.test.mts` · `uv run --directory rag-sidecar --extra chunking pytest -q tests/<file>.py` |
| **Full suite command** | the `pr-smoke.yml` sequence (vitest; node:test unit, rag-db and rag-e2e; `node scripts/check-config.mjs`; `node scripts/ci/check-rag-boundary.mjs`; `npm run gen:schemas` + diff; sidecar and eval pytest; both eval smoke tiers; `npx next typegen && npx tsc --noEmit -p tsconfig.json`) |
| **Estimated runtime** | quick ~30 s per file; full suite per CI run (minutes) |

---

## Sampling Rate

- **After every task commit:** the quick command of the touched area, plus `npx tsc --noEmit -p tsconfig.json` when TypeScript changed
- **After every plan wave:** the full `pr-smoke.yml` sequence, including both eval smoke tiers
- **Before `/gsd-verify-work`:** full suite green, all-off parity recorded, per-switch comparisons recorded
- **Max feedback latency:** one quick command per task
