## Deviations
1. **Save while the deployment switch is off.** UI-SPEC 6.9 lets targets be saved with `RAG_DOC_TRANSLATION=off`; the plan's must-have and `fails_when` require Save disabled. The plan was followed and `targets.deploymentOff` reworded in all three locales; a short form `targets.deploymentOffShort` was added for the button reason.
2. **Workspace key in commands.** UI-SPEC 11 item 5 lists tenant keys among values never rendered; the plan asks for the key in the backfill command. It is built from the admin's own workspace selector (validated UUID), appears only inside the command `code`, and the test asserts it appears nowhere else. Multi-tenant personal workspaces get a `u:<user-id>` placeholder.
3. **Extra copy keys beyond UI-SPEC 12.7**: `targets.unchanged`, `targets.loaded`, `coverage.label`, `coverage.none`, `coverage.staleBadge`, `coverage.gaps`, `gaps.none`, `backfill.dryRun`, `backfill.run`, `command.*`, `action.copy*`, `copy.*`, `action.saving`, `targets.deploymentOffShort`, and the settings keys of 12.9 (each panel carries its own copy of the settings strings, as versions-dates does).
4. **Extra test files touched**: a binding row in `config-rag-panel-binding.test.ts` and an XSS row in `config-ui-xss-scripts.test.ts` (as plans 60 and 61 did).
