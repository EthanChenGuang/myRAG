# Phase 4.4 Plan 03: BM25 reference and neutral corpus Summary

**Test-only BM25 reference with Lucene IDF and a seeded Zipf corpus generator over `w0..wN`, for the SQL scorer tests (plan 05) and the benchmark (plan 12).**

## Exported API

```ts
// tests/helpers/bm25-reference.ts
interface Bm25Stats { N: number; avgdl: number; df: Map<string, number> | Record<string, number> }
interface Bm25ReferenceInput { docs: readonly (readonly string[])[]; query: readonly string[]; k1: number; b: number; stats?: Bm25Stats }
function bm25Reference(input: Bm25ReferenceInput): number[]   // one score per doc, in input order

// tests/helpers/neutral-lexical-corpus.ts
interface ZipfPickerOptions { seed: number; size: number; exponent?: number }
interface NeutralLexicalCorpusOptions { seed: number; chunks: number; vocabulary: number; minLength: number; maxLength: number; exponent?: number }
function lcg(seed: number): () => number                       // uniform [0, 1)
function zipfPicker(options: ZipfPickerOptions, random?: () => number): () => number   // rank 0..size-1
function neutralLexicalCorpus(options: NeutralLexicalCorpusOptions): string[][]
```

- `idf = ln(1 + (N - df + 0.5) / (df + 0.5))`, df clamped to `[1, N]`; `score = Σ over distinct query terms of idf · tf · (k1 + 1) / (tf + k1 · (1 - b + b · dl / avgdl))`; `dl` is the token count of the document.
- Without `stats`, N, avgdl and df come from `docs`. With `stats` (for a filtered corpus in the SQL tests), those values are used and `dl` still comes from each document.
- LCG: `state = state * 1664525 + 1013904223 mod 2^32`. Lengths are uniform in `[minLength, maxLength]`.

## Hand-computed case

Docs `[a a b]`, `[b c]`, `[c c c c]`, query `[a c]`, k1 1.2, b 0.75; N = 3, avgdl = 3, df(a) = 1, df(c) = 2:
- idf(a) = ln(8/3) = 0.9808292530117264; idf(c) = ln(1.6) = 0.4700036292457356
- d1 = idf(a) · 4.4 / 3.2 = 1.3486402228911238
- d2 = idf(c) · 2.2 / 1.9 = 0.5442147286003254
- d3 = idf(c) · 8.8 / 5.5 = 0.7520058067931769

The seed-7 snapshot (first three documents of `{ seed: 7, chunks: 50, vocabulary: 200, minLength: 5, maxLength: 20 }`) is committed in the test.
