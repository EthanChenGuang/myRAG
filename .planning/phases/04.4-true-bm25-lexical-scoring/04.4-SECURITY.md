### Documented deviations (not open threats)

- The trigger functions `rag_lexstats_chunks_insert/update/delete` hold EXECUTE for `service_role` (0901:123-125, repeated in 0410:193-203), where D-32 said "no EXECUTE grant". This is required by the repo-wide ACL rule `tests/helpers/sql-function-acl.ts:306` and has no effect, because PostgreSQL refuses to call a `RETURNS trigger` function directly. Recorded in `04.4-02-SUMMARY.md`.
- `rag_lexstats_compact_tenant` has no tenant guard by design. It is service_role only, returns 0 for a key with no state row, and is pinned as the only exception by `lexical-stats-static.test.mts` (`UNGUARDED_BODIES`).
- Operational: re-running 0904 alone replaces the 0932 body with the 26-argument version, which has no access filter. The 0932 header and AGENTS.md say to re-run 0932 afterwards. This is an operator rule, not a code gap.
