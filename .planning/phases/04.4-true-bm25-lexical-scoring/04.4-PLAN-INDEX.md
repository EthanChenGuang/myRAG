# Phase 4.4 Plan Index

15 plans in 7 waves (ids 04.4-01 to 04.4-15). Plans in the same wave share no file in `files_modified`; a file touched by two plans has a dependency path between them. Migrations: 0900 (plan 02), 0901 (plan 02), 0902 (plan 04), 0903 (plan 07), 0904 (plan 05); 0905–0919 unused. `hybrid_search_chunks` is not redefined by any plan. No plan changes a Pydantic contract or a generated Zod schema. Only plan 04.4-15 touches a live project.

Rules for every plan:
- Locate code by symbol name and rebuild from the newest definition on trunk at execution time.
- A plan that opens a PGlite fixture database never runs at the same time as another one in the same working tree (D-42); the orchestrator serialises them or uses separate worktrees.
- Neutral synthetic text only (D-41). No lexeme, token or query text in logs.
- Commit with plain `git commit` and explicit paths; hand-off notes go to `handoffs/04.4-<plan>-<topic>.md`.
