Rules for every plan:

- A plan that opens a PGlite fixture database never runs at the same time as another one in the same working tree (D-42); the orchestrator serialises them or uses separate worktrees.
- Neutral synthetic text only (D-41). No lexeme, token or query text in logs.
- Commit with plain `git commit` and explicit paths; hand-off notes go to `handoffs/04.4-<plan>-<topic>.md`.
