## What changed

**Switch (D-44, D-45).** `RAG_LEXICAL_DF_MODE` in `scripts/init-env.js`, `src/lib/env.ts`, `scripts/config-server.js` (all three templates), the Config UI (one select after the BM25 parameters, disabled unless `bm25`, plus a status note), `scripts/rag/env-manifest.json`, `config/rag/settings-classification.json` (query-side, no mechanism), `eval/config/rag-eval-env.json` (`raw`), the run-config allow-list and the regenerated `rag-affecting.generated.json`. `src/lib/rag/deps.ts` passes the variable into `loadRagConfig`. `LexicalScoringConfig.dfMode` is effective: invalid → `raw`; `cluster` without effective `bm25` → `raw`; `cluster` with `RAG_DUP_CLUSTERS` off → `raw`; each with one `[RAG Config]` warning. `lexicalScoringHashBlock` adds `df_mode: 'cluster'` only for effective cluster. The v2 startup check logs the count of tenants with ready cluster statistics when the mode is `cluster` (`countReadyClusterLexstatsTenants`, a count only).

**Migration 0905 (D-46 to D-48).** Precheck 55000. `cluster_status` / `cluster_rebuilt_at` on the state table; the three corpus CHECKs replaced by name to allow `chunks_cluster`; `rag_lexical_cluster_dirty` and `rag_lexical_cluster_units` (RLS on, no policy, client roles revoked, service_role granted incl. the identity sequence, 0853 tenant-key guard trigger). Trigger functions rebuilt from 0901 with an added cluster branch (only for tenants with `cluster_status` set). `rag_lexstats_compact_tenant` folds both corpora and reconciles up to `p_max_rows` markers; `compact_all` also visits tenants with markers; `rebuild` rebuilds both corpora and the ledger in one snapshot statement when cluster-enabled; `cluster_enable` (55000 without a state row; idempotent; ready stays ready) and `cluster_disable`; `disable` also removes markers and ledger; `status` and `check` add cluster keys for cluster-enabled tenants; the purge hook marks ledger rows whose chunk no longer exists before compacting. No new SECURITY DEFINER function; every function `SET search_path = ''`, revoked from PUBLIC/anon/authenticated, granted to service_role; every tenant function asserts the key first.
