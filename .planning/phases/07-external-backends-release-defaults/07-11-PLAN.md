<objective>
Build reconcile: detect and repair drift between Supabase's servable rows and each external store, record per-tenant index state, and prune the outbox (D-05, D-11, A-12).

Purpose: RET-05 (a reconcile job detects and repairs drift) and RET-09 (index-ready state per backend, profile and tenant comes from a matching reconcile).
Output: 0707 RPCs, their fake-edge registration, reconcile.ts and SQL and unit tests including the drift-injection test on the fake store. The same drift test on real Qdrant and Weaviate runs in the backend-canary job (plan 07-16).

Backend half: depends on 07-06 (store interface, fake store, fake-edge registration pattern) and 07-09 (drain engine for repairs). Rollout position: D-26 step 6.

Execution note: this plan adds migration 0707, which every PGlite test applies. With workflow.use_worktrees false, run it to completion before plan 07-12 (same wave) runs any PGlite-backed test.

Planner resolution (A-12): reconcile deletes `done` outbox rows older than 7 days and keeps `dead` rows until an operator requeues them (index-compat warns on dead rows, plan 07-15). D-05's content comparison is implemented as a per-bucket digest of (id, content_hash, lexical_version), which detects any stale payload, where a maximum alone would miss changes below the maximum.
