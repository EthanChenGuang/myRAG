<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| voice token to tenant scope | voice requests carry no session; the signed token is the only tenant source |
| embed configuration to tenant scope | embedded chat takes its tenant from RAG_EMBED_TENANT, never from the request |
| external store to the app | a store may answer outside the requested tenant |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-111 | Information disclosure | voice retrieval crossing tenants on an external backend | critical | mitigate | voice-scope canary on all three backends with the filter-ignoring negative control dropped by rag_validate_chunks |
| T-07-112 | Information disclosure | embed retrieval crossing tenants | critical | mitigate | embed-scope canary on all three backends; raw-body workspace refusal; negative control |
| T-07-113 | Denial of service | the voice switch routing voice to an unready store | medium | mitigate | voice default pgvector with no readiness call; not-ready fallback asserted under the switch |
| T-07-114 | Repudiation | a canary that cannot fail | high | mitigate | every case has a negative control whose raw response must contain the foreign ids before the re-check drops them |
| T-07-SC | Tampering | npm/pip/cargo installs | high | accept | no package installed by this plan |
</threat_model>
