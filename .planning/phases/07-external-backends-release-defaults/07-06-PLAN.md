<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external store to the app | a store may return foreign, stale or planted ids |
| app to Supabase service role | re-validation runs with the service key, tenant only from TenantScope |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-16 | Information disclosure | foreign or stale ids from a store | critical | mitigate | rag_validate_chunks on every request, no switch; ranks rebuilt from kept ids only |
| T-07-17 | Information disclosure | answer text sourced from a vendor | high | mitigate | payload excludes content and names; hits hydrated from Supabase only |
| T-07-18 | Elevation of privilege | client roles calling validate or sync reads | high | mitigate | REVOKE from PUBLIC, anon, authenticated; SET ROLE tests |
| T-07-19 | Repudiation | silent drops | medium | mitigate | tenant_validation_dropped in the span and a [RAG Security] error line with counts |
| T-07-20 | Tampering | servability drift between pgvector and external stores | high | mitigate | one view as the servable definition; parity test against hybrid_search_chunks |
| T-07-SC | Tampering | npm/pip/cargo installs | high | accept | no package installed by this plan |
</threat_model>
