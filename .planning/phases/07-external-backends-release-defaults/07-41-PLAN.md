<objective>
Put the languages of the retrieved chunks on every trace next to the query language, its confidence and the answer language; report online judge scores per language; and calibrate query-language confidence from the fixture set with a tool-written file.

Purpose: LANG-10 (traces and per-language judge scores) and the OBS-03 clause "treats query-language confidence as the three-value mapping (1, 0.5, null) until Phase 7 calibrates it". The FBK-01 log already stores these codes (Phase 5.1.1 D-03a); the traces did not, so a Langfuse trace or an eval trace could not be split by language.
Output: the trace changes, the online judge per-language summary, the calibration tool, the committed calibration file and the mapping module.

Closeout half. Plan precondition (check before Task 1; stop without any edit if it fails): each of `.planning/phases/05-verified-citations-groundedness/05-VERIFICATION.md`, `.planning/phases/05.1-prompt-injection-defense/05.1-VERIFICATION.md` and `.planning/phases/06-query-layer-llamaindex-langchain/06-VERIFICATION.md` has `status: passed` or `status: human_needed`. File-order dependencies: 07-40 (TraceLanguages, LanguageConfidenceCalibration), 07-12 (last Phase 7 editor of collector.ts, log.ts and rag-eval/trace.ts); 05.1.1-22 closes Phase 5.1.1, whose plans 05.1.1-05 and 05.1.1-07 edit finish.ts and set the answer language on the holder; 03.2-68 closes Phase 3.2 (chunk language, LANG-05). Phase 5.1 edge: 05.1-22.

Planner resolutions (revision 4, owner rule: take the recommended option):
- The trace block has no switch: it adds codes to traces that are already written and changes no response; with Langfuse off nothing is sent, as today.
- Calibration bins are deliberately coarse (two confidence flags, three length buckets, two script classes) so a fixture set of a few hundred items fills every bin; an empty bin falls back to the mapped value and is marked so in the file.
- The tool is TypeScript because the detector is TypeScript; Python never re-implements detection.

Commit rule for every task: plain `git commit`; the message ends with the attribution lines (Co-Authored-By and the session link) that the executor's own session supplies; never copy them from a plan. No model identifiers in code comments or commit messages; no secrets.
</objective>
