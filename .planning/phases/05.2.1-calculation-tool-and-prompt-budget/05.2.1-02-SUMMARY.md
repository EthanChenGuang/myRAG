## Behaviour changes

- None at the defaults. With the four switches unset or at their defaults, every Phase 5.2 field of `readAnswerConfig` is unchanged, `anyNonDefault` stays false and no warning is added (tested).
- `RAG_CONTEXT_OVERFLOW=refine` while `RAG_PROMPT_BUDGET` is off resolves to `truncate` with warning `overflow_needs_budget`. An unknown value resolves to `truncate` with `invalid_context_overflow`. The messages name variables only and never repeat a configured value.
- `RAG_CALC_CHECK=true` without `RAG_CALC_TOOL` is valid (D-72, D-73).
- A run config may set the four switches. Booleans must be `true` or `false`, and the overflow must be `truncate` or `refine`.
- Config UI: the Calculations group holds `RAG_CALC_TOOL` and `RAG_CALC_CHECK`. The Prompt size group holds `RAG_PROMPT_BUDGET` and the `RAG_CONTEXT_OVERFLOW` select ("Keep the highest-ranked documents" / "Answer over several calls"). Ids equal the env names, so the existing load and Save All Changes cover them. The en, zh and it labels come from UI-SPEC 14.3.
- No product behaviour reads `contextLength` yet. The prompt budget (later plans) will use it.
