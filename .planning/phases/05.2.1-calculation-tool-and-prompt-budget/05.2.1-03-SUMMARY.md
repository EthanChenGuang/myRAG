# Phase 5.2.1 Plan 03: Exact calculation core Summary

**BigInt rationals, integer civil dates and the closed D-67 operation set, checked against a standard-library Python oracle and kept free of floating-point code by a source scan.**

## Accomplishments
- `rational.ts`: an immutable reduced `{ n, d }` (d > 0) with the strict grammar `^-?[0-9]+(\.[0-9]+)?$`; exact add, subtract, multiply, divide; `roundTo` with `half_up`, `half_even`, `up` and `down` (D-95); the display and `display_rounded` rule; `bitLength` for the evaluator's bounds (Pitfall C3); typed `CalcError`.
- `dates.ts`: strict ISO parsing with leap years, Hinnant days-from-civil in integer arithmetic, `dateDiff` with complete months and years.
- `operations.ts`: one pure function per operation, a frozen `OPERATIONS` table and `applyOperation`, which rejects any string outside the closed set, `constructor` and `__proto__` included.
- `rag_eval.calc_vectors`: 711 deterministic cases (parse 24, binary 144, list 57, cap_each 21, percentage 30, round 216, display 30, date_diff 189), covering ties in every mode, negative-zero rounding, leap days, month ends, inclusive and exclusive differences, dates before 1970 and invalid dates.
