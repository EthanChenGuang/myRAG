# Phase 5.2.1 Plan 08: Tokenizer Calibration Summary

**`python -m rag_eval.calibrate tokenizer` reads recorded eval runs, pairs each trace's pre-factor cl100k estimate with the provider-reported prompt tokens, and writes one factor per model family (nearest-rank 0.95 quantile, at least 20 samples) to `eval/config/tokenizer-calibration.json`. It is the only writer of that file, validates its output with `TokenizerCalibration`, keeps the cells of families it did not measure, and reads files only.**

## Accomplishments

- `tokenizer.py`: `load_samples(run_dirs)` returns (family, estimated_raw_total, input_tokens, run_id) samples and skip counts. `fit_factors(samples, quantile, min_samples, computed_at)` returns measured cells and the sample counts of under-sampled families. `run_tokenizer_calibration(run_dirs, out_path, quantile=0.95, min_samples=20, write=True)` merges with the existing file, validates, and writes atomically with `written_by: "rag_eval.calibrate tokenizer"`.
- `__main__.py`: the `tokenizer` subcommand prints fitted cells, under-sampled families and skip counts. `--dry-run` prints the cells as JSON and writes nothing.
- Fixture run `run-a`: 25 traces of family `f1` with ratios from 1.10 to 1.30, 5 of `f2`, one trace without prompt_budget and one without usage. The fitted f1 factor is 1.2920.
