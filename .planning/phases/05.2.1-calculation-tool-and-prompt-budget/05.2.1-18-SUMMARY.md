# Phase 5.2.1 Plan 18: Calculation check on the chat stream

**With `RAG_CALC_CHECK` on and a calculation offered, the chat answer is checked once at the end of the stream; a wrong number gets a correction notice with the recomputed value, an unverifiable one a "not verified" notice, in the same response. Both values go into the finish metadata and the answer record, and the review reason reaches the queue by the record or, without a record, directly.**
