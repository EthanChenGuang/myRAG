<objective>
Remove the trailing calculation block from what users see and hand it to the check, for every model the tool cannot reach (D-72).

Purpose: the default model and every no-tools path (embed, models without tool support) must still get recomputed numbers (RESEARCH Pitfall C2); the block must never reach the guard, the sentence splitter or the user (Pitfall C5).
Output: a pure extractor with a whole-text twin, the stream adapter in the chain builder, optional marker stripping, tag neutralization in assembly.

The chain builder `answer-transforms.ts` and the sentinel neutralization step in assembly are Phase 5.2's; this plan adds its slot and re-reads both first (D-96).
</objective>
