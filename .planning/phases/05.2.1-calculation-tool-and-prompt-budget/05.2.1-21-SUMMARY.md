# Phase 5.2.1 Plan 21: Prompt budget on the chat route

**With `RAG_PROMPT_BUDGET` on, every chat (and WhatsApp) request is planned against its model window before retrieval, documents get the budget that is left, history is dropped oldest-first in whole turns, the question stays last, OpenRouter cannot compress the prompt, and a request that cannot fit fails in-band with `notices.prompt_too_long`. Off, nothing is computed and the request is byte-identical.**
