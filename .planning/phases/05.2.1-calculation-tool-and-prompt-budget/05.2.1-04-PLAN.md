<objective>
Let callers pass a document token budget into retrieval and pack blocks to it in rank order, deduplicated by parent, in both the v2 and the legacy assembly (D-83, RNK-08).

Purpose: the prompt-budget planner (plan 05.2.1-13) decides the document budget before retrieval; aliases are assigned during assembly, so packing must happen there, never afterwards (RESEARCH Pattern D, Pitfall B1).
Output: one option, one packing helper, the two assembly paths and the voice payload honouring it, a packing summary on the result.

This plan touches the retrieval pipeline only; with the option absent nothing changes.
</objective>
