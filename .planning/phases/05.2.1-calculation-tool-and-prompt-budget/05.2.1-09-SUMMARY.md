# Phase 5.2.1 Plan 09: Calculation tool, offer signal and answer-rule part 6

This plan adds the shared pieces the routes need to offer the calculation: one `calculate` tool builder that evaluates through `evaluateCalc` against the request's aliases, a per-request trace holder, the offer signal, the tool-capability predicate that copies the chat route's current rule, and part 6 of the answer-rule block. No route uses these yet; that starts with plan 05.2.1-14.
