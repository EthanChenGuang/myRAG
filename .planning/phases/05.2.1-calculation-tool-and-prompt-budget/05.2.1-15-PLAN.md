## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| voice agent to app | internal routes authenticated by the API key and the signed scope token |
| agent-supplied ids and numbers to server data | chunk ids and sizes come from the agent and are never trusted for tenant access |

| T-05.2.1-32 | Information disclosure | reading another tenant's chunk through a chosen chunk id | critical | mitigate | server-side scoped read; ids outside the scope are unknown sources; two-tenant tests in both modes |
| T-05.2.1-33 | Denial of service | oversized bodies or source lists | medium | mitigate | zod limits (20 sources, 8,000-character answer, 5 traces, schema limits) |
