## Sampling Rate

- **After every task commit:** Run the quick command for the touched module (under 30 s)
- **After every plan wave:** Run the full suite command
- **Before `/gsd-verify-work`:** Full suite green, `npm run gen:schemas` with an empty diff, `node scripts/check-config.mjs`, the D-62 comparison (all switches off: zero paired differences against the latest baseline; switches on: the absolute-zero gates pass and no slice moves beyond the noise band)
- **Max feedback latency:** 30 seconds per task; full suite once per wave
