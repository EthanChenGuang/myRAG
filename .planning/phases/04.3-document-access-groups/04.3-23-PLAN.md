<objective>
Let uploaders choose who sees a new document, validate the choice on the server, and apply it before the document becomes retrievable on every upload path.

Purpose: D-16 (choice at upload, admins any group, members their own groups, backfill flag) and D-19 (new versions inherit unless changed), without the window of RESEARCH Pitfall 7.
Output: the `access` form field end to end through the unified and legacy writers, the Config UI proxy and the backfill CLI, with tests.

Standing rules (04.3-PLAN-INDEX.md): the client sends group ids or everyone, never keys; `uploadAccessKeys` (plan 07) validates, `setUploadAccess` (plan 21) writes; legacy writers stay in `LEGACY_WRITERS` and only gain the column in their insert; `scripts/config-server.js` uses 4-space style of its own; this plan builds PGlite databases in its integration test, so run it alone in the working tree while that test runs.
Execution note (A-11 / PLAN-INDEX standing rule): this plan builds PGlite fixture databases; do not run it at the same time as another fixture-database plan of the same wave in the same working tree.
</objective>
