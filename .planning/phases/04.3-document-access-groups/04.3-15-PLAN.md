<objective>
Close the non-retrieval read paths: shared chats, the document list and by-id routes, images, scraper and ingest status, and add a boundary rule so a new content read outside the RAG module must be reviewed.

Purpose: D-15 (non-RAG paths that expose content or names apply the same scope in server code, because they use the service-role client) and D-27 (shared chats refuse or re-check).
Output: a small share-access module, eight routes and the shared page changed, a boundary rule, two test files.

Standing rules (04.3-PLAN-INDEX.md): not visible equals unknown everywhere (same status, same body, same title); imports from `@/lib/rag` only (`resolveAccessScope`, `scopeAccessFilter`, `visibleDocumentIds`, `accessTableFilter`, `documentAudiences`); every helper takes the scope returned by `resolveAccessScope`; `src/app/shared/[shareId]/page.tsx` is a UI path for the design gate: it gains no visible element, and the SUMMARY records the design-skill outcomes for it; the share route keeps its own response shape (`{ error }`, no `success` field).
</objective>
