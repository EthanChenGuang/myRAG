Output: migration 0931 extended, the answer-finish writer, the answer read path, tests. Traces and Langfuse are plan 14.

Standing rules (04.3-PLAN-INDEX.md): the Phase 5.1.1 tables are a seam (re-grep for `rag_retrieval_log`, `rag_review_items`, `rag_is_domain_expert`); guarded DDL only around tables, functions top-level; label sets carry keys only, never group names or content; PGlite plan, run alone in this working tree.
</objective>
