## Sampling Rate

- **After every task commit:** the quick command for the files the task touches
- **After every plan wave:** the full suite command
- **Before `/gsd-verify-work`:** full suite green; smoke tier within the noise band with `RAG_DOC_ACCESS_GROUPS` off and on
- **Max feedback latency:** 60 seconds per task
