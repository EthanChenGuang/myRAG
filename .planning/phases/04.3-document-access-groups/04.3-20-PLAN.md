<objective>
Write the service-role SQL functions behind group administration: groups, members, candidate search, the caller's own groups, and the admin document view with audience and counts.

Purpose: D-28's single API (both surfaces call it), D-18's fail-closed group deletion with its counted confirmation, D-29's member view, and the data the UI-SPEC section 8.1 views need.
