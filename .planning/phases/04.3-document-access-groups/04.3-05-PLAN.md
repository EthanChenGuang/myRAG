| server code to service-role functions | tenant key from the scope, user id from the verified identity, keys from the resolver |
| one tenant to another | group ids, user ids and document ids are checked against the tenant key |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.3-051 | Elevation of privilege | resolver returns a group or admin right of another tenant | critical | mitigate | tenant-key filter on every lookup; two-organization fixture test |
| T-04.3-052 | Tampering | setter writes a key of another tenant or an empty label | high | mitigate | key validation (unknown_group, unknown_user, empty_access); tests |
| T-04.3-053 | Information disclosure | relabel reaches only the current version | high | mitigate | lineage-wide update; drift test with superseded rows |
| T-04.3-054 | Repudiation | label changes without a trace | medium | mitigate | one audit row per lineage with actor and actor kind |
| T-04.3-055 | Information disclosure | security event or audit holds content | medium | mitigate | id and code columns only; writer takes ids only |
| T-04.3-056 | Elevation of privilege | client executes a resolver or setter | high | mitigate | REVOKE from PUBLIC, anon, authenticated; static grant test |
